## 5. 데이터 구조 → 프론트 매핑

`daily_letters` 테이블 한 row → 프론트 `mockTodayFeed[i]` 한 카드.

| daily_letters 컬럼 | mockTodayFeed 필드 | 비고 |
|--------------------|---------------------|------|
| editor_id | editorId | "NT-min" → /editors/NT-min 라우트 |
| archetype | archetype | OneShotLetter chip |
| theme | theme | meta chip |
| headline | title | 큰 헤드라인 |
| subtitle | subtitle | 부소제목 |
| body_s3_uri | body | 본문 (S3 fetch) |
| keywords | keywords | 형광펜 highlight |
| article_id | sourceArticleId | "원문 보기" 링크 |

→ 프론트 코드는 mockTodayFeed import 한 곳만 `fetch('/api/v2/today-letters')` 로 교체.

## 6. 톤 비교 — 페르소나 4명 (1줄 요약)

- **민철**: 두 숫자 → 한 흐름. "다음 화요일 PMI 가 다음 신호" 같은 다음 액션 한 줄로 닫음.
- **하은**: 사건이 아니라 **구조**. "14년 곡선" 같은 시간축 + "결과보다 먼저 짚고 싶은 건" 같은 우회.
- **준서**: ①②③④. 숫자·날짜·1.4배. 군더더기 0.
- **소율**: 가격 + 행동 + 한 줄 시그널. "우리가 멀리 와 있다는 신호" 같은 정서적 클로징.

→ 4명이 같은 날 같은 풀에서 글을 써도 톤이 완전히 다른지가 핵심 검증. 위 4편이 그게 됐나 사용자 확인 부탁드려요.
