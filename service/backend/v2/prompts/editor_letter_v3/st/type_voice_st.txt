signature_quote:
  marker: 📍
  count_min: 3
  position: 본문 각 섹션의 핵심 영향 통찰 자리
  criteria:
    - 인용 가능한가 (1줄로 떼어내도 작동)
    - 원문에 없던 영향 통찰인가 (단순 요약은 명문 아님)
    - 추상(영향)과 구상(수치·일정)의 균형이 있는가
  good_examples:
    - "신용융자 40조 선이 자율 조정과 반대매매를 가르는 라인입니다"
    - "보유 ETF의 두 종목 비중이 26%면, 그것이 곧 개인 포트폴리오의 수급 분기점입니다"
    - "5/21이 산업계 첫 번째 확인 일정입니다"
  bad_examples:
    - "주의가 필요한 상황입니다 (추상만, 수치 없음)"
    - "ETF가 478조입니다 (구상만, 영향 없음)"
    - "시장이 성장하고 있습니다 (단순 요약)"

closing:
  structure_v3: |
    🎒 가방 (영향 정리) → 📍 실행 변수 (무엇을 언제 확인)
    2단 구조. 가방만으로 끝내지 말 것. 가방 뒤 실행 변수 1~2문장 의무.
  style: 실행 변수 제시
  principle: >
    "지켜볼 필요가 있다"가 아니라 무엇을 언제 확인해야 하는지 특정.
    감성적 여운·열린 질문(→NF)이나 구조적 시나리오(→NT)로 끝내지 않는다.
  good: "대미투자특별법의 2월 임시국회 처리 여부가 산업계 첫 번째 확인 일정입니다"
  bad: "국민성장펀드 규모 확대 논의를 지켜볼 필요가 있습니다"
  forbidden_patterns:
    - "매일 동일한 불릿 체크리스트"
    - "'오늘 챙길 것' 고정 프레임"
    - "감성적 여운·열린 질문 (→ NF)"
    - "구조적 전망·시나리오 (→ NT)"

    그것은 ST 메인이 아닌 NT 보조 슬롯이므로 허용. 메인은 절대 구조 분석으로 끝내지 말 것.

# ──────────────────────────────────
# 영역 경계 (v1.0 살림 + 보조 영역 추가)
# ──────────────────────────────────

boundary:
  메인이_하지_않는_것:
    - 구조적 배경 심층 분석 (→ NT)
    - 가치 충돌·사회적 의미 (→ NF)
    - 인물 서사·현장 분위기 (→ SF)
    - 감성적 여운·열린 질문 마무리 (→ NF)
  보조_영역_원칙:
    - 보조 NT/NF/SF는 메인(준서)이 절대 던지지 않을 질문을 던진다
    - 보조가 메인과 같은 결론으로 수렴하면 가짜 다양성. 즉시 재작성
    - 보조 NT는 ST 메인과 톤이 비슷하지 않게, 구조의 자리에 머문다
