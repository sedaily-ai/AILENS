# cost — AWS 비용 추적

갱신: 2026-09-28.

## 이 폴더가 담는 것

이테크시스템 DSA 포탈(비용 탐색기)에서 확인한 AI LENS(`atlas4` 태그) AWS
비용을 날짜별 스냅샷으로 기록한다. `docs/`의 "질문별" 구조(architecture/
product/evaluation/...)와 다른 축이라 `backoffice/`와 같은 예외 폴더로
둔다 — 비용만 따로 추적하고 싶을 때 다른 폴더를 오가지 않아도 되게.

관련 정본:
- `docs/architecture/비용태깅_규칙.md` — 태깅 **규칙**(어떻게 태그를 붙여야
  하는지). 이 폴더는 그 결과로 **실제 얼마가 나왔는지**를 기록한다 — 서로
  다른 질문에 답하는 문서라 합치지 않는다.

## 스냅샷 규칙

- 파일명: `YYYY-MM-DD-주제.md` (worklog와 동일 컨벤션).
- 이테크시스템 포탈에서 그대로 복붙한 표는 원본 그대로 남기고, 그 아래
  "관찰"/"가설" 섹션에 해석을 덧붙인다 — 표 자체는 해석하지 않으면
  숫자 나열일 뿐이라, 왜 그 시점에 그렇게 움직였는지 아는 사람이(세션
  기록·코드 변경 이력과 대조해) 가설을 남겨야 다음에 보는 사람이 이해할
  수 있다.
- 확정 사실과 추측을 분리해서 쓴다 — "실측 확인"과 "가설(미확인)"을
  명확히 구분.
