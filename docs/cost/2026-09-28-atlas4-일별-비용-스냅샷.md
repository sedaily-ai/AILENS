## 가설

- **Stable Image Ultra 급등(확인됨)** — 세션 git log로 직접 대조:
  `8bd4e51`(2026-09-20) "웹툰 발행 파이프라인 모델 디스패치 admin과
  통합 + GPU→Ultra 전환" 커밋이 바로 이 날짜. 웹툰 컷 이미지 생성을
  GPU(IP-Adapter, `pipeline` 모델)에서 Stable Image Ultra(`sd_ultra`)로
  전환한 게 정확히 이 스파이크와 날짜가 일치 — 우연이 아니라 이 전환이
  원인이라고 봐도 될 것 같다(모델 단가 차이 + 자동 파이프라인이 매일
  다수 기사를 8컷씩 생성하니 하루치 물량이 그대로 청구액에 반영).
- **Stable Image Core → Ultra 인계(확인됨)** — 같은 커밋이 이미지 모델을
  교체했으므로 Core 비용이 같은 시점에 0으로 꺼진 것도 같은 원인.
- **EC2 9/16 이후 고정 ~$31.7/day — NAT 게이트웨이가 유력(가설, 정황 보강됨)**
  `lens-cms-api-prod`는 `t3.micro`라 인스턴스 자체 컴퓨팅비는 하루
  몇십 센트 수준밖에 안 나온다 — $31.7/day는 이 인스턴스 하나로는
  설명이 안 된다. VPC에 **NAT 게이트웨이가 2개** 떠 있는 걸 확인했는데
  (`nat-0590017950e4a7495`, `nat-0665bd606c707c846`), NAT 게이트웨이
  비용(시간당 기본요금 + 처리한 데이터량당 과금)은 AWS 비용 분류상
  "Amazon EC2" 항목으로 잡힌다 — 자동 발행 파이프라인 컨테이너들이
  매번 이 NAT를 거쳐 Bedrock·S3와 통신하면서(웹툰 8컷 이미지 업/다운로드
  포함) 데이터 처리 비용이 누적됐을 가능성이 높다. 다만 Cost Explorer가
  SCP로 막혀 있어 리소스별 정확한 내역까지는 이 세션에서 확정 못 함.
- **GPU 사용 시기(확인됨)** — 웹툰 캐릭터 일관성용 GPU IP-Adapter는
  `f183c3a`(2026-09-09) 커밋으로 프로덕션에 편입돼 9/9~9/20 약 11일간
  실사용됐고, `8bd4e51`(2026-09-20)로 Stable Image Ultra로 완전히
  대체됐다(그 이후론 실사용 0건, 2026-09-25 코드에서 옵션 자체 제거,
  2026-09-28 파일 삭제). GPU 자체는 EC2 인스턴스로 떴었을 텐데, 이미
  지워져서(터미네이트 이력 조회 결과 빈 값) 이 스냅샷 표의 어느 항목에
  얼마나 잡혔는지는 개별로 분리가 안 됨 — 9/1~9/9 구간 "Stable Image
  Core" 비용과는 별개다(그건 이미지 모델이고 GPU는 EC2 컴퓨팅).
- **Claude Sonnet 4.6이 이 구간 내내 우세(설명됨, 향후 전망)** — 이
  스냅샷은 9/26까지만 담는데, 레터/웹툰/팟캐스트/영상 전 카테고리를
  Opus 5로 전환한 결정은 2026-09-27에 있었다(이 세션에서 직접 확인·작업).
  즉 이 표의 Sonnet 4.6 비용은 전환 **이전** 구간이라 앞으로(9/27 이후)
  스냅샷을 다시 뜨면 Sonnet 4.6은 거의 0으로, Opus 5가 그 자리를
  대체했을 것으로 예상 — 다음 스냅샷에서 검증 필요.
