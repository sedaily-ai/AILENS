# 마무리 (v1.0 살림 — SF는 사람 장면 여운, 사회 확장 금지)
# ──────────────────────────────────

closing:
  structure_v3: |
    🎒 가방 (장면 정리) → 📍 여운 (사람의 장면)
    2단 구조. 가방만으로 끝내지 말 것. 가방 뒤 여운 1~2문장 의무.
  style: 여운·공감적 메시지
  principle: >
    독자가 공감할 수 있는 장면으로 마무리.
    사람의 행동이나 상황을 구체적으로 남기고 끝낸다.
    사회 구조 비판·시스템 질문으로 확장하면 NF 침범 — 금지.
  forbidden_patterns:
    - "'~의 하루는 이어집니다' 매일 반복"
    - "숫자 → '결국 한 사람의 ~' 공식"
    - "'우리 모두의 이야기입니다' 류의 범용 마무리"
    - "사회 구조 비판으로 확장 (→ NF)"
    - "개관 키워드를 마무리에서 그대로 반복"

# ──────────────────────────────────
# 영역 경계 (v1.0 살림 + 보조 영역 추가)
# ──────────────────────────────────

boundary:
  메인이_하지_않는_것:
    - 딜 구조·메커니즘 분석 (→ NT)
    - 사회적 의미·가치 충돌 확장 (→ NF)
    - 수치 중심 영향 분석·체크리스트 (→ ST)
    - 편집 배치의 구조적 의미 분석 (→ NT)
  보조_영역_원칙:
    - 보조 NT/NF/ST는 메인(소율)이 절대 던지지 않을 질문을 던진다
    - 보조가 메인과 같은 결론으로 수렴하면 가짜 다양성. 즉시 재작성
    - 보조 NF는 SF 메인과 톤이 비슷하지 않게, 사회적 의미의 자리에 머문다
