# 말풍선 없는 여러 컷 만평

## 목적

말풍선이 그림을 가리는 문제를 없애고, 기사 내용을 상징·표정·상황으로 전달하는 만평 스타일로 바꾼다.

## 선택한 구성

- 사용자가 선택한 방향: 여러 컷 유지 + 그림 아래 설명.
- 기존 8컷 구조와 웹툰 탭 이름을 유지한다.
- 말풍선·생각풍선과 이미지 위 텍스트 합성을 제거한다. 빈 말풍선도 생성하지 않도록 지시한다.
- 대화하는 진행자 중심의 구성을 기사에 근거한 시각적 비유와 상황 중심으로 바꾼다. 비유를 새로운 사실처럼 설명하지 않는다.
- 컷마다 짧은 한국어 설명을 그림 바로 아래의 어두운 띠에 흰색으로 합성한다. 이미지에도 설명이 포함되어 다운로드에 보이며, 합성 실패 때만 기존 `text_caption` 외부 표시 경로를 쓴다.
- 창작 화풍은 공통 제작 코드에 고정하지 않고 버전별 프롬프트에 둔다. v67은 기사에 근거한 인물·행동·상황, 풍부한 색과 질감, 장면 간 연결을 지시하며 무관한 상징·미지정 국기와 말풍선을 금지한다.

## 검토한 접근

1. **선택: 여러 컷 만평 + 아래 설명.** 기존 읽기 흐름을 유지하면서 그림 가림을 없앤다. 각본과 이미지 지침, 합성 경로를 함께 수정해야 한다.
2. 한 장의 만평 + 아래 설명. 메시지는 압축되지만 사용자가 선택한 여러 컷 구성과 맞지 않는다.
3. 설명 없는 무언 만화. 그림에 집중할 수 있지만 수치와 기사 맥락 전달이 어려워 선택하지 않았다.

## 구현 범위

- 자동 발행과 관리자 컷 생성·재합성 경로에서 같은 규칙을 적용한다.
- 코드 기본값만 바꾸면 실제 발행 프롬프트가 덮어쓸 수 있으므로, 발행 프롬프트를 읽는 경로와 운영 설정 반영 방법을 함께 확인한다.
- 기존 기사 근거 검증, 이미지 모델 설정과 실패 처리를 유지한다.
- 기존 발행 이미지에는 말풍선이 이미 포함되어 있다. 이번 변경은 새 생성·재생성분에 적용하며 기존 게시물을 일괄 재생성하지 않는다.

## 검증과 완료 기준

- 과거 형식의 대사가 입력되어도 새 생성·재합성 결과에 말풍선을 그리지 않는다.
- 이미지 지침에 말풍선 금지와 만평 스타일이 포함된다.
- 컷별 설명이 발행 데이터에 보존되고 그림 아래 표시된다.
- 관련 회귀 검사와 번들 의존성 검사를 실행한다. 실제 이미지 생성으로 화풍을 확인했는지는 별도로 보고한다.

## 상태

2026-11-18 사용자 설계 승인(“진행.”). 1차 운영 반영 후 실제 결과의 밋밋한 장면과 자막 띠 부재를 확인해 보완했다. v65는 보존하고 v66도 남긴 채 v67을 활성화했으며 이미지 설정 v31은 유지한다. CMS·자동 발행 correction 배포 완료. 단일 컷 실제 생성에서 자막 띠와 맥락 장면을 확인했으나 이미지 속 가짜 글자 흔적이 남아 전체 컷의 시각 품질을 보장하지 않는다.
