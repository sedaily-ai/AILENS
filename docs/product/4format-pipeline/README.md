# 4포맷 파이프라인 프롬프트 스펙

기사 원문 1건 → 레터·웹툰·팟캐스트·영상 4개 포맷을 자동 생성하고 사실
커버리지를 검증하는 파이프라인의 **프롬프트 정의**. 각 포맷이 무엇을 담고
무엇을 담지 않는지, 출력이 어떤 형태여야 하는지가 여기에 있다.

**왜 이 4개 포맷인가**는 `../4format-persona-system.md`.
**품질을 어떻게 재는가**는 `../../evaluation/4format-evaluation-system.md`.

## 단계

```
기사 원문
  └─ 02_EXTRACT  사실 추출 → facts.json
       ├─ 03_LETTER    구조와 인과      (core + support 전부)
       ├─ 06_WEBTOON   감정 이입 가능한 장면
       ├─ 04_PODCAST   의미와 감각      (수치 3개 이하)
       └─ 05_VIDEO     변화와 대비      (대비 수치 없으면 chart 컷 스킵)
  └─ 07_VERIFY   facts.json 대비 커버리지 검증 → 발행 게이트
```

| 파일 | 다루는 것 | 상태 |
|---|---|---|
| `02_EXTRACT.md` | 원문 → facts.json. 4포맷·검증의 공통 입력 | ⚠️ **재구성본** |
| `03_LETTER.md` | 레터 — 시계열·구조·메커니즘 | 원본 |
| `04_PODCAST.md` | 팟캐스트 — 1인 화자, 감각 변환 | 원본 |
| `05_VIDEO.md` | 영상 — 컷 6종, 렌더용 JSON | 원본 |
| `06_WEBTOON.md` | 웹툰 — 스크립트 → 연출 → 이미지 3단계 | 원본 |
| `07_VERIFY.md` | 커버리지·사실 검증 게이트 | ⚠️ **재구성본** |

## ⚠️ 재구성본 2개 — 원본이 나오면 원본이 정본이다

`02_EXTRACT.md` 와 `07_VERIFY.md` 의 원본은
`2_ailens/마스터DB/03_개발·프롬프트/4포맷_파이프라인/` 에 있고 이 레포에 없다.
2026-08-25 에 나머지 네 스펙이 facts.json 에 대해 요구하는 것과
`4format-persona-system.md` 의 사고 기록을 역으로 짜맞춰 복원했다.
두 문서 모두 §7 에 **필드별 근거 출처표**와 "추정이 섞인 곳"을 명시해 뒀다.

## 아직 없는 것

`00_CONTEXT.md` · `01_COMMON.md` 는 이 레포에도, 로컬에도, DDB 에도 없다.
**네 포맷 스펙이 전부 "01_COMMON.md의 모든 규칙을 준수한다"로 시작하므로,
지금은 모든 포맷이 읽을 수 없는 공통 규칙을 전제하고 있는 상태다.**
02·07 과 달리 내용을 추정할 근거가 없어 복원하지 않았다 — 마스터DB 에서
원본을 회수하는 게 맞다.

## 실제 운영 프롬프트는 DDB 에 있다

이 문서들은 **정의**고, 프로덕션이 읽는 건 DynamoDB
`sedaily-mbti-admin-prompts-dev` (`PROMPT#<category>/<scope>`) 다.
`pipelines/common/ddb_prompt.py` 가 로드하고, admin 콘솔에서 편집한다.

**여기를 고쳐도 프로덕션은 안 바뀐다.** 반영하려면 DDB 프롬프트를 같이 올려야
한다. 반대로 DDB 만 고치고 여기를 안 고치면 정의와 운영이 갈라진다.

### 커버리지 트레일러 — 순서 주의

`03`·`04` 는 코드블록 **바깥** 마지막 줄에 `FACT_IDS: [1, 3, 4]` 를,
`05` 는 컷마다 `"fact_ids": []` 를 내보낸다(`06` 은 원래부터 냈다).
07_VERIFY 가 이 값으로 커버리지를 대조한다.

🛑 **코드가 먼저 나가야 한다.** 이 트레일러를 떼어내는 처리가 없으면
레터는 그 줄이 발행 본문 문단이 되고(`_parse_letters` 에 종료 조건이 없다),
팟캐스트는 ElevenLabs 가 소리 내어 읽는다. 처리는 PR #26
(`common/text_utils.py` 의 `extract_fact_ids`)에 있다.
**PR #26 머지 → DDB 프롬프트 갱신** 순서를 지킬 것.
