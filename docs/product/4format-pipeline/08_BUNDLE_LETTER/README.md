# 묶음 레터 (지면특별코너 다건 통합 레터)

상태: **보류 (2026-09-28)** — 개별 기사를 하나의 레터로 융합하는 방향 대신,
개별 레터는 그대로 두고 그 위에 "오늘의 [탭] 조망" 요약 카드를 별도로
얹는 방향(다이제스트 레이어)으로 기울었으나, 이것도 UI/UX 설계가 먼저
필요해 보류. 우선순위는 `일반` 카테고리 선정 로직(소거+다양성) 쪽으로
이동 — worklog 참고.

지면특별코너(전체/증권/산업/시그널) 각 탭에 선정된 여러 건(최대 4건)의
기사를 **레터 1건 = 기사 1건**이 아니라 **레터 1건 = 기사 여러 건 묶음**으로
발행하는 신규 콘텐츠 유형. 다른 포맷 폴더(`02_EXTRACT`~`07_VERIFY`)와 달리
번호(`NN-`) 대신 **시맨틱 버전**(`vX.Y-`)으로 파일을 쌓는다 — 이 폴더 자체가
아직 실험 단계라 "확정 스펙에 append하는 결정기록"보다는 "버전을 거듭하며
바뀌는 프로토타입"에 가깝다는 판단(2026-09-28, 사용자 명시 요청).

## 왜 필요한가

지면특별코너 각 탭에서 선정된 기사 4건이 지금은 각각 독립된 4포맷
(레터/웹툰/팟캐스트/영상) 콘텐츠로 따로 발행된다. 서로 다른 뉴스를
따로따로 접하면 "흩어진 퍼즐 조각"처럼 느껴져 인사이트가 약하다 —
독자가 레터를 클릭했을 때 연결성 있는 스토리텔링으로 읽히는 게
더 가치 있다는 판단(사용자, 2026-09-28).

## 기존 레터와의 관계

`03_LETTER/`(기사 1건 → 레터 1건)는 그대로 유지된다. 이 폴더는
지면특별코너 4탭 전용의 **별도 콘텐츠 유형**을 다룬다 — "일반" 카테고리는
지금처럼 기사 1건 = 레터 1건을 유지할지, 이것도 나중에 주제별로 묶을지는
미정(2026-09-28 대화에서 "일반은 여러 기사가 서로 무관해서 억지 연결
위험이 크니 몇 개의 작은 주제 클러스터로 나눠서 묶는 게 안전하다"는
방향까지만 나옴, 클러스터링 방식은 미설계).

## 영향 범위

기사 1건을 전제로 하는 `pipelines/common/publish_utils.py::publish_article()`
전체(레터·웹툰·팟캐스트·영상 4포맷 생성 + facts_extract 0단계)가 다
영향을 받는다 — 레터 프롬프트만 바꿔서 될 일이 아니다.
