# VIDEO — 현재 구조 베이스라인 (2026-09-21)

작성: 문영광 + Claude Code. 코드 직접 대조로 확인 — 갱신 시 이 문서도
같이 고칠 것.

## A to Z — 실제 코드 흐름

```
frontpage_auto/run.py, mustknow_auto/run.py
  └─ publish_utils.publish_article()
       └─ publish_utils.generate_video(name, article_path, out_dir, photo_url, photo_caption)
            └─ generate_script.generate_script(...)             ← Python, Bedrock
                 └─ ddb_prompt.load_prompt("video")
                 └─ call_text(guide, "...기사 원문(+사진 유무)...", max_tokens=4000)
                 └─ JSON 파싱 실패 시 1회 재요청(형식만 재요청, 내용 재창작 아님)
                 └─ fix_script()  — 화이트리스트 밖 아이콘 자동 치환, 사진 URL 주입 등
                 └─ validate_script(script) → 에러 있으면 ValueError, 그 기사는 영상 스킵
                 └─ script.json 저장
            └─ subprocess: `npm run render -- --input script.json --format horizontal
                 --output video.mp4`                              ← Node.js, Remotion
       └─ 성공: video_url·thumb_url S3 업로드, status="published"
       └─ 실패(각본 생성 실패/validate_script 에러): status="published_no_video",
          needs_video=true로 표시 — 레터·웹툰·팟캐스트 3포맷만 우선 발행,
          영상은 나중에 사람이 채워 넣음(자동 재시도 없음)
```

- 각본 생성: `pipelines/video/generate_script.py`
  (`generate_script()` 189행~, `validate_script()` 156~186행)
- 렌더링: **별도 실행 환경**(Node.js/Remotion, `pipelines/video/scripts/render.ts`
  — Python 파이프라인이 `subprocess.run(["npm", "run", "render", ...])`로
  호출). 4포맷 중 유일하게 렌더링이 텍스트 생성 모델 바깥, 별도
  런타임에서 일어난다.
- 모델: `call_text()` 호출에 `model=` 인자를 안 넘김 —
  `bedrock_client.call_text()`의 기본 모델을 그대로 씀(전용 profile로
  안 뺀 상태, 확인 필요)
- 프롬프트: `video/published` — Postgres(lens-cms-api)
- **§23 원칙 — 팩트 없으면 사실을 지어내지 않고 실패시킨다**:
  `validate_script()`가 `stat` 컷의 수치, `chart` 컷의 비교값(최소
  2개), `diagram` 컷의 노드가 비어 있으면 **자동으로 채우지 않고
  에러로 남긴다**(156~184행 주석: "임의로 두 번째 값을 지어내지
  않으므로 원문에서 비교값을 직접 채울 것"). 이 에러가 나면 해당
  기사는 영상 없이 발행된다 — 영상만 유일하게 "실패하면 그 포맷만
  건너뛴다"는 명시적 설계를 가진 포맷.
- `fix_script()`는 반대로 **자동으로 고쳐도 되는 것**만 손댄다 —
  렌더러가 모르는 아이콘 이름을 화이트리스트 안 값으로 치환, 사진
  URL을 실제 값으로 주입 등(팩트 자체를 바꾸는 게 아니라 형식만 정리).
