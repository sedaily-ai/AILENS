# AILENS 영상 제작 프롬프트

01_COMMON.md의 모든 규칙을 준수한다.
`../02_EXTRACT/`의 facts.json을 입력으로 받는다.

────────────────────────
## 0. 이 포맷이 맡는 것
────────────────────────

**변화와 대비.** 무엇이 무엇으로 바뀌었나.

- 담는다: 전후 비교, 구조 도해, 추이 변화, 규모 대비
- 담지 않는다: 배경 설명, 정서, 종합 정리

**판단 기준: 이 정보를 눈으로 보면 더 잘 이해되는가.**
글로 읽는 게 나은 정보는 영상에 넣지 않는다.

────────────────────────
## 1. 분량과 구조
────────────────────────

- 전체 60~120초
- 컷 8~12개
- 나레이션 400~700자

**골격**

[컷1] 진입 (6~8초) — 질문 또는 상황. 3초 안에 주제가 잡혀야 함
[컷2] 문제 (8~12초) — 지금 무엇이 문제인지. 수치 1개
[컷3~6] 본론 (각 8~14초) — 변화·구조·비교 순차 제시. 컷당 정보 하나
[컷7~8] 반전/규모 (10~14초) — 예상과 다른 지점 또는 임팩트 수치
[컷9] 클로징 (8~10초) — 독자가 쓸 정보. 미확정 사항 명시
[엔드카드] (3초)

────────────────────────
## 2. 컷 타입 6종
────────────────────────

| type | 용도 | 화면 |
|---|---|---|
| opening | 진입 | 아이콘 + 타이틀 |
| stat | 단일 수치 | 큰 숫자 + 라벨 + 출처 |
| diagram | 흐름·구조 | 노드 + 커넥터 |
| chart | 추이·비교 | 막대 또는 꺾은선 |
| highlight | 핵심 정보 | 박스 + 강조 텍스트 |
| closing | 마무리 | 정보 박스 |

────────────────────────
## 3. 나레이션
────────────────────────

- 컷당 1~2문장, 25~50자
- 자막과 나레이션은 다르게 쓴다
  - 나레이션: "D램 사용량은 16분의 1로 줄어듭니다"
  - 자막: "D램 1/16"
- 구어체 "~요"체
- 숫자는 읽는 방식 그대로

────────────────────────
## 4. 비주얼 원칙
────────────────────────

- 인물 캐릭터 없음. 아이콘·도식만
- 배경 딥네이비(#0F1A2E), 텍스트 화이트, 강조 앰버(#FFB020)
- 컷 하나에 요소 3개 이하
- 실제 로고·브랜드 이미지 금지
- 수치 컷에 출처·기준 시점 표기

**소재별**

| 소재 | 처리 |
|---|---|
| 사건·피해 | 수법 설명 시 피해 결과 반드시 병기 |
| 시황·종목 | 주가 차트가 매수 유도로 읽히지 않게. 목표주가 표시 금지 |
| 기술·산업 | 구조 도해 중심. 성능 주장은 주체 명시 |

────────────────────────
## 5. 출력 형식
────────────────────────

두 가지를 함께 출력한다.

**(1) 각본 — 검수용**

[컷N] 용도 / 초
type: 컷 타입
나레이션: (텍스트)
자막: (텍스트)
화면: (구성 설명)

**(2) 렌더용 JSON**

{
  "title": "",
  "brand": "같은 뉴스, 네 가지 시선 | AILENS",
  "cuts": [
    {
      "type": "stat",
      "duration": 10,
      "narration": "",
      "caption": "",
      "data": {},
      "fact_ids": []
    }
  ],
  "source": "자료: ",
  "disclaimer": ""
}

**타입별 data 스키마**

// opening
{ "icon": "lucide 아이콘명" }

// stat
{ "value": 0, "unit": "", "label": "", "sourceNote": "" }

// diagram
{
  "nodes": [
    { "kind": "node", "icon": "", "label": "" },
    { "kind": "connector", "variant": "arrow" }
  ],
  "sourceNote": ""
}

// chart
{
  "chartType": "bar|line",
  "points": [{ "label": "", "value": 0 }],
  "unit": "",
  "sourceNote": ""
}

// highlight — caption을 세그먼트 배열로
"caption": [
  { "text": "관건은 " },
  { "text": "매장 규모", "emphasis": true }
]

// closing
{}

────────────────────────
## 6. 체크리스트
────────────────────────

□ 3초 안에 주제가 잡히는가
□ 각 컷의 정보가 시각화할 가치가 있는가
□ 컷 하나에 정보 하나인가
□ 자막과 나레이션이 다른가
□ 웹툰과 같은 정보를 반복하지 않는가
□ 수치 컷에 출처·기준이 있는가
□ 미확정 사항을 명시했는가
□ 컷마다 fact_ids가 있는가 (담은 사실이 없으면 빈 배열)
□ JSON 스키마가 유효한가
□ highlight의 caption이 세그먼트 배열인가
□ diagram의 nodes에 kind가 있는가
