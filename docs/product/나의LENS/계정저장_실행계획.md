# 나의 LENS 첫 백엔드 개발 묶음

목표: 서랍 조회 인증 보완 → 콘텐츠 ID 정리 → 계정 관심사·읽을 시간·레터 북마크 저장과 프론트 연결.
설계 정본: 백엔드_개발_인수인계.md, ../../architecture/나의LENS_백엔드_API계약.md.
구조: 기존 공개 Python Lambda handler → service/repository → 내부 FastAPI → psycopg2/PostgreSQL 유지.
실행: 현재 세션에서 순서대로 구현. 운영 DB·배포·AWS 호출·커밋·push는 수행하지 않는다.

## 공통 조건

- 계정 owner는 Cognito ID token의 검증된 sub만 사용한다.
- 기존 공개 콘텐츠·문장 저장/삭제·공개 인기 문장 계약은 보존한다.
- 직접 고른 관심을 에디터 팔로우로 덮어쓰지 않는다.
- 로컬 공용 북마크·기기 관심은 자동으로 계정에 가져오지 않는다.
- 실패를 정상 빈 목록이나 로컬 저장 성공으로 표현하지 않는다.
- DB 테스트는 loopback PostgreSQL과 가짜 자료, JWT는 로컬 서명키/JWKS stub 사용.

- [x] SQL v1.48: user_lens_preferences, user_letter_bookmarks. 계정 FK/CASCADE, revision CAS, saved_at keyset index, 서비스 최소 권한.

## 연결과 남은 범위

로컬 공개 API shim은 신규 handler를 호출하고 내부 CMS 라우터를 실제 PostgreSQL에 연결한다. 인증 우회 코드는 제품 소스에 추가하지 않는다. 운영 API Gateway 신규 integration·마이그레이션 실행·배포는 후속이다. 팔로우 계정 저장·기존 자료 가져오기·서버 추천·리워드·푸시는 이번 묶음에 포함하지 않는다.
