# 나의 LENS — 기획·개발 인계 문서

> **2026-10-19 기능 다이어트(현재)**: 나의 LENS는 '홈'·'내 서랍' 두 탭이다. 읽기 기록·리워드, 형식 선호, 알림 설정, 웹 푸시, 읽을 시간(5·10분), 읽음 표시, 저장 문장 관련 글을 화면과 공개 API에서 걷어냈다(DB 데이터는 보존). 아래 문서 중 [완료·리워드](완료·리워드_구현상태.md)·[알림·푸시](알림·푸시_구현상태.md)·[형식 선호](형식선호·계정연결_구현상태.md)·[이용 기록 축소](이용기록_리워드축소.md)는 그 시점의 기록이다. 현재 범위: [작업 기록](../../worklog/2026-10/2026-10-19-기능-다이어트.md), [API 계약 상단](../../architecture/나의LENS_백엔드_API계약.md).

> 2026-10-20 저장한 기사: 기사 화면 '저장'으로 기사를 계정에 저장하고, 내 서랍에서 '담은 문장'·'저장한 레터'·'저장한 기사' 세 종류를 본다(SQL v1.57) — [작업 기록](../../worklog/2026-10/2026-10-20-저장한-기사.md).

> 2026-10-16 리워드 축소: [이용 기록 중심 변경](이용기록_리워드축소.md). 날짜 체크·기간 기록은 유지하고 신규 스탬프·배지 지급과 주간 목표를 중단한다. 운영 반영 여부는 작업 기록을 따른다.

> 2026-10-15 현재: 계정별 형식 선호·추천/알림 연결, 에디터 팔로우, 서버 완료 읽음 필터, 사용자 선택 북마크 가져오기를 구현했다. PR #109는 main에 머지됐고 후속 로컬 보완으로 레터 카테고리 타입과 알림 잠금 권한을 맞췄다. 현재 계약은 [형식 선호·계정 연결](형식선호·계정연결_구현상태.md)과 [전체 리뷰 보완](백엔드_리뷰_보완.md)의 v1.55·API를 따른다. 아래 이전 단계의 미구현 표시는 해당 구현으로 대체하며 운영은 미반영이다.

나의 LENS는 뉴스·레터 이용 분야와 키워드, 직접 선택한 관심사, 저장한 문장·레터를 연결하는 로그인 사용자 대시보드다. 홈 / 내 서랍 / 읽기 기록·리워드 / 관심사·알림의 네 메뉴를 제공한다.

현재(2026-10-14): 개발 화면도 로그인 필수다. 공개 레터의 북마크 저장·해제도 로그인 필수이며 기존 브라우저 저장은 조회용으로 보존한다. 서랍 조회 인증·콘텐츠 resolver·계정 관심/읽을 시간·레터 북마크에 이어 이용 신호·관심/문장 기반 추천·홈 집계 API와 프론트 연결을 로컬 구현했다. 운영 DB 적용·API Gateway 연결·배포는 2026-10-15에 완료했다(worker 정기 실행은 보류). 콘텐츠 완료·KST 주/월/연 기록·스탬프·주간 배지도 로컬 구현했다. 개인화 알림 설정·별도 동의·암호화 기기 구독·후보/전달 원장·프론트도 로컬 구현했다. 기본 dry_run이며 실제 외부 푸시는 발송하지 않았다. 구현된 코드와 미적용 운영 조건을 구분한다.
