# 나의 LENS — 기획·개발 인계 문서

나의 LENS는 뉴스·레터 이용 분야와 키워드, 직접 선택한 관심사, 저장한 문장·레터를 연결하는 로그인 사용자 대시보드다. 홈 / 내 서랍 / 읽기 기록·리워드 / 관심사·알림의 네 메뉴를 제공한다.

현재(2026-10-14): 개발 화면도 로그인 필수다. 프론트 구성과 기존 API 재사용까지 진행했으며 계정 저장·추천 집계·유효 완료 기반 리워드·실제 개인화 푸시는 후속 서버/프론트 연동 범위다. 브라우저 초안·리워드 예시를 실제 지급·동의·발송으로 해석하지 않는다.

## 백엔드 개발자에게 전달할 문서

1. [백엔드 개발 인수인계](백엔드_개발_인수인계.md): 제품 목적, 최신 화면·저장 범위, P0 선행 보완, 기능별 흐름·예외, 개발 단계와 인수 시나리오.
2. [API 계약](../../architecture/나의LENS_백엔드_API계약.md): 기존 API 호환 및 신규 계정 API의 요청·응답·필드·인증·오류·멱등성.
3. [데이터·구현 설계](../../architecture/나의LENS_백엔드_데이터·구현설계.md): 기존 Lambda→내부 CMS API→PostgreSQL 경계, 추가 파일·테이블·인덱스, 트랜잭션·추천·발송·마이그레이션·검증.
