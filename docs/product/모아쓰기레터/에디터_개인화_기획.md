# 레터 에디터 개인화 기획 (2026-10-11)

## 1. 문제 정의
- 에디터 8명이 큰 주제 묶음(AI·테크, 정책, 국제, 생활경제 등)이라 독자가 "나는 누구를 고르지?"를 판단하기 어려움
- 구독 단계가 에디터 하나를 고르는 방식이라 독자의 상황·목적·시점을 반영하지 못함
- 추천 이유가 "겹친 주제 이름"뿐이라 왜 나에게 맞는지 와닿지 않음

## 2. 리서치 요약 (근거와 한계)
| 항목 | 확인된 것 | 한계 |
|---|---|---|
| 온보딩 질문 수 | Morning Brew는 이메일 1칸만 받음, Axios는 레터 선택이 곧 개인화 | 뉴닉·어피티·머니레터 등 국내 서비스의 질문 구조는 미확인 |
| 단계 수와 이탈 | 단계가 많아도 전환이 오른 사례와 내려간 사례가 섞여 있음 | 엄밀한 연구 없음 → 질문 수는 가설, 측정으로 조정 |
| 이메일 먼저/나중 | 무작위 비교 연구 미확인 | 가입 1화면(이메일) + 질문은 가입 뒤 선택으로 두는 것이 안전하다는 것은 추정 |
| 세분화 틀 | 뉴스업계는 BBC User Needs(Update me / Give me perspective / Educate me / Keep me on trend)를 근거로 독자 니즈를 나눔. 상황×과업 분류는 이 틀과 개념상 가까움 | 금융 독자 유형(사회초년생·직장인 투자자 등)의 수치 근거는 미확인, 업계 통념 수준 |
| 필터 버블 | 개인화 효과는 작거나 혼재, 다양성 감소 증거는 약함 | 추천 이유 공개가 행동을 바꾸는지는 미확인 |
| 개인정보 | 직업·소득은 민감정보 목록에 없다는 것이 일반 해석, 최소수집·선택 미동의 시 서비스 거부 금지 | 법제처·개인정보위 확인 필요 |

## 3. 설계 원칙 (리서치 반영)
1. 가입은 이메일 1칸. 질문은 가입 직후 선택 단계(건너뛰기 가능)
2. 질문 3개 이내, 화면 1~2개: 상황 / 과업 / 받는 시각 (질문 수는 가설, 완료율로 조정)
3. 상황 칩 6개 이내. 초기 가설이며 클릭 데이터로 검증
4. 과업은 주제가 아니라 User Needs 형태 칩 4개, 복수 선택 가능
5. 직업·소득·구체 직무는 수집하지 않음. 선택 미응답이어도 동일 서비스 제공
6. 추천 이유는 독자가 고른 상황과 연결하되 사실 설명만(중립 원칙)
7. 선택한 상황 밖 레터도 일부 고정 편성(시작값 20~30%, 근거 없는 가설). 정치·논란성 주제는 개인화 대상에서 제외

## 4. 독자 상황 (6개, 초기 가설)
| id | 상황 | 설명 문구 |
|---|---|---|
| invest | 주식·ETF에 투자하고 있어요 | 직접 투자하는 직장인 |
| jobseek | 취업을 준비하고 있어요 | 경제를 처음 공부하거나 면접 소재가 필요한 분 |
| shop | 가게를 운영하고 있어요 | 자영업·상권 |
| home | 내 집 마련을 준비하고 있어요 | 전세·청약·대출, 육아·교육비 |
| startup | 창업이나 투자 흐름을 보고 있어요 | 스타트업·벤처 |
| retire | 노후를 준비하고 있어요 | 연금·배당·세금 |
(+ 그 밖에, 해당 없음: 에디터 전체 보기)

## 5. 독자 과업 (User Needs 4개)
| id | 과업 | 레터가 해 주는 일 |
|---|---|---|
| update | 오늘 무슨 일이 있었는지 알고 싶어요 | 핵심 소식을 간결하게 정리 |
| impact | 내 일과 어떻게 닿는지 알고 싶어요 | 제도·수치가 상황에 닿는 지점을 사실로 정리(권유·판단 없이) |
| context | 배경과 맥락을 이해하고 싶어요 | 숫자·타임라인·이전 흐름 |
| perspective | 다른 관점도 알고 싶어요 | 엇갈리는 해석과 반대 사례 |

## 6. 에디터 정의 (상황 × 과업)
이름·MBTI·이미지는 이전 서비스 것을 그대로 쓰고, 소개문의 "누구에게 / 언제 / 무엇을 해 주는지"만 구체화한다. 말투는 모든 에디터가 같다(레터 본문은 중립 원칙).
| 에디터 | 상황 | 주 과업 | 시점 | 구체 소개 |
|---|---|---|---|---|
| 민철 | invest | update, impact | 장 마감 후 | 삼성전자·ETF 등을 직접 사고파는 분께, 장 마감 뒤 실적·금리·환율이 어떻게 확인됐는지 숫자로 정리해요 |
| 소율 | jobseek | context | 출퇴근·점심 | 경제 뉴스가 처음이거나 취업을 준비하는 분께, 어려운 말과 기업 소식을 쉬운 말로 풀어요 |
| 시우 | shop, home | impact | 아침 | 임대료·상권·세금·전세처럼 생활에 닿는 제도가 바뀌면 무엇이 달라졌는지 정리해요 |
| 지훈 | startup | update, perspective | 아침 | 인공지능·반도체·벤처투자 흐름과 대기업 전략 변화를 사례로 정리해요 |
| 서연 | home | context | 주말 | 규제와 제도가 시행되는 과정과 시장 반응을 단계별로 정리해요 |
| 하은 | retire | context, perspective | 주말 | 저출생·고령화·노동처럼 오래 이어지는 사회 변화를 숫자와 사례로 짚어요 |
| 예린 | invest, startup | perspective | 아침 | 해외에서 나온 소식이 우리 경제에 닿는 경로를 나라별로 정리해요 |
| 준서 | invest | update | 장 마감 후 | 금융·증시 소식을 결론 먼저, 근거 숫자를 뒤에 정리해요 |
- 한 에디터가 여러 상황에 걸치는 것은 정상이며, 온보딩 결과로 1~2명을 추천한다.

## 7. 온보딩 흐름 (구독 대화상자 안, 2단계)
1. 1단계(필수, 1화면): 이메일 입력 + 동의 (현재 대화상자와 같음)
2. 2단계(선택, 건너뛰기 가능): "어떤 분께 맞춰 드릴까요?" — 상황 칩 1~2개 → 과업 칩 1~2개 → 받는 시각. 같은 화면에 모두 표시, 선택 후 "맞는 에디터 추천"
3. 3단계: 추천 에디터 1~2명 카드 + "이 에디터 구독하기" (이메일 확인 메일은 1단계 직후 발송)
- 추천 규칙: 선택한 상황과 과업이 겹치는 에디터를 점수순으로(상황 일치 2점, 과업 일치 1점)
- 추천 이유 문구 예: "'주식·ETF에 투자하고 있어요'를 고르셨어요. 민철은 이 상황의 독자를 위해 실적·금리·환율을 정리해요."

## 8. 측정
| 지표 | 정의 | 가설 |
|---|---|---|
| 신청 전환율 | 대화상자 열림 → 신청 | 15% 이상 |
| 온보딩 완료율 | 신청 → 2단계 완료 | 40% 이상(건너뛰기 허용) |
| 확인 완료율 | 신청 → 메일 확인 | 60% 이상 |
| 에디터별 읽음 완료율 | 메일 클릭 → 70% 이상 읽음 | 측정 후 기준 설정 |
| 수신거부율 | 구독 후 30일 내 | 2% 미만 |
- 모든 수치는 근거 없는 시작 가설이며 첫 2주 데이터로 보정한다.

## 9. 미확정·확인 필요
- 국내 뉴스레터(뉴닉·어피티·머니레터·토스피드·퍼블리·요즘IT)의 실제 가입 플로우 캡처
- 상황·과업 수집 항목의 개인정보처리방침 문구와 법무 확인
- 상황 6개 분류의 타당성(구독자 클릭 데이터로 검증)
