# 그날로 떠나요 (타임라인) — 기획 v0.2

작성: 2026-10-04 / 상태: v0.1 초안 후 사용자 방향 확정("1990년부터 지금까지 연대기별로, 사건 기간의 기사까지 함께"), 구현 진행 중. v0.2 변경은 문서 끝 §12
이름: 기존 "그날로 떠나요" 유지(사용자 결정, "담백하다")
관련 코드: 홈 구역 `features/news-feed/components/NewsTimeMachineSection.tsx`, 결과 페이지 `app/(content)/timeline/[date]`

## 1. 문제 발견

- 지금 기능은 "날짜를 고르면 그날 기사 목록"이다. 기획서 없이 홈의 비슷한 두 구역을 합치고(2026-08-17), 검색엔진용 날짜 주소가 필요해서(SEO 점검) 생겼다. 누구의 어떤 문제를 푸는지 정의된 적이 없다.
- 결과 페이지는 기사 제목 30건을 늘어놓고 원문(서울경제·빅카인즈)으로 내보내는 중간 목록이다. 독자를 AI LENS 안에 붙잡을 이유가 없다.
- 날짜를 알아야만 쓸 수 있다. "언제 무슨 일이 있었는지"를 모르는 독자는 입구가 없다.

## 2. 문제 정의

독자가 과거를 궁금해하는 방식은 날짜가 아니라 사건·시대다. "IMF 때 무슨 일이 있었지", "2008년 금융위기 땐 주가가 어떻게 움직였지". 날짜를 모르는 상태에서 시대를 고르고, 그 안의 결정적인 날로 들어가, 그날의 기사까지 내려가는 길이 없다.

## 3. 왜 (가치와 니즈)

사용자 발언(2026-10-04): 특정 기간에 어떤 일이 있었는지, 대한민국에서 사람들이 기억하는 역사적인 날로 타임머신 여행하듯 돌아가기. 투자·경제는 "언제 발생했고 어떤 기사가 있었는지"를 궁금해한다. 역사에서 미래를 배우고, 추억을 되짚는다. 시대를 설명하고 연대기로 보여준다.

| 니즈 | 독자 | 이 기능이 주는 가치 | 근거 수준 |
|---|---|---|---|
| 위기·사건의 맥락을 알고 싶다 | 투자·경제 독자 | 시대 설명 + 연표 + 그때 기사 | 가설(지표 없음) |
| 추억을 떠올리고 싶다 | 중장년 독자 | 기억하는 날로 바로 이동 | 가설 |
| 내 날짜(생일·기념일)가 궁금하다 | 일반 독자 | 날짜 직접 입력 | 기존 기능 유지, 가설 |
| "IMF 연표" 같은 질문에 답을 찾는다 | 검색·AI 검색 유입 | 시대 허브 페이지 | SEO·GEO 가설 |

서울경제가 1990년부터 쌓은 기사(빅카인즈 연동)가 이 기능에서만 쓸 수 있는 자산이다.

## 4. 구조: 시대 → 사건 → 그날

```
시대(Era)    IMF 외환위기 1997~2001, 글로벌 금융위기 2008, 코로나 쇼크 2020 …
  └ 사건(Event)  1997-11-21 IMF 지원 요청 발표, 1997-12-03 협상 타결 …
      └ 그날(Day)   /timeline/1997-11-22 — 그날 신문 기사 (현재 페이지)
```

흐름
1. 홈 "그날로 떠나요" → 시대 카드 중 하나를 고르거나, 날짜를 직접 입력한다.
2. 시대 페이지: 한 문단 설명, 연표(사건 8~10개), 그 기간 코스피 흐름, 대표 기사.
3. 사건을 누르면 그날 페이지로 이동. 날짜 입력은 그날 페이지로 바로 간다(기존 되감기 연출 유지).
4. 그날 페이지 위에서 전날·다음날, 같은 시대의 다음 사건으로 계속 이동한다.

## 5. 데이터와 검증 원칙

과거에 이 기능이 "그날의 역사적 사건"을 위키피디아·스크래핑으로 채우다 상당수가 지어낸 내용이어서 삭제한 이력이 있다. 그래서 다음을 지킨다.

- 사건 하나에 서로 다른 출처 2개 이상. 날짜가 출처마다 다르면 그대로 표기하고 "표현 차이"를 메모한다.
- 시대 설명은 AI가 쓰더라도 검증된 사건 목록과 근거에서만 만든다. 목록에 없는 사실을 추가하지 않는다.
- 사건 후보는 서울경제 기사량이 급증한 날로 자동 추천하고, 사람이 출처로 확정한다.
- 각 사건에 `근거(출처 URL·문장)`를 데이터로 저장한다. 화면에도 출처를 노출한다.
- 사건일과 보도일이 다르다. 신문은 사건 다음 날 아침에 나온다(예: 11월 21일 밤 발표는 11월 22일 지면). 사건 카드는 "사건일"과 "관련 지면 날짜(보통 +1일)"를 둘 다 가진다.

## 6. 조사 결과 — 데이터 한계 (2026-10-04 실측)

서울경제 아카이브(빅카인즈 연동, 현재 `/time-machine`)를 1990~2001년 월별로 평일 표본 조사했다.

1. 공백: 1998년 1~8월 전체가 0건이다(1998-01-02·01-05·01-07·02-10·03-10·04-10·05-12·06-15~19·07-10·08-12 모두 0건, 1998-08-29 이후 재개). IMF 위기 한복판이다. 1990·1992·1994·1997·2000년의 일부 달도 표본에서 부분적으로 비었다. 단일 날짜 0건이 휴일인지 연동 누락인지는 구분하지 못했다.
2. 상한: 하루 최대 30건이고 중요도 순이 아니라 소스 순서다. 1997-12-03(협상 타결일)·12-04의 상위 30건에는 IMF 관련 기사가 없었다. 시대의 핵심 기사를 보여주려면 날짜 단위 조회가 아니라 키워드+기간 검색이 필요하다(백엔드 신규).
3. 공백 원인(빅카인즈 쪽 미적재인지 provider 표기 차이인지)은 확인하지 못했다. 빅카인즈에서 직접 조회해 확인해야 한다.

대응: 공백 구간은 숨기지 않고 "이 기간은 아카이브 연동이 비어 있어요"라고 화면에 밝히고, 연표·설명·코스피 흐름(별도 데이터)으로 시대 이야기를 이어간다.

## 8. 화면 (초안)

시대 허브 `/timeline`
- 시대 카드 목록(IMF 외환위기, 닷컴 버블, 카드 대란, 글로벌 금융위기, 유럽 재정위기, 코로나 쇼크, 금리 급등기 등 10개 안팎. 목록 확정은 미결정)
- 날짜 직접 입력(생일·기념일)

시대 페이지 `/timeline/era/{slug}`
- 제목·기간·한 문단 설명(근거 표기)
- 연표: 사건 카드 8~10개(사건일, 한 줄 설명, 출처, 그날 보기)
- 그 기간 코스피 흐름
- 대표 기사(키워드 검색 기반)
- 데이터 공백이 있으면 안내

그날 페이지 `/timeline/{날짜}` (현재)
- 날짜 제목, 전날·다음날, 같은 시대 사건 이동
- 기사 목록(최근·과거 같은 행), 분야 탭
- 과거는 "그날 이걸 샀다면" 투자 카드

## 9. 지표와 가설

지표(심어야 한다, 지금은 없음): 시대 카드 클릭률, 시대 페이지 체류 시간, 사건 → 그날 이동률, 그날 페이지에서 원문 클릭률, 날짜 직접 입력 횟수, 공유 횟수.

가설(반증 가능)
- H1: 시대 허브가 있으면 날짜 직접 입력보다 시대 카드 클릭이 더 많다(입구가 "날짜"가 아니라 "사건"이므로). 반증: 출시 후 4주간 직접 입력이 카드 클릭의 1/2 이상이면 날짜 입력이 주 입구이므로 구조를 다시 본다.
- H2: "IMF 외환위기 연표" 같은 시대 페이지가 검색·AI 검색 유입을 만든다. 반증: 6주 안에 시대 페이지 색인·노출이 없으면 제목·구조화 데이터를 점검한다. 위험: 위키·나무위키가 이미 상위를 차지해 서울경제 기사 링크만으로는 이기기 어렵다.
- H3: 사건 카드에서 그날 페이지로 이동하는 비율이 30% 이상이다. 반증: 이하이면 사건 카드가 정보 소비로 끝나므로 카드 안에 대표 기사를 직접 보여준다.
- 위험: 데이터 공백(1998년 전반)이 대표 시대에 걸려 있어 이야기가 끊긴다. 완화: 공백을 밝히고 연표·지표로 메운다. 빅카인즈 미적재라면 다른 소스(서울경제 자체 아카이브)를 확인한다.

## 10. 단계

1. 기획 확정(이 문서) — 시대 목록, 이름, 근거 정책 승인
2. IMF 시대 한 개를 끝까지 만든다(데이터 + 시대 페이지) — 구조가 맞는지 확인하는 샘플
3. 키워드+기간 검색 백엔드(빅카인즈 `query`), 공백 원인 확인
4. 시대 10개 안팎으로 확장, 홈·`/timeline` 허브 연결, 지표 수집
5. (후속) 시대 설명의 AI 보조, 시대별 웹툰·영상 형식 연결

## 11. 미결정

- 시대 목록 확정(최종 10개 안팎)과 우선순위
- 시대 데이터 저장 위치: 코드 내 정적 JSON vs CMS(어드민). CMS 쪽이 "CMS에서만 제어" 원칙에 맞지만 초기에는 정적 JSON이 빠르다.
- 1998년 공백 원인 확인 방법(빅카인즈 직접 조회, 담당자 문의)
- 시대 설명 문안 작성 주체(편집팀 검수 필요 여부)

## 12. v0.2 변경 (2026-10-04)

- 방향 확정: 1990년부터 지금까지 연대기로 쌓고, 사건 기간에 나온 기사를 같이 본다. 이름은 "그날로 떠나요" 유지.
- 구조: 연대(1990s~2020s) 페이지 `/timeline/decade/{연대}`, 시대(사건 3개 이상 묶음) 페이지 `/timeline/era/{slug}`, 그날 페이지 `/timeline/{날짜}`. 홈 칩은 연대별 대표 사건 5개.
- 데이터: 연대별 병렬 조사(4건) 결과 사건 85개 중 출처 2개 이상 확정 79개(1990s 19, 2000s 21, 2010s 21, 2020s 18), 확인 필요 6개(`docs/product/time-machine-events/PENDING.md`). 원본 JSON(사건마다 출처 URL과 원문 인용)은 `docs/product/time-machine-events/`, 화면용 TS는 `scripts/build-timeline-events.py`로 생성. 화면에는 확정 사건만, 작업 메모(note)는 노출하지 않는다.
