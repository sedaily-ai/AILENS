# AI LENS 기획 · 화면설계 문서

영문 사이트(EN Daily ver2) 문서(`마스터DB/04_기획·요구사항/화면설계`)와 같은 형식을 따른다. AI LENS와 섞이지 않도록 번호는 화면 `AL-`, 정책결정 `LD-`를 쓴다.

## 규칙
- 파일명: `YYMMDD_문서명_vX.Y.html`. 새 버전은 새 파일로 만들고 이전 버전은 `_이전버전/`으로 옮긴다(삭제하지 않는다).
- 확인된 사실만 적는다. 미확정 사항은 정책결정사항의 LD-번호로 관리한다.
- 캡처는 `assets/`에 둔다. 이전 | 이후 사진은 `BA_*`.
- 생성: `docs/worklog/…`에 기록한 변경 내용을 근거로 쓴다. 이 폴더의 HTML은 손으로 고치지 말고 새 버전을 만든다.
