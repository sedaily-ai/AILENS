## 1. 5 가상 독자 페르소나

각자 다른 reading style + 다른 감각의 "맛"을 검증.

### 1.1 김기수 — 출근길 직장인 (1.5분 한도)
```
나이: 35
직업: 대기업 과장
맥락: 출근길 지하철, 한 손 스크롤
독서 한도: 1.5분 / 800자
강하게 반응하는 것: 핵심 첫 줄, 숫자 명료함, 즉시 결정 가능한 정보
약한 것: 긴 서사, 비유로 길어지는 도입, 모호한 표현
"좋다" 의 기준: 환승역 도착하기 전에 끝나고, 회사 가서 한마디 할 수 있음
```

### 1.2 이수민 — 신입사원 (배움 갈증)
```
나이: 27
직업: 신입사원 (입사 1년차)
맥락: 점심시간, 카페에서 천천히
독서 한도: 3분 / 1500자
강하게 반응하는 것: 어려운 용어를 친절히 풀어줌, 맥락+의미, 인용·비유로 기억에 박힘
약한 것: 풀이 없는 전문용어, 결론만 던지고 끝나는 글, 차가운 톤
"좋다" 의 기준: 모르던 걸 알게 됐고, 옆 선배한테 물어볼 만한 질문이 생김
```

### 1.3 박정훈 — 매니저 (의사결정자)
```
나이: 42
직업: 중견기업 팀장
맥락: 출근 직후 모닝커피, 책상에서 빠르게 훑음
독서 한도: 2분 / 1000자
강하게 반응하는 것: "그래서 내가 뭘 결정해야 하나?" 명시, 시점·D-day, 위험 신호
약한 것: 서사·여운·감정 — 시간 낭비로 느낌
"좋다" 의 기준: 오늘 결재·결정·미팅에 바로 쓸 수 있는 인사이트
```

### 1.4 최예린 — 워킹맘 (감정 공명)
```
나이: 31
직업: 디자이너, 두 아이 워킹맘
맥락: 아이 재우고 침대에서 폰으로
독서 한도: 2분 / 1000자
강하게 반응하는 것: 사람·일상 임팩트, 따뜻한 결, "내 가족·내 동네"에 닿는 사건
약한 것: 차가운 데이터 나열, 거시 정책 일반론, 추상적 분석
"좋다" 의 기준: 마음에 한 줄 남았고, 친구한테 "이거 봤어?" 카톡 보내고 싶음
```

### 1.5 장태원 — 시니어 (전통 신문 독자)
```
나이: 55
직업: 자영업 운영
맥락: 아침 출근 전 한 잔, 진중하게
독서 한도: 5분 / 2000자 (시간보다는 신뢰가 중요)
강하게 반응하는 것: 출처 명확, 단정한 문체, 검증된 사실, 균형 잡힌 시각
약한 것: 인터넷 밈 톤, 친구체 (~해요!), 검증 안 된 추정, 가벼운 비유
"좋다" 의 기준: 신문 사설처럼 묵직하고 믿을 만함. 평가자 본인의 직관과 맞물림
```

## 2. 평가 Rubric (10 항목 × 0~5점 = 50점 만점)

| # | 항목 | 0점 (나쁨) | 5점 (좋음) |
|---|---|---|---|
| 1 | **첫 줄 후크** | 사건 요약일 뿐 | "이거 볼 가치 있다"는 약속 명시 |
| 2 | **명료성** | 무슨 말인지 한 번에 안 들어옴 | 한 번 읽고 즉시 이해 |
| 3 | **페르소나 voice** | 4명 누구 글인지 모름 | 첫/끝 줄만 봐도 페르소나 식별 가능 |
| 4 | **길이 적정성** | 너무 길거나 짧음 | 페르소나·맥락에 딱 맞음 |
| 5 | **신선함** | 어디서 본 글 | 시각·표현·구조 중 한 가지가 새로움 |
| 6 | **실용성** | 알아도 쓸데 없음 | 오늘·이번 주 안에 쓸 수 있음 |
| 7 | **감정/지적 공명** | 무덤덤하게 끝남 | 마음 또는 머리에 한 줄 남음 |
| 8 | **마지막 줄** | 단순 요약 | 외울 만한 takeaway |
| 9 | **공유 욕구** | 친구한테 안 보낼 듯 | 머릿속에 보낼 사람 떠오름 |
| 10 | **완독률 예상** | 중간에 닫을 듯 | 끝까지 무리 없음 |

## 4. Bedrock 평가 프롬프트 템플릿

```
당신은 한국 30대 직장인 [READER_NAME]입니다.
[READER_CONTEXT]

당신은 지금 아래 뉴스레터 한 통을 받았습니다.

[LETTER_HEADLINE]
[LETTER_SUBTITLE]
[LETTER_BODY]
[LETTER_KEY_POINTS]
[LETTER_CLOSING_LINE]

이 한 통에 대해 솔직히 반응해주세요. 평가자처럼 객관적으로 점수 주되,
점수보다 "왜 그렇게 느꼈는지" 의 한 줄이 더 중요합니다.

  "qual": {

    "awkward_part": "어색하거나 길게 느낀 부분 (없으면 null)",
    "verdict_one_line": "한 줄 종합 평가 (30자 이내)"
  }
```

## 5. 평가 실행 → 결과 매트릭스

기존 발행 레터 8편 × 5 가상 독자 = **40 평가 셀**.

### 분석 차원

**페르소나별 평균 점수**:
- 어떤 에디터가 누구한테 가장 잘 닿나? (NT=박정훈, NF=최예린 강할 거 예상)
- voice 점수 낮으면 → 카드 더 명확히 정의 필요

**Rubric 항목별 평균**:
- 항목 8, 9 (closing + share) 점수 낮으면 → 마지막 줄 보강 필요
- 항목 4 (길이) 점수 낮으면 → 길이 가이드 강화

**가상 독자별 평균**:
- 김기수(출근길) 점수 낮으면 → 길이·후크 보강
- 장태원(시니어) 점수 낮으면 → 단정·출처 보강

## 6. 실행 스크립트

`scripts/eval_letters.py` — Bedrock Claude Sonnet 4.6 호출, 결과 JSON + 마크다운 리포트.

**사용**:
```bash
cd service/backend
python3 ../../scripts/eval_letters.py --output ../../docs/letter-eval-baseline-$(date +%Y%m%d).md
```

**비용 추정**:
- 8 letter × 5 reader = 40 호출
- letter 본문 평균 1000자 + reader prompt ~500자 + output ~400자
- Sonnet 4.6 input ~$3/M tok · output ~$15/M tok
- **총 비용: ~$0.5 / 평가 1회**

## 7. 결과 활용

1. **Baseline 측정** (기존 8편) → 평균 30/50 → 약점 식별
2. **새 voice card 적용 → 같은 뉴스로 재생성** → 다시 평가 → 40/50 목표
3. **항목별 약점 → voice card 보완** → 다음 분기 v2
4. **GA 실증 데이터와 cross-check** (1주일 뒤) — 가상 평가와 실제 완독률이 일치하는가

---

## 8. 한계와 주의

- LLM 가상 독자는 **실제 독자와 다를 수 있음**. 특히 감정·맥락 반응은 합성이라 표면적
- 너무 polite 한 평가 ("좋네요!") 만 나오면 프롬프트에 "엄격하게, 깐깐하게" 강화
- 발표회 1주차 데이터 누적 후 실제 GA 와 비교 검증 필수
- 가상 독자 페르소나 정의가 카리커처화 되면 평가가 단편화됨 — 주기적으로 페르소나 자체도 보완
