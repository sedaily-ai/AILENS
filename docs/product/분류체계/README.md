# AI LENS 분류 체계 개편

작성: 문영광 + Claude Code (2026-10-09)
관련: 영문 사이트 카테고리 체계 `1_ai_link/globe/ver2/마스터DB/04_기획·요구사항/화면설계/260929_카테고리체계_v0.4.html`, 코드 정본 `service/frontend/src/shared/constants/menuTaxonomy.ts`

## 1. 문제

- 증시와 시그널이 같은 하위 분류(국내증시·해외증시·IB&Deal 등)를 써서 겹침
- 글 2,560건 중 637건(25%)이 분류가 없음. 정치·사회·경제 기사가 여기에 섞여 있음(제목 키워드로 거칠게 센 값: 정치 약 114, 사회 약 99, 경제 약 79, 나머지는 기존 분류에 넣을 수 있는데 파이프라인이 안 붙인 것으로 보임)
- 분류 정의가 프론트(`econCategories.ts`·`econSubcategories.ts`), 파이프라인(`CATEGORY_MAP`·`SUBCATEGORY_MAP`), admin 세 곳에 복제돼 있음
- 하위 분류가 비어 있는 글이 많음(증시 348건, 산업 389건 등)

## 2. 결정(2026-10-09)

- 대분류 8개: 시그널 · 부동산 · 경제 · 금융 · 산업 · 정치 · 국제 · 문화
  - 영문 사이트의 마켓시그널·부동산(집슐랭)·경제·금융·기업·정치·국제·문화에 대응. 이름은 일반 이름으로 씀
  - 증시와 시그널은 하나로 합침
  - 사회·스포츠·오피니언은 두지 않음(스포츠 약 8건, 오피니언 해당 글 없음, 사회는 이번에 제외)
- 하위 분류는 영문 메뉴를 그대로 옮기지 않고, 지금 AI LENS에 글이 한 건이라도 있는 것만 둠
  - 문화: 전시·공연·영화·미디어·출판·아트씽은 글이 없어 제외, 문화일반·여행·레저만
  - 금융: 영문의 '금융'은 글에 '가상자산'으로 저장돼 있어 데이터 이름을 씀
- 경제·정치는 지금 분류 값이 없어 메뉴에는 아직 보이지 않음(planned). 재분류 뒤 글이 있는 하위 분류만 채워서 켬

## 4. 단계

| 단계 | 내용 | 상태 |
|---|---|---|
| 1. 메뉴 | 헤더 돋보기로 여는 전체 메뉴(대분류·하위 분류·검색)를 분류표 한 파일(`menuTaxonomy.ts`)에서 그림. 페이지가 있는 분류만 보임 | 구현(로컬), 배포 전 |
| 2. 새 글부터 | 파이프라인이 경제·정치를 붙여 발행, 프론트에 `/economy`·`/politics` 페이지 추가, 헤더 탭을 분류표에서 그림, 시그널 통합(`/signal` → `/markets` 영구 이동) | 미착수 |
| 3. 기존 글 | 분류 없음 637건 등을 재분류. 시험 실행(dry-run)으로 변경 목록을 검토한 뒤 적용, 바뀐 글은 옛 주소에서 308 이동 | 미착수 |
| 4. 검색 반영 | 사이트맵 재제출, 색인 보고서의 리디렉션·색인 추이를 2~4주 관찰 | 미착수 |

주소 원칙: 기존 분류의 주소(`/markets`, `/property`, `/finance`, `/industry`, `/international`, `/culture`)는 이름만 바꾸고 유지해 색인된 주소를 흔들지 않음. 새 주소는 `/economy`, `/politics`만 추가.

## 5. 가설(반증 가능, 2단계 이후 측정)

- H1: 재분류 후 분류 없음 비율이 25%에서 5% 이하로 줄어든다(정치·경제 분류 추가와 기존 분류 누락 보정). 5% 초과면 재분류 규칙을 다시 본다.
- H2: 재분류로 바뀐 글의 옛 주소 308 이동 후 4주 안에 Search Console의 "리디렉션이 포함된 페이지"가 늘되 색인된 페이지 수는 줄지 않는다. 줄면 이동 대상을 다시 점검한다.
- 위험: 분류가 바뀌는 글이 많으면 색인된 주소가 한꺼번에 이동한다. 단계 3은 한 번에 적용하지 않고 분류별로 나눠 적용한다.

## 6. 미정·확인할 것

- 하위 분류를 메뉴에 보이는 최소 글 수(제안: 5건 이상, 지금은 한 건이라도 있으면 보임)
- 사회를 나중에 대분류로 추가할지(분류 없음 글의 약 15%로 추정)
- 분류 없음 글 중 2026-08-09자 `test3` 테스트 글이 공개 상태. 삭제 여부 확인 필요
- 분류 정의 복제 3곳(프론트·파이프라인·admin)을 한 곳으로 모으는 방법(단계 2에서 결정)

## 7. 이번 작업의 한계

- 분류별 글 수는 제목·요약 기반 검색용 목록(2,560건)으로 센 값이며, 정치·사회·경제 건수는 키워드 추정이라 정확하지 않음
- 헤더 탭은 아직 옛 분류(증시·시그널 별도)를 그대로 씀. 전체 메뉴(시그널로 통합)와 이름이 다른 상태가 단계 2까지 이어짐
