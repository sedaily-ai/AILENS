사람이 손으로 고친 것 — 원본 그대로 두면 다음에 헷갈릴 수 있어 명시한다:

   빠져 있어 Remotion 쪽 zod 스키마 검증에서 떨어졌다 — 추가해서 고침.
2. 아이콘 키(`lucide-bread`, `lucide-car`, `lucide-event` 등)가 실제 Remotion
   프로젝트의 아이콘 화이트리스트(`src/components/Icon.tsx`)에 없어 전부
   물음표(HelpCircle)로 렌더될 뻔했다 — `croissant`/`car`/`map-pin`으로
   교체하고, 해당 3개를 Icon.tsx 화이트리스트에 추가했다(lucide-react에 실제
   존재하는 아이콘인지 확인 후 추가). 이 코드 변경은 dev2 저장소가 아니라
   별도 로컬 Remotion 프로젝트(`콘텐츠/프로젝트/ailens/video`)에 있다 — 그
   폴더는 홈 디렉터리 전체가 git 루트로 잡혀 있어(`git rev-parse
   --show-toplevel` → `/Users/yeong-gwang`) 여기서 커밋하지 않았다. 별도 확인
   필요.
3. 전환 브릿지("그런데", "~도")와 비교 수치 기준값 제시를 프롬프트가 시킨
   대로 일부는 GPT가 알아서 잘 넣었고(컷2→3), 일부는 사람이 손으로 보강했다
   (컷6→7 "5개 도시 중 가장 적게 늘어난 서울도" — GPT 원본은 그냥 "서울의
   숙소 검색량도 11% 증가"로 밋밋했음).
