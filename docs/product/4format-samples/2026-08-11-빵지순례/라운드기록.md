## 라운드 1 (2026-08-19~20)

**프롬프트 버전**: letters v1→v2(v2에서 분량 강제 문구 추가), webtoon v1→v2(v2에서
"맞장구만 하는 대사 금지" 자가점검 추가), podcast v1→v2(v2에서 "여러분" 금지
자가점검 추가), video v1(안 건드림)

**한 것**
- 4개 프롬프트로 텍스트 초안 생성 → 문제 발견 → 프롬프트 수정 → 재생성, 1회 반복
- 웹툰: 스크립트(1단계) → 장면연출(2단계) → 실제 이미지 8컷(3단계, GPT 이미지)까지
  실물 생성
- 팟캐스트: 대본 → AWS Polly(한국어 Seoyeon, generative)로 실제 mp3 생성
- 영상: 별도 세션에서 만든 Remotion 렌더(`cli-horizontal.mp4`, 16:9)를 그대로 재사용
- 4개 산출물 전부 CMS에 실제 발행 — 위 링크에서 4개 탭 다 확인 가능

**읽어본 소감(사용자 관점)**

| 포맷 | 소감 |
|---|---|
| 레터 | 내용은 괜찮은데 분량이 목표(2000~2800자)보다 한참 짧다(1000자 안팎). 프롬프트에 분량 강제 문구를 넣어도 안 지켜짐 — 미해결 |
| 웹툰 | v2에서 대사 톤이 나아짐("맞장구만" 문제 개선). 다만 이미지 자체에 실존 브랜드명("성심당")이 배경 간판에 그대로 렌더됨 — 상표 노출 문제 |
| 팟캐스트 | "여러분" 금지 규칙 적용 후 확실히 고쳐짐. 다만 수치 개수 제한(3개 이하)은 여전히 초과하는 경향 |
| 영상 | 텍스트(각본) 생성까지는 확인 안 함 — 이번 라운드는 별도로 만들어둔 렌더를 그대로 붙이는 데만 썼음 |

**디자인 관련(별도 트랙, 이번 라운드에서 손 안 댐)**
- 웹툰 탭: 실제 이미지 있으면 그냥 세로로 쌓아서 보여줌. 캐러셀·스와이프 같은 인터랙션 없음
- 영상·팟캐스트 탭: 실제 링크 있으면 raw `<video>`/`<audio>` 태그로만 재생. 챕터 리스트 등 다른 정보와 조합 안 함
- 상단 "이 뉴스, 누구의 눈으로 볼까요?" 선택 UI 문구가 여전히 "누가"를 묻는데, 실제로 고르는 건 "어떤 형식"이라 프레이밍이 어긋나 있음

**다음 라운드에서 손볼 것**
- 레터 분량 — `max_tokens` 상향 또는 few-shot 예시로 재시도
- 웹툰 이미지 — 실존 상호명이 안 나오게 프롬프트에 배경 상호를 일반명사로 바꾸라는 지시 추가, 혹은 발행 전 육안 검수를 표준 절차화
- 팟캐스트 — 수치 3개 이하 규칙 재점검(자가점검 문구를 "여러분"처럼 명시적으로 강화)
