## 한 것

- 장면 변환기 `doc_plan.py` 신규: PRISM 장면 JSON → 다큐 틀 장면 계획. 숫자는 JSON 값만 씀. 쇼츠용 컷 선택(`build_shorts`, 약 50초 이내, 도입 훅 + 숫자 컷 + 마무리), 마무리 화면에 AI 제작 고지.
- `prism_batch.py`: `PRISM_LAYOUT`(기본 `doc`, `classic`이면 기존 틀). 쇼츠는 롱폼을 끼우던 `shorts_compose` 대신 세로 틀로 따로 렌더. 변환 실패 시 기존 틀로 자동 전환.
- `render_from_script.py`: `plan`·`composition`·`out_name` 인자 추가(인자 없으면 기존 동작 그대로).
- `scripts/render-lambda.ts`: `--plan`/`--composition`, 다큐 틀은 별도 사이트(`ailens-video-lab-doc`)에서 렌더, 컷 시작 시각 `*.timing.json` 기록. 컷 길이 계산은 `src/doc/timing.ts`로 분리.
- 막대 장면(`BarsScene`): 단위·소수점 표시. 기존에는 값이 모두 `+정수%`로 나왔음(2.5조 원이 `+3%`로 표시되던 오류).
- 설명글: `seo_description.py` 신규(마케팅팀 템플릿 프롬프트 그대로 + 입력 5칸 자동 채움). 롱폼은 챕터(`youtube_upload.chapters_from_timing`), 투자 그룹(SG4·SG6·SG8)은 투자 고지. 검사(입력에 없는 숫자·URL, 필수 문단, 한국어 원제목과 영어 제목 대조)에 걸리면 `youtube_upload.v2_description`으로 대체.
- 배포(운영 이미지 위에 바뀐 파일만 얹는 방식):
  - 24번 `video-lab-doc-20261118` → 25번 `…b`(막대 단위) → 26번 `…c`(설명글). 각각 23번 설정 복사 + 이미지·`PRISM_LAYOUT=doc`.
  - 롤백 기준점: 23번 이미지 `video-lab-amountfix-20261110` (`sha256:5d2285f72dc1d6f50840194fff701d75f7d684bd948bfc1a994b6b38bb5f1691`).
  - 되돌리기: `PRISM_LAYOUT=classic`으로 새 리비전을 등록하거나 23번 이미지로 새 리비전 등록.
  - Remotion 사이트 `ailens-video-lab-doc` 신규 배포(기존 `ailens-video-lab`과 분리). 화면 코드를 바꾸면 `npx remotion lambda sites create src/index.ts --site-name=ailens-video-lab-doc --region=us-east-1`를 다시 실행.

## 결정

- 설명글은 마케팅팀 SEO·GEO 템플릿(오늘 자동 버전)을 적용. 기존 자동 버전·모건스탠리 편과 8개 항목을 비교해 7개 충족·1개 부분 충족, 원문 링크 포함, 자동 적용 가능이 근거.
- `public/doc/`의 사진(`hike.jpg`, `jennie.jpg`)은 저장소에 넣지 않음. 연합뉴스 캡션 사진이고 사용 권한 확인 전. 자동 PRISM 렌더는 사진 장면을 쓰지 않아 영향 없음. 수작업 v2 3편을 다시 렌더할 때만 로컬에 두 파일이 필요.
- 쇼츠는 롱폼에서 컷을 골라 따로 렌더(롱폼이 3분을 넘으면 쇼츠로 분류되지 않는 문제를 구조적으로 피함).
