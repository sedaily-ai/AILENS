# 2026-11-23 PRISM 기사 사진 썸네일 — 유튜브 thumbnails.set 자동 업로드

작성: 문영광 (+ Claude Code)
관련: 브랜치 `feat/prism-photo-thumbnail`, `pipelines/video/prism_batch.py`·`youtube_upload.py`·`shorts_thumbnail.py`·`article_photo.py`

## 배경

- `@en.sedaily` 유튜브 썸네일이 영상 중간 프레임(한국어 지면 캡처·차트)으로 자동 추출돼 조회수가 0~2회에 머물렀다.
- 요청: **기사 자체에 실린 서울경제 보도사진**을 배경으로, 영문 제목을 얹은 커스텀 썸네일을 만들어 자동으로 달기.
- `shorts_thumbnail.py`에 `make_wide()`(1280x720)·`make_wide_from_url()`이 이미 있었지만 아무도 부르지 않았고, `youtube_upload.py`에는 `thumbnails.set` 호출이 없었다.

## 한 것

- **기사 txt에 사진 주소 싣기** — `pipelines/video/prism_auto.py::_article_block()`이 기사 머리줄에 `사진: <주소>`를 넣는다(XML `<image href>` → `photo_url`). 사진이 없는 기사는 줄이 없다. 지면 편(`prism_paper.py`)은 같은 함수를 쓰므로 PG1~PG4도 자동으로 실린다.
  - 마케팅팀이 손으로 만든 txt·2026-11-23 이전 파일에는 이 줄이 없어도 그대로 동작한다(하위 호환).
  - `prism_auto.py`는 admin Lambda zip에 flat 복사되므로(다른 모듈 import 불가) 줄 모양을 이 파일 안에서 만든다.
- **`pipelines/video/article_photo.py` 신규** — `photo_urls()`·`primary_photo_url()`·`strip_photo_lines()`. 대본 AI·금액/날짜 검수에는 이 줄을 빼고 넘긴다(주소 속 숫자가 검수에 섞이지 않게).
- **`youtube_upload.set_thumbnail(video_id, thumb_path, creds)` 신규** — `https://www.googleapis.com/upload/youtube/v3/thumbnails/set?videoId=…&uploadType=media`에 JPEG/PNG를 POST(기존 urllib 스타일). 2MB 상한·빈 파일은 올리기 전에 거부, HTTP 오류는 본문을 담은 RuntimeError.
- **`prism_batch.py` 연동** — 롱폼 업로드 성공(`video_id` 확보) 뒤 사진이 있으면 `make_wide_from_url()` → `set_thumbnail()`. 쇼츠도 업로드 성공 뒤 `make_from_url()`(1080x1920)로 같은 방식.
  - 상태: `youtube_thumbnail` = `photo` | `none`, 실패는 `youtube_thumbnail_error`(+ 쇼츠는 `youtube_shorts_thumbnail`, `youtube_shorts_thumbnail_error`).
  - 썸네일 생성·업로드가 실패해도 **영상 업로드는 실패 처리하지 않는다** — 경고 로그와 위 상태만 남기고 편은 `done`.
- **`shorts_thumbnail.py` 가로 썸네일 디자인 손질**(첫 렌더 확인 뒤)
  - 사진을 화면 가득(cover, 가운데 크롭) 깔고 오른쪽에 그라데이션을 얹는 방식으로 바꿨다. 예전에는 사진을 높이에 맞추고 남는 자리를 흐린 배경으로 채워 사진·배경 경계선이 눈에 보였다.
  - 그림자는 drawbox 띠 대신 `geq` 알파로 매끄럽게(띠 경계·밴딩 없음). 제목 자리에서 약 35%, 오른쪽 끝 90%.
  - 제목 크기를 사다리로 고른다(`WIDE_TITLE_LADDER`: 64px·15자·5줄 → 58px·17자·6줄 → 52px·19자·6줄). 64px에서 "…Shutdown"이 잘리던 75자 제목이 58px에서 5줄로 다 들어간다.
- **`admin/backend/routes/prism_batch.py`** — `GET /admin/prism-batch/{batch_id}` 응답에 `youtube_thumbnail`, `youtube_thumbnail_error` 추가(화면 없이도 어느 편이 사진 썸네일로 나갔는지 보이게).

## 시험

- 단위 테스트(모두 통과): `pipelines/video` 62개(신규 `test_article_photo` 6·`test_youtube_thumbnail` 4·`test_prism_batch_thumbnail` 6·`test_prism_auto_photo` 3 포함), `pipelines/common` 69개, `admin/backend/tests/test_prism_batch_get.py`+`test_prism_schedule.py` 27개.
  - `prism_batch` 연동: 사진이 있으면 그림→업로드 순서로 불리는지, 사진 주소가 대본 프롬프트에 안 들어가는지, 썸네일이 403으로 실패해도 `stage=done`·`youtube_thumbnail_error`만 남는지, 사진이 없으면 `none`인지, 쇼츠까지 세로 썸네일이 붙는지.
- 실제 ffmpeg 렌더 확인(`make_wide`): 서울경제 기사 사진(11/23 삼성 시안팹, 640x427 PNG)으로 1280x720을 만들어 보니 2배 확대인데도 육안으로 읽힌다. 4:3·세로(900x1440)·거의 흰 배경에서도 제목 가독성과 크롭 확인. 1280x720 JPEG 60~250KB(2MB 상한 여유).
  - 기사 사진이 640px대면 1280x720으로 2배 확대된다. XML `image href`가 더 큰 원본을 가리키는지는 확인하지 못했다(daily-xml은 AWS 접근 필요).

## 결정

- **사진 전달은 기사 txt 머리줄로** — CMS 화면·manifest·ECS 인자에 새 필드를 늘리지 않아도 되고, 자동 제작(prism_auto·prism_paper)이 이미 txt를 만들어 S3에 넣는 경로를 그대로 쓴다. 손으로 올린 txt도 같은 줄만 넣으면 동작한다.
- **썸네일 실패는 영상 실패가 아니다** — 채널에 맞춤 썸네일 권한이 없으면 403이 오고, 그때는 유튜브가 중간 프레임을 쓴다. 영상을 다시 올리면 중복 업로드가 되므로 편은 완료로 둔다.
- **가로 썸네일은 cover 크롭** — 예전 "높이 맞춤 + 흐린 배경"은 지면 사진처럼 보이지 않았다. 1.25배 확대 상한(`WIDE_MAX_UPSCALE`)은 없어졌고, 대신 원본이 작아도 크롭만 하므로 질감 손실이 적다.
- 쇼츠(1080x1920) 틀은 이번에 바꾸지 않았다 — 이미 동작하고, 이번 요청의 핵심은 롱폼 썸네일이었다.
