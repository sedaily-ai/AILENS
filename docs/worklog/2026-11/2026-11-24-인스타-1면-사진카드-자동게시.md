## 배경

인스타그램 카드뉴스 자동화 추진 정리(2026-11-24)의 1단계. 서울경제 국문 채널은 카드뉴스 사이트
(AX-CONTENTS-LAB)에서 사진 1장 + 헤드라인 이미지를 만들고 캡션과 함께 사람이 손으로 올린다.
이 형식을 자동으로 만들어 올리는 것을 `@lens.sedaily`에서 먼저 시험한다.

## 한 것

  Bedrock Sonnet 5(사진 첨부)로 제목 2줄·자를 위치·캡션 → Pillow 1080×1350 → S3 → 그래프 API 단일 이미지 게시 → SNS(Slack).

  Bedrock 앱 프로필 `lens-instagram-single-sonnet-5`, EventBridge `cron(0 0,3,6,9 * * ? *)` + 리소스 정책 `events-4x`(추가 후 get-policy로 확인).
- 11:21 수동 실행으로 첫 게시(엔비디아 CEO 복귀), 12:01 첫 자동 실행 게시(삼성 시안 공장) 확인.

## 결정

- 기사는 1면 배치 순서대로 1회 1건, 하루 4건. 웹툰과 같은 기사가 겹치지만 시험 채널이라 그대로 둔다.
- 꾸밈(인물 누끼·말풍선·스티커)은 넣지 않는 기본형. 실제 인물 사진을 AI로 합성·변형하지 않는다.
- 단체 사진 오인(제목 "강금실"인데 가운데 홍익표만 남음) → 원문 figcaption의 "왼쪽부터" 순서로 자를 위치를 정한다.
- 제목은 국문 채널 썸네일 말투(인용·물음표·ㄷㄷ 허용)로 하되, 줄이다 뜻이 바뀌는 표현은 금지("첫 여성"→"65년 만의 여성" 등).
- 미리보기 기간 없이 첫날부터 실게시(요청). 대신 배포 직후 `dry_run` 1회로 동작만 확인했다.
- 실패 기사는 `{날짜}_failed`로 건너뛰어 같은 기사로 4번 다 막히지 않게 했다.
