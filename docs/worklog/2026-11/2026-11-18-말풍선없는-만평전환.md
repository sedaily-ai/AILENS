# 2026-11-18 말풍선 없는 8컷 만평 전환

관련: 브랜치 `feat/webtoon-editorial-cartoon`, 기준 `origin/main` (`dad17632`),
`docs/superpowers/specs/2026-11-18-webtoon-editorial-cartoon-design.md`

## 배경

말풍선이 그림을 가리는 문제를 해결하기 위해 사용자가 말풍선 제거와 만평 화풍을 요청했다.
여러 컷 유지와 그림 아래 설명을 선택하고 설계를 승인했으며, 이후 CMS·자동 발행 배포와 PR 생성을 요청했다.

## 한 것

- 공통 각본 계약에 8컷 만평·기사 근거·한국어 narration·빈 dialogue를 명시했다. 저장된 옛 말풍선 지시보다 새 제작 규칙을 우선한다.
- 이미지 프롬프트와 negative_prompt에서 말풍선·생각풍선·빈 말풍선·이미지 속 글자를 금지한다. 공급자 길이 제한에도 만평 규칙이 남는다.
- `compose_text.compose()`는 그림을 가리지 않고 배율만 조정한다. 관리자 생성·재합성에도 적용하며 얼굴 인식 호출을 제거했다.
- `external_caption()`으로 새 설명과 옛 대사를 보존한다. 새 생성 성공분은 모든 공급자 경로에서 textcaption 표시 파일을 남기며, resume으로 건너뛴 기존 이미지는 그대로 둔다.
- 공개 API가 `text_caption`을 잃던 문제를 수정했다. 기존 `admin_extra`에서 URL 기준으로 복원하고 응답까지 보존하므로 DB 변경은 없다.
- CMS의 말풍선 설정 UI를 제거하고 컷 카드·미리보기에 외부 설명을 표시한다. 생성 당시 caption을 채팅 메시지에 저장·복원해 이후 각본과 섞이지 않게 했다.
- 미리보기를 body portal로 옮겨 고정 테스트 헤더가 그림 위로 겹치는 현상을 수정했다.
- 신규 태스크 정의의 비용 규칙에 맞게 `frontpage_auto/tags-ecs.json`의 Service를 lens로 수정했다.
- 원격 main의 최신 보안 업데이트와 영상 변경을 보존하도록 `dad17632` 기준으로 작업 브랜치를 만들고 의존성을 동기화했다.

### 검증

- 파이프라인·공통 계약·번들·관리자: `python -m pytest pipelines/common/test_webtoon_contract.py pipelines/common/test_admin_bundle.py pipelines/webtoon/test_compose_text.py pipelines/webtoon/test_pipeline_retry.py admin/backend/tests -q` → **254 passed**.
- 공개 API: `python -m pytest service/lens-cms-api/tests -q` → **152 passed, 71 skipped**. DB 통합 실행에 필요한 연결 정보가 없어 건너뛰었다.
- 변경 Python 파일 pyflakes, CMS `tsc --noEmit`·변경 TS/TSX ESLint·Next 16.4.6 build 통과. 합성 원본 보존 검사는 수정 전 2건 실패·수정 후 통과를 확인했다.
- 임시 Python 3.14 환경에서 최신 main의 관리자 보안 의존성과 운영 고정 FastAPI 0.115.6을 사용했다. 합성 JWT 키 경고와 Python 3.14 사용 중단 예정 API 경고는 테스트 환경에 한정된다.
- 실제 배포 Docker 이미지(Python 3.11)를 네트워크 없이 실행해 원본 바이트 보존·옛 설명 추출·긴 프롬프트 규칙 보존을 검사했다. 이미지 안 핵심 Python 소스 6개의 SHA-256이 로컬과 일치한다.
- Browser 플러그인이 없어 Playwright로 로컬 정적 export를 검사했다. HTTP·WebSocket·이미지는 fixture를 사용했다. 각본 B가 최신이어도 A 이미지의 생성 당시 설명이 복원되고, PC 920px·모바일 미리보기 390px에서 설명이 이미지 아래에 있음을 확인했다. 최종 페이지 오류·콘솔 오류 0건, body portal z-index 60, 배경 헤더 겹침 없음.
- 화면 증거: `/private/tmp/lens-webtoon-caption-desktop.png`, `/private/tmp/lens-webtoon-caption-mobile.png`.
- 독립 읽기 전용 통합 리뷰에서 설명 저장·복원 누락 P2 1건을 발견해 수정했다. 수정 및 portal 변경 재검토 후 추가 확정 결함은 없었다. 독립 리뷰는 코드 검토이며 브라우저 검사를 독립 실행한 것으로 표현하지 않는다.

## 결정

- 사용자는 별도로 설정 변경·프롬프트 재발행을 할 필요가 없다. CMS 새 생성과 다음 자동 발행부터 적용한다.
- 기존 게시물 일괄 재생성·이미지 교체·유료 추론은 실행하지 않았다. 실제 이미지 모델의 만평 화풍·금지 지시 준수는 이번 실행에서 미검증이다.
- 최초 운영 배포와 별도 자동 발행 배포는 자동 승인 검토가 명시적 승인을 요구해 보류됐으나, 사용자에게 각각 승인을 받은 뒤 배포했다.
- PR 요청에 필요한 커밋·push·PR 생성까지만 진행하며 리뷰어 지정·자동 병합·병합은 수행하지 않는다.
