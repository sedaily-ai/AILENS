# 서울경제 1면 원본 데이터 연결

## 배경
서울경제에서 받은 1990~2026년 1면 CSV를 날짜별 사진·기사 현황과 타임머신 화면에 반영한다. 같은 날짜의 기존 네이버·빅카인즈 목록보다 서울경제 제공 자료를 우선한다.

## 한 것
- 원본 CSV 37개를 읽어 100,977개 행, 11,570개 발행일, 442개 월별 JSON 파일로 변환하는 `timemachine-data/build/build_sedaily_archive.py`를 추가했다. ID·발행일·제목·부제목·본문을 보존하고 원본 CSV는 수정하지 않는다.
- 프런트엔드가 `/timemachine-newspaper/index/v2/YYYY/MM.json`을 읽고, 해당 날짜가 CSV에 있으면 서울경제 원본을 우선 표시하게 했다. 기사 ID에서 BigKinds 상세 링크를 구성한다. 사진은 기존 날짜 경로에서 별도로 읽는다.
- 날짜 현황 카드도 사진 연도 현황과 CSV 월 파일을 병렬로 확인해, 1면 기사 보유 표시를 빅카인즈 조회 완료 전에 내도록 했다.
- 변환 데이터 132,738,126바이트(약 126.6 MiB)를 기존 S3 버킷에 442개 파일로 올렸다. 버킷 태그를 다시 읽어 `Service=lens`를 확인했다. 공개 경로 `https://ailens.sedaily.ai/timemachine-newspaper/index/v2/1991/01.json`은 HTTP 200, 404,807바이트다.
- BigKinds 백필과 기존 캐시 색인의 시작 기준을 CSV 마지막 발행일 다음 날인 2026-11-01로 옮겼다. S3 진행 포인터 두 개도 조건부 갱신하고 일일 Lambda를 배포해 `State=Active`, `LastUpdateStatus=Successful`을 확인했다. 시간별 EventBridge는 계속 ENABLED다.
- 사진 목록과 CSV 날짜 대조에서 발행일 중 사진 없는 1,243일을 확인했다: 1991~1993년 1,060일, 1998년 6~12월 182일, 2006-04-15 하루.
- 프런트엔드 `npx tsc --noEmit`, `npm run build`, `git diff --check` 통과. 빌드는 완료했으나 빌드 중 외부 API DNS 오류 경고가 있어 일부 정적 뉴스 데이터는 네트워크에서 가져오지 못했다.

## 결정
- 원본 CSV 전체를 기준 자료로 유지한다. 월별 서비스 데이터는 요청한 달에 한해 전송한다.
- CSV에 날짜가 있고 제목이 있는 기사 행은 기존 기사 소스보다 우선한다. 날짜가 월 파일에 없거나 요청에 실패하면 기존 경로로 되돌아간다.
- 600일 캐시 색인은 BigKinds API를 새로 호출하지 않고 기존 DynamoDB 캐시를 S3 현황에 반영한다. 새 기준일 이후만 순회하고 최신 날짜에 도달하면 새 날짜가 생길 때까지 대기한다.
- 작업 브랜치는 `feat/timemachine-newspaper-availability`다. 타임머신 일일 Lambda와 S3 데이터 게시를 먼저 적용했다. 프런트엔드 운영 배포는 운영 런북에 따라 변경이 `main`에 반영된 뒤 진행한다.
