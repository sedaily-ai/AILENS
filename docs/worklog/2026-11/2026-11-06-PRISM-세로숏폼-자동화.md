## 배경

PRISM은 가로(1920x1080) 롱폼만 만든다. 서울경제 유튜브 채널의 쇼츠는 본사 뉴스팀이 사람이 편집하는 한국어
뉴스 쇼츠이고, PRISM(영문 AI 영상)의 세로 숏폼은 아직 없다. 승찬의 목표는 PRISM을 세로 숏폼으로도
자동 제작하는 것이다. 영상 디자인은 일단 접어두고 자동화 뼈대부터 만들었다.

코드로 확인한 현재 상태:

- 렌더 엔진은 세로(1080x1920)를 지원하지만 **PRISM은 `compositionFor`에서 `format`을 버리고 무조건
  `AiPrismHorizontal`로 보냈다.** `prism-settings`의 FORMAT을 `vertical`로 바꿔도 가로가 나온다.
- PRISM 장면(`theme.ts`의 `W=1920, H=1080` 고정, `scenes.tsx` 좌표)은 실제 캔버스 크기를 읽지 않는다.
  세로 컴포지션만 등록하면 오른쪽 840px이 잘린 영상이 나온다.
- 업계는 가로(롱폼)와 세로(숏폼)를 별개 네이티브로 둘 다 만든다. 가로를 세로로 리프레임하면 쇼츠로
  제대로 분류되지 않고 노출이 떨어진다.
- NYT·서경 쇼츠는 실제 취재 영상이 주인공이고 자막이 거든다. PRISM은 취재 영상이 없는 AI 그래픽이라
  이 구조를 그대로 따라 할 수 없다.

## 한 것

- `schema.ts`, `Root.tsx` — `PRISM_COMPOSITION_ID`를 가로/세로 객체로 바꾸고 세로 컴포지션
  `AiPrismVertical`(1080x1920) 등록. `compositionFor`가 PRISM도 `format`을 따른다.
- `render_from_script.py` — `render_and_upload`에 `output_basename`·`s3_suffix` 추가. 기본값은 기존 가로 동작 그대로.
- `prism_batch.py` — 가로 렌더 뒤 세로 렌더 1회 추가(`media/video-lab/{job_id}_vertical.mp4`,
  `status.vertical_key`). 세로 렌더가 실패해도 가로·편 완료에는 영향 없음.
- `youtube_upload.py`, `prism_batch.py` — 세로 mp4를 `#Shorts` 제목·설명으로 유튜브에 업로드(`shorts_metadata`).
- `prism_notify.py` — 슬랙 완료 알림에 쇼츠 링크·실패 표시(시도한 편만).
- `test_prism_notify.py` — 테스트 3개 추가. 알림·날짜·숫자 검수 테스트 21개 통과.
- 세로 3단 레이아웃 시안과 NYT·서경 쇼츠 분석(기획 문서에 반영).

## 결정

- **세로 렌더와 쇼츠 업로드는 둘 다 기본 꺼짐.** `PRISM_RENDER_VERTICAL=1`, `PRISM_UPLOAD_VERTICAL=1`을 줘야 켜진다.
  처음엔 렌더를 기본 켜짐으로 넣었다가 되돌렸다. 지금 세로는 오른쪽이 잘려 쓸 수 없는데, 켜 두면 Lambda 렌더가
  2배가 되고, 세로 렌더가 가로 유튜브 업로드보다 먼저 돌아 가로 공개가 렌더 시간(약 1~2분)만큼 늦어진다.
- 뼈대(렌더·업로드 경로)와 디자인(장면 세로 대응)을 분리했다. 뼈대는 디자인과 독립이라 먼저 만들어도 헛수고가 아니다.
- 쇼츠는 유튜브만 넣었다. 데일리모션 세로는 기획에서 정하지 않았다. 스포티파이는 팟캐스트라 숏폼과 무관.

## 켤 때 할 일 (순서대로)

1. **Remotion 사이트 번들 재배포.** `AiPrismVertical`은 새 컴포지션이라 영상 서버 이미지 배포만으로는 안 들어간다.
   번들(`ailens-video-lab`)은 저장소에 배포 스크립트가 없고 사람이 올린다(`docs/ops/운영-런북.md`).
   10/30 이후 `pipelines/video/src` 변경이 없어 다시 올려도 달라지는 건 이번 변경뿐이고, 같은 사이트 이름이면
   `SERVE_URL`을 고칠 필요가 없다. 사이트와 이미지 배포 순서는 상관없다.
   ```bash
   cd pipelines/video
   npm ci
   npx tsc --noEmit        # PR #221 때 못 돌린 타입 체크
   npx remotion lambda sites create src/index.ts --site-name=ailens-video-lab --region=us-east-1
   ```
2. 영상 서버 이미지 배포 (`frontpage_auto/deploy.sh`).
3. **세로 렌더를 가로 유튜브·데일리모션 업로드 뒤로 옮긴다.** 지금 순서(가로 렌더 → 세로 렌더 → 업로드)는 켜면 가로 공개가 늦어진다.
4. `PRISM_RENDER_VERTICAL=1`로 한 편 시험 렌더(업로드는 꺼 둔 채). 환경변수는 ECS 태스크 정의에 넣으므로 새 리비전이 필요하다.
5. 세로 장면 디자인이 끝나면 `PRISM_UPLOAD_VERTICAL=1`.

## 안 한 것 / 미확인

- `tsc` 타입 체크 미실행(로컬 node_modules 없음). 실제 세로 렌더·쇼츠 업로드도 한 번도 돌리지 않았다.

- 세로 렌더 비용은 측정한 적이 없다. 렌더 횟수가 2배라는 것만 확실하다.
