# 2026-11-06 PRISM 세로 숏폼 자동화 — 기획 초안(plan)

작성: 승찬 + Claude Code
상태: **기획 초안** — 코드 미착수. 결정 필요 항목은 아래 "결정할 것"에 미정으로 표시.
관련: `pipelines/video/`(렌더·업로드), `prism_batch.py`(제작 본체), `src/prism/`(장면 디자인),
`src/lib/schema.ts`(포맷 정의), `pipelines/common/video_settings.py`(발행 설정)

## 배경

승찬님 역할 "콘텐츠 유형·숏폼 자동화", 목표 "숏폼 자동 제작". 현재 PRISM(서울경제 영문 기사 →
AI 영상 → 유튜브·데일리모션 공개)은 **가로(1920×1080) 롱폼만** 자동 생산한다(2026-11-06 실제
자동제작 영상 `prism-20261106-1005-...-07.mp4` 해상도 1920×1080로 확인). 세로(9:16) 숏폼은 아직 없다.

서울경제 유튜브 채널에 쇼츠가 올라오고 있으나, 그것은 **본사 뉴스팀의 한국어 일반 뉴스 쇼츠**
(사람이 편집, 실제 취재 영상 기반)로 PRISM과 별개 라인이다. 따라서 PRISM 숏폼은 **신규 작업**이다.

## 조사로 확정된 사실

- **렌더 엔진은 세로 지원** — `schema.ts` `FORMAT_DIMENSIONS.vertical = 1080×1920`, `render.ts`·
  `render-lambda.ts` `--format vertical`. `layout.ts`에 `useIsVertical()`·`useScale()`(짧은 변 기준)도 있다.
- **그러나 PRISM 장면은 가로 하드코딩** — `src/prism/theme.ts`가 `W=1920, H=1080` 상수를 고정으로 쓰고,
  `scenes.tsx`의 모든 좌표(`TOP=130`, `W-2*MARGIN`, split 패널 640, 좌우 2스탯 등)가 이 가로 크기 기준이다.
  `--format vertical`로 렌더해도 가로 레이아웃이 세로 캔버스에 억지로 들어가 깨진다(글자 넘침·빈 공간·잘림 추정).
- **발행 포맷 기본값이 `horizontal`** — `video_settings._DEFAULT_FORMAT`. `prism_batch`는 편당 `render_and_upload`를
  1회만 호출하므로 지금은 가로 1편만 나온다.
- **업계 관행: 가로·세로는 별개 포맷, 둘 다 네이티브 제작.** 가로를 세로로 리프레임하면 쇼츠 알고리즘이
  제대로 분류 못 해 노출이 떨어진다(여러 2024~2026 자료 공통). 신문사들은 젊은 독자용으로 세로 숏폼을
  소셜 우선으로 적극 생산하는 추세.
- 스포티파이는 팟캐스트(오디오, 별개 파이프라인)라 숏폼(세로 영상)과 무관.

## 세로 레이아웃 방향 — 한국어 쇼츠 분석에서

서울경제 한국어 쇼츠의 세로 구성을 참고(단, PRISM은 실제 취재 영상이 없고 AI 그래픽이라 그대로는 못 씀):

- **상단**: 큰 2줄 제목 + 핵심어 하이라이트 박스 — 소리 없이 스크롤하는 시청자용 필수.
- **중앙**: PRISM 그래픽(종이 질감·아이콘·큰 숫자). 세로에선 좌우로 펼치던 걸 **위아래로 쌓아** 큼직하게.
- **하단**: 영문 나레이션 자막 띠.
- **아웃트로**: "Full story at Seoul Economic Daily" 류 영문 유도 — 영문사이트 유입(서비스 목적과 일치).

→ 핵심: PRISM 가로 장면은 좌우 분할(split 패널, 2스탯) 구조라, **세로에선 상하 분할로 재배치**해야 한다.

## 결정할 것

1. **숏폼 제작 방식** — (A) 롱폼과 같은 대본을 세로 레이아웃으로 / (B) 숏폼 전용 짧은 대본(30초, 핵심 1개).
   업계는 B 선호하나 A가 자동화 비용이 쌈. **1차 추천: A로 시작, 뒤에 B 확장.** → 미정
2. **올릴 채널** — 유튜브 쇼츠 / 데일리모션(이미 업로드 코드 있는 2곳). 인스타·틱톡은 법·계약 장벽(이전 조사). → 1차 추천: 유튜브 쇼츠 + 데일리모션
3. **생성 범위** — 하루 전체 그룹(SG1~8 등) 세로도? 일부만? → 미정
4. **가로+세로 동시** vs 세로만 — 1차 추천: 가로 유지 + 세로 추가(편당 렌더 2회) → 미정
5. **길이** — 쇼츠 보통 30~60초. 현재 PRISM 가로 영상 길이 확인 필요. → 미정
6. **디자인 통일 여부** — 세로를 PRISM 가로 디자인과 통일 / 숏폼용 새로. → 1차 추천: 통일(브랜드 일관)

## 작업 순서(결정 후)

1. 세로 렌더 샘플 1편 실제 제작 → 깨지는 지점 눈으로 확인(승찬님 화면 검증).
2. `src/prism/` 장면을 세로 네이티브 대응 — 고정 `W/H` 대신 `useVideoConfig()` 사용, `useIsVertical()`로 상하 재배치.
3. `prism_batch.py`가 가로+세로 둘 다 생성(편당 렌더 2회), 업로드 분기(유튜브 롱폼=가로 / 쇼츠=세로).
4. 테스트 + 영상 서버 배포.
