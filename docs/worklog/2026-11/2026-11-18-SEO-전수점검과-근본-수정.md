# 2026-11-18 SEO·GEO 전수 점검과 근본 수정

## 배경
- SEO·GEO 적용 상태 점검 요청. 운영 사이트와 로컬 24개 페이지를 검색 봇 UA로 비교했다. 기본 태그(제목·설명·canonical·h1·구조화 데이터)는 일관돼 있었고, 아래 항목이 어긋나 있었다.

## 결정·남은 것
- `/news` 경로 발생 원인: 분류 LLM이 "판단이 어려우면 null"로 두고 원문 태그 폴백도 실패하면 category가 비어 `lensCategorySlug`가 `news`로 폴백(11월 신규 635건 중 4건). 파이프라인에서 분류를 강제할지는 편집 정책 결정 사항이라 미적용.
- `/games`는 서버 HTML 글자가 약 250자로 얇음. 게임 규칙은 번들 JS 안에 있어 코드만으로 정확한 설명을 쓸 수 없음 → 규칙 확인 후 소개 문구 추가 필요.
- `pageShareMeta`는 타임라인에만 적용. 이미 이미지가 있는 기존 13개 파일은 그대로(필요 시 점진 이전).
- `/words/page/{n}`은 내부 링크로만 발견됨. 사이트맵에는 미포함.
- 검증은 로컬 응답·스크린샷만 수행. tsc·eslint·build는 사용자 요청으로 생략. 운영 반영 전 필요.

## 추가 반영 (같은 날)
- 분류 강제: `pipelines/common/taxonomy.py` `classify_article`이 AI(null 허용) → AI(null 금지) → 원문 태그 → 제목 부서명 → `경제` 순으로 항상 대분류를 채운다. 기존 `/news/...` 4건은 주소 변경 이슈로 미처리.
- 사이트맵 core에 `/words/page/2~17` 추가, `/lens`·`/words`·`/timeline` lastmod 갱신.
- `llms.txt`의 용어·타임라인 설명을 실제 구조(페이지 분할, 연대·시대 연표)에 맞게 갱신.
- `/timeline` 입구에 CollectionPage(ItemList) JSON-LD 추가(`timeline/hubJsonLd.ts`, 하위 페이지에는 중복 없음).
- 남은 SEO 과제: 네이버 서치어드바이저 소유확인(코드값 필요), 기사 작성자에 기자 이름 반영 검토, `/games` 소개 문구(게임 규칙 필요).
