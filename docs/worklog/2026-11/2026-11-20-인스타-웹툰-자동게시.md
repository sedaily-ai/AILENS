# 2026-11-20 1면 웹툰 인스타그램 자동 게시

작성: Claude Code
관련: 브랜치 `feat/instagram-webtoon-auto`, Lambda `sedaily-lens-instagram-webtoon`, `pipelines/instagram_auto/`

## 배경

서울경제 콘텐츠 AX 기획(2026-11-19)의 Instagram 확장 단계. 웹툰은 AI LENS 사이트에만 있었고
인스타 `@lens.sedaily`에는 영수증·카드뉴스만 올라갔다. 기사 1건의 웹툰 8컷에 표지·마무리를 붙여
10장 캐러셀로 정해진 시각에 자동 게시하고, 결과를 Slack으로 받는 것이 요청.

## 한 것

- Meta 개발자 앱 `LENS Webtoon Publisher` 생성, 비즈니스 포트폴리오 "서울경제 LENS" 신설,
  `@lens.sedaily`를 Instagram 테스터로 연결, 통합 로그인 구성으로 시스템 사용자 토큰(만료 없음) 발급.
- `pipelines/instagram_auto/lambda_function.py`: 공개 API에서 오늘 1면 → 표지(Pillow 합성)+8컷+마무리
  JPEG → S3 `media/instagram/` → 그래프 API 캐러셀 게시 → SNS(Slack). 미리보기(`dry_run`)·`only` 지원.
- AWS(태그 `Service=lens`, `Workload=instagram-webtoon`): Lambda, IAM 역할(최소 권한), SSM SecureString 토큰,
  EventBridge 규칙 `cron(0 23 * * ? *)`. 게시 기록은 비공개 키 `instagram/posted.json`.
- 11/20 1면 3번 기사(한덕수 파기환송)를 시험 게시 → 표지 제목이 프로필 격자에서 잘려 삭제 후
  가운데 정렬 표지로 재게시. Lambda는 dry_run으로 4건 처리 확인(이미 게시한 1건 건너뜀).
- `config/resources.env`에 `INSTAGRAM_*` 이름 추가, `pipelines/README.md` 표에 한 줄 추가.

## 결정

- 대상은 1면 기사(하루 4~5건, 편집국 배치 그대로). 08:00에 1분 간격으로 연달아 게시.
- 이미지 크기는 웹툰 컷과 같은 1824×1490 — 캐러셀 안에서 한 장도 잘리지 않게. 대신 프로필 격자(3:4)용으로
  표지 글자를 가운데 안전 영역에 둔다.
- Slack은 새 앱 설치 한도 때문에 기존 `ailens-ops-alerts` 토픽(→ `#03_lens-alarm`)을 재사용. AWS 쪽 변경 없음.
- Pillow는 레이어 대신 Linux 휠을 zip에 동봉(ECR·Docker 빌드 불필요).
- 처음엔 담당자 PC 작업 스케줄러로 돌렸다가, PC에 의존하면 안 된다는 판단으로 같은 날 Lambda로 옮겼다.
- Facebook 로그인 방식(페이지 연결 필요)은 버리고 통합 로그인을 썼다 — lens.sedaily가 페이스북 페이지와 연결돼 있지 않다.
