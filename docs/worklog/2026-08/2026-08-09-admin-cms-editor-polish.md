# 2026-08-09 관리자 CMS 글쓰기 화면 개선 + 용어 해설 채널

작성: Claude Code
관련: admin/frontend, service/frontend

## 배경

새 글 쓰기 에디터(이미지 편집, 헤더, 미리보기)를 다듬고, "단어장"(레터
키워드 모음)을 정식 콘텐츠 분류로 승격해달라는 요청을 반영했다.

## 한 것

- 이미지 편집: 이미지 옆 컨텍스트 툴바(정렬·교체·삭제) + 이미지 바로 아래
  항상 보이는 캡션 입력창(alt, placeholder "사진 설명을 입력하세요").
  발행 화면(`PostPreviewModal.tsx`, `LetterDetailClient.tsx`)에서만 표시
  시점에 `<figure>+<figcaption>`으로 감싸 보여준다 — 저장되는 HTML은
  `<img alt="...">` 그대로라 에디터 재로딩 시 안전.
- `posts/edit` 헤더 재구성: 로고+뒤로가기(호버 툴팁), 상태 배지를 제목 옆
  왼쪽으로, 저장→발행/내리기만 우측에 색 있는 버튼으로 남기고 미리보기·
  사이트에서 보기·삭제는 아이콘 버튼으로. "발행 보기"→"사이트에서 보기".
- "미리보기" 모달 신규(`PostPreviewModal.tsx`) — 저장 전 상태를 독자 화면에
  가깝게 확인.
- flushSync 콘솔 에러 수정(이미지 로드 시 `setContent`를 microtask로 지연).
- **"용어 해설" 채널 추가** — 오늘의 이슈/머니 트렌드/깊은 이야기와 같은
  방식(`body_inline.section`)의 4번째 분류. `types.ts`, `PostMode.tsx`
  분류 드롭다운, `posts/page.tsx` 채널 필터·일괄 이동에 반영. 기존에
  "액면분할"/"보통주vs우선주"/"레버리지·인버스 ETF" 키워드를 담고 있던
  레터 3개를 이 채널로 이동(관리자가 직접 일괄 이동 UI로 수행).
- 공개 사이트 "단어장" 표기를 "용어 해설"로 변경 — `/words` 페이지 제목,
  레터 하단 링크, `about` 페이지, 홈 미리보기 섹션, 공지 배너.
- 채널 필터를 표 헤더에서 날짜 필터 옆(툴바)으로 이동 — "표에 두지 말고
  밖으로" 요청. 표는 이제 항상 4열(채널 열 제거).

## 결정

- "용어 해설"은 레터 키워드를 자동 집계하는 별도 화면이 아니라, 기존
  레터 글을 그대로 분류만 바꿔 관리하는 방식으로 결정 — 새 데이터 모델
  없이 기존 분류(section) 메커니즘 재사용.
- 이미지 캡션은 저장 HTML 구조를 바꾸지 않고 표시 시점에만 감싼다 —
  Tiptap 스키마에 없는 `<figcaption>`을 저장 HTML에 직접 넣으면 재로딩 시
  ProseMirror가 텍스트를 별도 문단으로 잘못 흡수할 위험이 있어 피했다.
