# 레터 소제목(◾) 파싱 누락 → "■" 오표시 수정 (2026-09-24)

## 문제 발견

- 발행된 레터에서 "◾"로 시작해야 할 소제목이 "■"로 깨져 나온다는 제보

## 문제 정의

- `pipelines/common/publish_utils.py::parse_letters()`가 "◾"로 시작하는 줄을 소제목으로 인식하지 못하고 조용히 걸러냄
- 걸러진 자리를 다른 렌더 경로가 "■"로 대체 표시 — 파싱 실패가 표시 오류로 전이된 것

## 왜 그렇게 했는지

- 별도 우회 렌더 처리 대신 파싱 규칙 자체에 "◾" 시작 줄을 독립 문단(소제목)으로 인식하는 조건을 추가하는 근본 수정을 선택

## 어떻게 달라졌는지

| | 이전 | 이후 |
|---|---|---|
| "◾" 시작 줄 | 소제목 미인식 → 다른 경로가 "■"로 대체 렌더 | 소제목으로 정상 파싱·렌더 |

- 프론트 3곳(`LensFormatPanel.tsx`/`LensViewClient.tsx`/`LetterStoryCards.tsx`) 소제목 시각 구분 렌더 반영
- curl로 lens-cms-api 응답 직접 대조 검증 후 배포(frontpage_auto ECS 이미지 + service/frontend) 완료
