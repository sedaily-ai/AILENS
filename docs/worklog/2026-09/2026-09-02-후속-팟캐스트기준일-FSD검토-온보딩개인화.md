## 한 것

- **팟캐스트 기준일 표기**(기자 피드백 Step 2 일부) — DDB
  `PROMPT#podcast/published` v3→v4. `[오프닝]` 섹션에 facts.json 날짜를
  자연스럽게 한 번 언급하도록 지시 추가("O월 O일 기준으로" 등), 이 언급은
  "수치 3개 제한"에서 제외한다고 명시. 코드 변경 불필요(팟캐스트는 구조화
  파싱 없이 전체를 TTS로 넘김) — 프롬프트만으로 다음 실행부터 반영.

  **Before/After**: 기존 `[오프닝]` 지침은 "같은 뉴스, 네 가지 시선.
  AILENS입니다."로 끝 — 언제 기준 정보인지 청취자가 알 방법이 없었다.
  변경 후 지침:
  > 이어서 오늘 이야기의 기준 시점을 자연스럽게 한 번 짚어준다 —
  > "O월 O일 기준으로", "오늘 새벽 발표된" 처럼 facts.json의 날짜를
  > 말로 풀어 언급한다.
  다음 실행부터 팟캐스트 도입부에 "9월 1일 기준으로..." 같은 문장이
  자연스럽게 섞여 나오게 된다(구어체 유지, 숫자처럼 딱딱하게 안 읽음).
- **영상 기준일 표기는 이번에 안 함** — 화면 자막으로 띄워야 해서
  `pipelines/video/`의 스크립트 스키마 + Remotion 렌더 컴포넌트까지 건드려야
  함(프롬프트만으로 불가), 오늘 스코프보다 커서 별도 라운드로 미룸.
- **FSD 경계 정리 검토** — `ConsumeStep.tsx`(features/onboarding)가
  `LensFormatPanel`(app 레이어)을 직접 import하는 문제를 `shared/ui/`
  이전으로 고치려 했으나, `LensFormatPanel`이 이미
  `widgets/SentenceSelectionPopover`에 의존하고 있어(shared→widgets 역방향
  위반이 새로 생김) 단순 이동이 안 됨을 확인. `SentenceSelectionPopover`
  자체도 `entities/user`(인증)에 의존해 shared로 재분류도 안 됨. **손 안
  댐** — 기능엔 지장 없는 lint 경고 하나로 남겨둠, 제대로 고치려면
  SentenceSelectionPopover의 인증 의존성을 props로 주입하도록 먼저
  분리해야 함(별도 작업).
- **온보딩 관심분야 실제 반영** — 지금까지 `format`/`interests`는 저장만
  되고 아무 데도 안 쓰이고 있었음. `LensPreviewSection`(홈 "오늘의 이슈"
  지면 탭)의 기본 활성 탭을 온보딩에서 고른 관심분야로 맞춤 — `SECTIONS`의
  `paperSection`이 온보딩 `InterestStep`과 완전히 같은 taxonomy(전체/증권/
  산업/시그널)라 매핑 없이 바로 매칭.
  - 이 작업 중 `onboardingStorage.ts`를 `features/onboarding/lib` →
    `shared/lib`로 이동 — `features/news-feed`가 `features/onboarding`을
    직접 import하면 feature 간 lateral import 금지 규칙에 걸림. 이
    파일은 React·온보딩 도메인 로직이 없는 순수 localStorage 유틸이라
    shared로 내리는 데 문제없었음.
