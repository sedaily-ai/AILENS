## 한 것

### 1. 레터 프롬프트 v4 → v5 (DDB `PROMPT#letters/published`)
기자가 제안한 "5문단·1500~2000자 두괄식" 전면 재구성은 레터의 기존 설계
의도("4포맷 중 사실 커버리지를 가장 넓게 책임지는 2000~2800자 분석형",
소제목 5~7개)와 상충한다고 판단, 사용자 확인 후 **기존 구조를 유지하면서
지적받은 두 가지만 타겟팅 보강**:
- `[리드]`: 원문에 결론/전망을 압축한 직접 인용문이 있으면 그걸로 여는 것을
  우선 고려하도록 지침 추가.
- `◾ 사실 확인` 소제목: 시제(날짜·출처)를 문장 안에 반드시 명시하는 규칙 +
  ✗/✓ 예시 추가.
- 체크리스트에 시제 확인 항목 추가.
- 파서(`_parse_letters()`, mustknow_auto/frontpage_auto 양쪽) 변경 불필요 —
  기존 마크다운 섹션 마크업 그대로, 지침 텍스트만 보강.
- 부수 발견: 파일시스템 폴백 사본(`service/backend/prompts/letters/published.md`)이
  v3 수준으로 낡아있던 것도 이번에 같이 v5로 동기화(`909bace`).

### 2. 부제목 줄바꿈 재검증
오늘 아침 이미 고친 메타디스크립션 `<br/>` 버그(`4ef509a`)와 근본 원인이
같아 별도 코드 수정 불필요. 오늘(2026-09-03) 발행된 실제 기사 10건을 CMS
API로 직접 조회해 subtitle이 정상 표시되는지 확인 — 전부 정상, 문제 없음.

### 3. 팟캐스트 "AI 음성 조교" 정체성 — 조사 후 현행 유지로 결정
대본(프롬프트) 쪽은 이미 아주 명확하게 "친근함" 정체성이 잡혀있었다("여러분"
절대 금지, 구어체, 화자의 개인적 반응 포함) — 오늘 실제 발행분 대본으로도
확인. 실제 목소리(Polly `Seoyeon`/generative 엔진, 2026-08-27 비용 이유로
채택 — ElevenLabs 대비 82% 절감)엔 SSML 프로소디 커스터마이징이 전혀 없고,
`DEFAULT_VOICE_STYLE`(`config/constants.py`, `desc: '전문적이고 차분한'`) 설정값은
어디서도 실제로 쓰이지 않는 죽은 코드였다는 것도 확인.

오늘 실제 발행된 에피소드 샘플(`media/podcast/mustknow-auto/20086701-podcast.mp3`)
링크를 사용자에게 전달해 직접 청취 판단을 요청 — **사용자 결정: "Polly로는
어렵다, 성우 목소리가 기본이 이렇다, 그대로 간다"**. SSML rate/pitch 튜닝
등 추가 작업 없이 현행(Seoyeon/generative, 스타일링 없음) 그대로 유지하기로
확정.
