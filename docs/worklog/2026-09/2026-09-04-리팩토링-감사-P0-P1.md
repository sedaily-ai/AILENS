### 1. `frontpage_auto`에 웹툰 실패 격리 이식
`mustknow_auto/run.py`는 2026-08-24에 웹툰 생성 실패 시 이미 성공한
레터·팟캐스트까지 통째로 버려지던 실제 장애를 겪고 try/except로 격리
수정을 넣었는데, `frontpage_auto/run.py`(같은 코드 경로)는 그 수정을
못 받아 잠재적으로 같은 장애에 노출돼 있었다. 그대로 이식.

### 2. 뉴스레터 구독 이중 구현 통합
`handlers/subscribe.py`(`/api/v2/subscribe`, unsubscribe 있음)와
`handlers/newsletter/subscribe.py`(`/api/newsletter/subscribe`,
unsubscribe 없음, `format`/`interests`/`letter` 캡처 있음)가 완전히
독립적으로 같은 테이블에 upsert하던 걸 발견 — 테이블명 환경변수 이름도
서로 달라(`SUBSCRIBERS_TABLE` vs `NEWSLETTER_SUBSCRIBERS_TABLE`) 운영
위험이 있었다. 사용자 확인 후 `subscribe.py`로 통합:
- `format`/`interests`/`letter`(구독 시점 화면의 특정 레터 즉시 발송)를
  이식 — 재구독 시 값이 없으면 기존 저장분을 보존하도록 주의.
- `admin/backend/routes/newsletter.py`의 환경변수도 `SUBSCRIBERS_TABLE`로
  통일.
- `handlers/newsletter/subscribe.py` 삭제, `deploy.sh`의
  `sedaily-mbti-newsletter-subscribe-dev` 항목 제거(배포된 Lambda·API
  Gateway 라우트 자체는 안 지움 — AWS 자원 삭제는 범위 밖).
- 프런트 `NewsletterEmailField.tsx`를 `/api/v2/subscribe` 호출로 변경.
