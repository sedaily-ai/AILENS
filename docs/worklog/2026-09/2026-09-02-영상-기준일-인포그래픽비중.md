## Before / After (구체적 예시)

**Before** — 영상 첫 화면(OpeningCut)엔 아이콘 + 제목만 있고 이 정보가
언제 기준인지 표시할 방법이 스키마에 아예 없었다. 시청자가 나중에
다시 보면 "이게 최근 얘기인가?" 판단할 수 없음.

**After** — 스키마에 `asOfDate` 추가, 모델이 0단계 공용 팩트시트의
[기준일]을 그대로 채워 첫 컷에 한 줄로 노출:
```json
{ "title": "...", "brand": "...", "asOfDate": "2027년도 예산안 기준", "cuts": [...] }
```
화면에는 제목 아래 작게 "2027년도 예산안 기준" 표시(muted 톤, BrandTag와
같은 절제된 스타일 — 화면을 잠식하지 않으면서도 한 번은 명확히 보임).

**인포그래픽 비중** — Before는 정해진 비율 규칙이 없어 opening/highlight/
closing(텍스트 위주 컷)만 연달아 나올 수 있었다. After는 프롬프트에
"stat·diagram·chart 합이 전체 컷의 최소 절반 이상" 규칙을 명시 — 예를
들어 9컷짜리 영상이면 최소 4~5컷은 숫자·도식·차트로 시각화되게 강제.

## 한 것

- `pipelines/video/src/lib/schema.ts` — `NewsScript`에 `asOfDate`(옵셔널)
  필드 추가.
- `NewsVideo.tsx` → `CutRenderer.tsx` → `OpeningCut.tsx`로 스레딩, 첫
  컷에만 한 번 작게 표시("2027년도 예산안 기준" 등). 모든 컷에 상시
  노출하는 대신 레터/팟캐스트처럼 한 번만 언급하는 원칙과 통일.
- `generate_script.py`는 손 안 댐 — 모델이 만든 JSON 최상위 필드가
  검증·수정 없이 그대로 `script.json`에 통과되는 구조를 확인해서,
  스키마+컴포넌트+프롬프트만 고치면 충분했다.
- 영상 프롬프트(DDB `PROMPT#video/published`):
  - v5 — JSON 스키마에 `asOfDate` 추가, "0단계 facts.json의 [기준일]을
    그대로 쓴다"고 지시 — 같은 날 앞서 만든 공용 팩트시트 기능과 자연스럽게
    연결됨(같은 세션 안에서 두 기능이 맞물리는 걸 확인).
  - v6 — "컷 구성 비율" 섹션 신설: stat/diagram/chart(정보 시각화 컷)
    합이 전체 컷의 최소 절반 이상 되게 지시.
- `npx tsc --noEmit` 클린 확인(Remotion/video 프로젝트).
- 파이프라인 Docker 이미지 재배포(리비전 21).
