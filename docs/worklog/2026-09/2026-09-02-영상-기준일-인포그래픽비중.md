## Before / After (구체적 예시)

**Before** — 영상 첫 화면(OpeningCut)엔 아이콘 + 제목만 있고 이 정보가
언제 기준인지 표시할 방법이 스키마에 아예 없었다. 시청자가 나중에
다시 보면 "이게 최근 얘기인가?" 판단할 수 없음.

**After** — 스키마에 `asOfDate` 추가, 모델이 0단계 공용 팩트시트의
[기준일]을 그대로 채워 첫 컷에 한 줄로 노출:
```json
{ "title": "...", "brand": "...", "asOfDate": "2027년도 예산안 기준", "cuts": [...] }
```
화면에는 제목 아래 작게 "2027년도 예산안 기준" 표시(muted 톤, BrandTag와
같은 절제된 스타일 — 화면을 잠식하지 않으면서도 한 번은 명확히 보임).

**인포그래픽 비중** — Before는 정해진 비율 규칙이 없어 opening/highlight/
closing(텍스트 위주 컷)만 연달아 나올 수 있었다. After는 프롬프트에
"stat·diagram·chart 합이 전체 컷의 최소 절반 이상" 규칙을 명시 — 예를
들어 9컷짜리 영상이면 최소 4~5컷은 숫자·도식·차트로 시각화되게 강제.

### 확인 방법

검증.

### 인포그래픽 비중 — 정상 작동 확인

추출한 프레임에서 diagram(플로우 다이어그램), stat(큰 숫자 카드),
chart(막대그래프) 컷이 골고루 확인됨 — v6 프롬프트의 "stat/diagram/
chart 합이 전체 컷의 최소 절반" 규칙이 실제로 지켜지고 있었다.

### 새 발견 — 기준일 표기에 "기준" 중복

**Before(실제 발행 영상에서 확인)**: 오프닝 컷 하단에
"2025년 7월 2일 오전 거래 기준 (가계부채는 2025년 6월 말 기준) **기준**"
— "기준"이 문장 끝에 겹쳐서 두 번 나옴.

**원인**: DDB `PROMPT#video/published`의 `asOfDate` 예시
(`"2027년도 예산안 기준"`, `"2026.9.1 발표"`)는 애초에 완결된 문구로
설계돼 있었는데, `OpeningCut.tsx`가 렌더링할 때 `{asOfDate} 기준`처럼
항상 " 기준"을 뒤에 하드코딩으로 덧붙이고 있었다 — 프롬프트를 만들
당시(리비전 21) 실제 렌더링 결과를 육안으로 확인 안 하고 넘어가서
발견이 늦어짐.

**After**: `OpeningCut.tsx`에서 `{asOfDate} 기준` → `{asOfDate}`로 수정
— 프롬프트가 아니라 렌더 쪽을 고쳤다(모델이 이미 완결된 문구를 쓰도록
설계돼 있으므로, 프롬프트를 다시 바꾸는 것보다 렌더의 잘못된 덧붙이기를
제거하는 게 근본적으로 맞는 방향).

### 교훈

프롬프트 스키마·지침만 보고 "이렇게 나오겠지"라고 넘겨짚지 않고,
**실제 배포된 최종 산출물(영상 프레임)을 직접 확인**해야 이런 종류의
"두 부품이 각자는 맞는데 합치면 틀린" 버그를 잡을 수 있었다. 웹툰
쪽에서도 같은 패턴(코드 주석엔 이미 원인이 적혀 있었는데 실제 확인 전엔
몰랐던 것)이 반복됐다.
