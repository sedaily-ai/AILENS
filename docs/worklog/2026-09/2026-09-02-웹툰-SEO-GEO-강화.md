# 2026-09-02 웹툰 페이지 SEO/GEO/AEO 강화

작성: Claude Code (사용자 지시 — "검색엔진에 노출되도록", "geo나 aeo가
잘 먹히도록", "리치스니펫도")
관련: 브랜치 `feat/webtoon-seo-geo-enhancement`(머지됨, main `d601422`),
프론트엔드 배포(release `20260902-150046`)

## 배경

사용자가 `/webtoon` 페이지를 보다가 "이건 뉴스를 웹툰으로 만든 신규
콘텐츠라 노출에 유리하지 않을까?"라며 SEO 상태를 물어봄. 감사부터
시작.

## 감사 결과 — 대부분 이미 잘 되어 있었음

기존 세션들에서 이미 상당히 꼼꼼하게 구현돼 있던 것(이번엔 손 안 댐):
- 상세·목록·페이지네이션·시리즈 페이지 전부 `generateMetadata` +
  `alternates.canonical`
- Open Graph + Twitter 카드
- JSON-LD(Article + BreadcrumbList)
- `sitemap.xml`에 웹툰 개별 URL 전부 등록(`priority`/`changeFrequency`)
- Google News 전용 sitemap 별도 운영(최근 2일 발행분)
- `robots.txt` — Google/Bing 같은 전통 검색엔진뿐 아니라 ChatGPT-User/
  PerplexityBot/ClaudeBot/Google-Extended 등 AI 검색·학습 봇까지 명시적
  허용(GEO 대응이 이미 상당 부분 돼 있었음)
- SSR이라 크롤러가 완성된 HTML을 받음(빈 페이지 아님)

## 실제로 고친 빈틈 3곳

### 1. alt 텍스트 — 내용 없는 텍스트였음

**Before**: `alt={`${webtoon.title} 컷 ${i + 1}`}` — "기사제목 컷 1",
"기사제목 컷 2"... 컷마다 똑같은 패턴만 반복, 실제 내용 없음.

**After**: `panel.caption`(이미 API가 컷마다 대사·상황 설명 텍스트를
내려주고 있었고, 화면에도 이미 캡션으로 렌더되고 있었음 — 정작 alt만
이걸 안 쓰고 있었음)으로 교체.

```
alt="A: 포켓몬 팝업인데 4시간 넘게 기다리는 거잖아요. B: 그게 지금 오프라인의 전부예요."
```

이미지 검색·스크린리더 둘 다에 실질적 내용이 전달됨.

### 2. sitemap.xml — 이미지 확장 없음

**Before**: URL만 등록, 페이지 안에 어떤 이미지가 있는지 사이트맵이
전혀 알려주지 않음. 웹툰은 텍스트 기사보다 시각 콘텐츠 비중이 커서
구글 이미지 검색 유입 잠재력이 큰데 그 신호가 없었음.

**After**: Next.js `MetadataRoute.Sitemap`의 `images` 필드(표준 이미지
사이트맵 확장)에 컷 전체 URL을 등록. 실측: 프로덕션 sitemap.xml에
`<image:image>` 태그 **10,816개** 반영 확인(웹툰 전편의 컷 전부).

### 3. JSON-LD — 대표 이미지 1장뿐, 본문 텍스트 없음

**Before**: `Article.image`가 대표 이미지(cover 또는 첫 컷) 1장만.
구조화 데이터만 보면 "이미지 1장짜리 기사"로 보임 — 실제로는 8컷짜리
스토리인데 그 구조가 전혀 안 드러남.

**After**: `associatedMedia`에 컷 전체를 캡션 딸린 `ImageObject` 배열로
추가, `articleBody`에 컷 캡션을 이어붙인 전체 대사 텍스트를 추가.
검색·AI 답변엔진이 실제 스토리 내용을 구조화 데이터 레벨에서 바로
읽을 수 있게 됨. 실측: 프로덕션 페이지 HTML에 `articleBody`,
`associatedMedia` 정상 포함 확인.

## 검증

- `npx tsc --noEmit` 클린
- 로컬 프로덕션 빌드(`npm run build`) 성공, standalone 서버로 sitemap.xml
  실제 출력에서 `<image:image>` 태그 확인
- 배포 후 프로덕션에서 재확인: sitemap 이미지 태그 10,816개, alt 텍스트
  정상, `articleBody`/`associatedMedia` 정상 반영
