# 2026-09-26 웹툰 생성 화면 UX 정리 + 모델 선택 통합

작성: 문영광 + Claude Code
관련: `admin/frontend/src/components/{PromptChatLab/PromptChatLab.tsx,PromptChatLab/ChatThreadSidebar.tsx,WebtoonCutGenerator/WebtoonCutGenerator.tsx}`, `admin/backend/routes/media.py`

## 1. 문제발견
- 웹툰 컷 생성 화면에서 "이 모델을 프로덕션에 적용" 버튼이 컷마다(8개) 각각 떠 있었다.
- 컷 이미지가 생성되면 오른쪽 결과 패널뿐 아니라 왼쪽 채팅 말풍선에도 같이 떴다.
- "다운로드" 버튼을 눌러도 실제 다운로드가 아니라 새 탭이 열렸다.
- 사이드바 대화 목록에 날짜/상대시간이 2줄로 나와 자리를 많이 차지했다.
- 채팅에 처음 들어가면 지금 어떤 프롬프트 버전이 쓰이는지 안 보였다(비-기본 버전을 시험할 때만 배지가 떴다).
- **근거**: 전부 사용자가 화면을 직접 보며 지적("일괄 적용으로 해야지", "실제로 이미지가 다운로드가 되면 좋겠습니다", "너무 자리차지해서", "처음 들어가면... 프로덕션이 기본값이 되도록") — 데이터 기반 아님, 실사용 관찰.

## 2. 문제정의
- 컷 8개가 실제로는 모델 하나를 공유해서 발행되는데, 화면은 컷마다 독립 설정처럼 8번 반복해 "어느 걸 눌러야 하는지" 애매했다.
- 컷 이미지가 채팅 로그와 결과 패널 두 군데에 중복 표시돼 화면이 산만했다.
- 다운로드 버튼은 겉보기엔 있지만 실제 기능이 없어 신뢰를 깎는 상태였다.

## 3. Why
- 웹툰 화면이 팟캐스트/영상 화면과 패턴이 갈라진 채로 방치되면, 사용자가 매번 "이 화면은 또 다르네"를 다시 학습해야 한다 — 지금 정리하지 않으면 다음 기능 추가 때마다 3개 화면이 따로 흘러가 유지보수 비용이 누적된다.

## 4. How
- **모델 선택 카드 단위로 통합**: `WebtoonCutGenerator.tsx`의 `SlotState.model`을 없애고 `TestState.model`(카드 공유값)로 승격. 컷마다 있던 모델 드롭다운 8개 + 적용 버튼 8개를 "이미지 생성 — 컷" 섹션 상단의 드롭다운 1개 + 버튼 1개로 교체. 여러 모델을 비교하고 싶으면 "+ 테스트 추가"로 카드를 하나 더 만드는 방식(팟캐스트/영상의 "카드별 독립 설정"과 동일 원칙).
- **채팅 버블 중복 제거**: `cut_image` 메시지를 `appendMessage`(로컬 messages도 갱신) 대신 `persistArtifact`(서버 저장만, 채팅 버블엔 안 남음)로 바꿨다. `useChatLabThread.ts::mapSavedMessage`가 `null`을 반환할 수 있게 확장해, 텍스트/스토리보드 없는 순수 이미지 메시지는 대화 복원 시 채팅 버블에서 제외되도록 처리.
- **다운로드 실동작화**: S3 버킷 CORS가 GET을 막고 있고 `<a download>`도 cross-origin에선 브라우저가 무시하는 문제라, presigned URL에 `ResponseContentDisposition: attachment`를 실어 보내는 방식으로 교체(`admin/backend/routes/media.py::handle_download_url`, 신규 `GET /admin/media/download-url`).
- **사이드바 날짜 제거**: `ChatThreadSidebar.tsx`의 `formatRelative()`와 날짜 렌더 줄 삭제, 제목만 남김.
- **버전 표시 상시화**: 채팅 상단 배지를 "비-기본 버전일 때만" 조건부에서 "항상"으로 바꾸고, 기본값 텍스트("프로덕션 (아직 발행 전) 사용 중" 등)를 추가. 새 대화 시작/전환 시 `setPromptVersion(null)`로 리셋해 프로덕션이 기본값이 되게 함.
