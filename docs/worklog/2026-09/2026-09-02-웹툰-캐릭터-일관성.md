## 배경

기자 피드백 5번 항목 — "컷마다 캐릭터의 얼굴·복장·체형이 달라 동일 인물이
이어지는 서사로 보이지 않는다."

## Before / After (구체적 예시 — 코드 레벨)

**Before** — 3단계 이미지 프롬프트에 인물 정보가 아예 없었다:
```python
prompt = build_background_prompt(s["camera"], s["scene"])
# → STYLE + "[SCENE] 회의실에서 마주앉은 두 사람" + 텍스트 금지 문구
# 8컷 전부 이 호출을 각자 독립적으로 실행 — 인물 생김새 정보 0
```
확산 모델은 "두 사람"이라는 말만 보고 매 컷 새로 인물을 그린다 — 컷1의
"30대 남성"이 컷5에선 "20대 여성"으로 바뀌어도 모델은 알 방법이 없다.

**After** — 1단계가 정한 인물 묘사를 8컷 전부에 동일하게 주입:
```python
characters = script.get("characters")
prompt = build_background_prompt(s["camera"], s["scene"], characters)
# → STYLE + "[CHARACTERS — keep consistent across all cuts]
#    A: 30대 남성, 캐주얼 셔츠, 피곤한 인상
#    B: 20대 여성, 정장, 또렷한 표정
#    setting: 사무실 회의실" + "[SCENE] ..." + 텍스트 금지 문구
```
8컷 모두 같은 `characters` 딕셔너리를 참조 — 완벽한 동일성 보장은
아니지만(확산 모델 한계), "정보가 아예 없던" 상태에서 "매번 같은 묘사를
참조하는" 상태로 바뀐 것이 핵심 개선.

## 한 것

- 원인 확인: `pipelines/webtoon/pipeline.py`의 1단계(스크립트) 출력에
  `characters: {A, B, setting}`(인물 묘사)가 기사당 한 번 정의되고,
  프롬프트도 "모든 컷에서 반복한다"고 지시하지만 — 이건 **1단계 텍스트에
  대한 지시일 뿐**, 실제 3단계 이미지 생성 호출
  (`build_background_prompt`/`build_image_prompt`)엔 `characters`가 인자로
  전달된 적이 없었다. 각 컷의 배경 이미지가 인물 생김새를 전혀 모른 채
  독립적으로 생성되고 있었음(현재 활성 경로는 `IMAGE_PROVIDER="bedrock"`
  — Stable Image Core, `build_background_prompt`).
- 새 헬퍼 `_characters_block(characters)` 추가 — 8컷 전부에 같은
  `characters` 딕셔너리를 `[CHARACTERS — keep consistent across all cuts]`
  블록으로 이미지 프롬프트에 주입. `build_background_prompt`(현재 활성
  Bedrock 경로) + `build_image_prompt`(OpenAI 크레딧 복구 대비 남겨둔
  휴면 경로) 둘 다 수정, 호출부(`characters = script.get("characters")`)도
  갱신.
- 인물 없는 소재(`characters: null`)는 빈 문자열 반환 — 기존 동작 그대로.
- 파이프라인 Docker 이미지 재배포(`sedaily-lens-frontpage-auto` 리비전
  19, mustknow_auto도 같은 이미지 공유).

## 결정

- 완벽한 컷 간 동일성 보장은 이번 스코프가 아니다 — 확산 모델(Stable
  Image Core) 특성상 진짜 캐릭터 시트·img2img 없이는 원천적으로 불가능.
  "아예 정보가 없어서 매번 무작위였던 것"에서 "같은 텍스트 묘사를 매번
  참조"로 개선하는 최소 조치로 스코프를 한정.
- git 작업 중 실수 기록: `git checkout main` 전에 로컬 변경사항이 있는
  상태로 브랜치 전환을 시도해 새 브랜치가 엉뚱한 브랜치(list-pagination
  작업 브랜치)에서 갈라지는 사고가 있었음 — stash로 격리해 다시
  main에서 정상적으로 분기함. 앞으로 새 브랜치 만들기 전엔 먼저 stash로
  작업 트리를 깨끗이 하고 checkout할 것.
