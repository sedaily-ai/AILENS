# 나의 LENS 구독 안내 카드 제거

## 배경

구독 현황을 확인할 수 있다면 구독자에게 안내 카드를 숨기고, 확인할 백엔드가 없다면 삭제하자는 요청을 조사했다.

## 한 것

- `features/letter/data/interestApi.ts`, CMS `routes_letters.py`, `letter_subscriptions_repo.py`, 계정 라우트와 대시보드 응답을 확인했다.
- 레터 구독 신청·이메일 확인·수신거부·미리보기 API는 존재한다. 구독은 이메일 단위이며 에디터 팔로우와 별도다. 신청 API는 기존 active 구독자에게도 pending과 동일한 응답을 반환하므로 신청 응답으로 가입 상태를 판별할 수 없다.
- 로그인 계정의 레터 구독 현황을 조회하는 API는 없다. `routes_users.py`의 내부 구독자 목록 API는 다른 뉴스레터 구독용 관리자 경로로, 해당 카드의 계정 상태 조회에 사용할 수 없다.
- `MyLensPage.tsx`의 구독 안내 카드와 이 카드 전용 대화상자 상태·스타일 주입·불필요한 import를 제거했다. 팔로우 조회 조건은 홈에서만 활성화한다.
- `myLensStyles.ts`의 카드 전용 CSS를 제거하고 작은 화면의 오른쪽 영역을 한 열로 정리했다.
- 프로덕션 빌드, `npx tsc --noEmit`, 변경 파일 ESLint, `git diff --check` 통과. 빌드 중 외부 API DNS 경고는 있었으나 빌드는 완료됐다.

## 결정

- 사용자가 제시한 ‘구독 현황을 조회할 수 없으면 삭제’ 기준에 따라 나의 LENS의 안내 카드를 제거한다.
- 실제 구독 데이터나 다른 화면의 이메일 구독 기능은 변경하지 않았다. 실제 메일 발송이나 구독 변경 호출도 하지 않았다.

## 다음

- 로컬 변경이며 배포하지 않았다. 계정과 이메일 구독을 연결한 인증된 상태 조회 API를 마련하면 노출 조건을 다시 설계할 수 있다.
