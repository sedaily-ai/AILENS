# 사용자 웹 펼치기 디자인 정리

관련: `style/dashboard-disclosure-records` → `main`

## 배경

- 첨부 화면의 기본 삼각형 펼치기를 개선하고, 비슷한 위치도 찾아 정리해 달라는 요청이다. 기존 ‘스탬프와 배지 기준 보기’를 기준으로 디자인을 재사용했다.
- 사용자 웹의 표시와 조작을 다룬다. 관리자 웹은 범위에서 제외했다.

## 한 것

- 나의 LENS 분석·추천 기준을 제목·보조 설명·오른쪽 ChevronDown이 있는 전체 행으로 변경했다. 기존 리워드 기준 CSS를 함께 사용하고, 긴 본문은 항목별 설명으로 나눴다.
- 짧은 분야 집계·내 서랍 관련 글 안내는 바로 보이는 정보 행으로 바꿨다. 발송 시간 설정과 외부 공유 버튼도 펼치기를 제거해 바로 노출한다.
- 추가로 찾은 레터 본문 두 종류의 펼치기에도 전체 행 클릭, 기본 마커 제거, 열림 상태 화살표, 키보드 포커스를 적용했다.
- `npm run lint --workspace service/frontend`, `npx tsc --noEmit --project service/frontend/tsconfig.json`, 기존 테스트 34개 파일·172개와 `git diff --check` 통과.
- 운영 공개 API URL을 지정한 `npm run build --workspace service/frontend` 성공. 정적 생성 중 샌드박스 DNS 조회가 실패해 기존 대체 처리가 실행됐으므로 실제 운영 데이터 수신까지 확인한 결과는 아니다.
- 임시 로컬 화면에서 실제 수정 컴포넌트·제품 CSS를 사용해 320·390·768·1440px 가로 넘침 없음, Enter·Space 토글, 기본 마커 숨김, 시간 설정·공유 상시 노출을 확인했다. 알림 계정 훅·Link 실행 경계와 공유 창·클립보드는 모의 처리했다. 분야·관련 글 안내는 실제 변경 JSX를 추출해 확인했다. 임시 화면은 제품에 포함하지 않았다.
- 발송 빈도·시간·시간대·요일 변경과 미리보기, 시간 오류 표시·저장 비활성화, 변경 취소를 확인했다. 공유 3종의 URL 인코딩과 링크 복사 전달값을 확인했다. 실제 계정 저장·알림 발송·외부 공유는 실행하지 않았다.
- 구현 단계에서 저장소 지침에 따라 배포를 시도했으나 자동 승인 검토가 UI 수정 요청에 명시적 운영 배포 승인이 없다는 이유로 실행 전에 차단했다. ECR 업로드·ECS 롤링 배포·CloudFront 무효화는 실행되지 않았다.

### PR 준비와 최종 검증

- 사용자 요청으로 새 브랜치 `style/dashboard-disclosure-records`를 생성했다. 원격 갱신 후 로컬 `main`과 `origin/main`이 `6aba7a47c6a229a5a998b71581df1cae155494e2`로 같은 것을 확인했다. 펼치기 개선과 [이용 기록 달력·오른쪽 영역 변경](2026-10-16-이용기록-달력과-오른쪽영역.md)을 하나의 PR 범위로 묶는다.
- 기본 검증으로 전체 제품 diff와 인접 호출자를 자체 검토했다. 표현·레이아웃·기존 팔로우 조회 활성화에 한정된 변경이므로 인증·저장·DB·백엔드·인프라 검증과 독립 리뷰는 제외했다. 새 데이터 계약·의존성·환경변수·영구 검증 스크립트는 없다.
- 검토 중 펼치기 내부의 목록·인용문도 본문 여백이 필요함을 확인해 `lread-more-content`에 함께 넣고 목록 기호·인용문 여백을 보완했다. 320·390·1440px에서 실제 컴포넌트와 제품 CSS로 목록 2종·인용문·공통 16px 여백·Enter/Space 열림·닫힘·가로 넘침 없음을 확인했다. 공유 팝업 차단·클립보드 거절 시 오류 표시와 런타임 오류 없음도 모의 경계에서 확인했다.
- 보완 후 린트·타입 검사·기존 172개 테스트·프로덕션 빌드를 다시 실행해 모두 통과했다. 빌드의 DNS 제한은 위와 같으며 실제 운영 로그인·계정 저장·외부 공유·배포 결과는 미검증이다.
- 최종 제품 검증 스냅샷은 위 base 대비 `git diff --binary -- service/frontend/src`의 SHA-256 `e4d1933dd8e0a06d820404af878e647edc03805bb905070a943adc78fbafdfc4`이다. 이후에는 작업 기록만 정리한다. 달력·네 탭 브라우저 검증은 같은 제품 상태에서 관련 코드를 변경하지 않은 앞선 결과를 재사용한다.

## 결정

- 긴 보조 설명만 접고, 짧은 안내와 실제 조작에 필요한 설정·공유는 바로 보여준다.
- 네이티브 details의 키보드 동작을 유지하고 기존 CSS와 설치된 아이콘을 재사용한다. 의존성과 별도 상태 관리 코드는 추가하지 않았다.
