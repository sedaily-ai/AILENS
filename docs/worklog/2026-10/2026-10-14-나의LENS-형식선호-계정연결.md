# 2026-10-14 나의 LENS 형식 선호와 계정 연결 보완

관련: feat/my-lens-account-storage · [현재 계약](../../product/나의LENS/형식선호·계정연결_구현상태.md)

## 배경

로그인 계정의 실제 콘텐츠 이용 형식을 대시보드·추천·알림에 반영하고, 브라우저에 남아 있던 팔로우와 저장 레터 읽음 기준을 서버에 연결한다. 기존 브라우저 북마크는 사용자 선택으로만 계정에 가져온다.

## 한 것

- 최근 90일 뉴스 콘텐츠/형식별 유효 열람·완료를 중복 없이 집계하고 표본 부족·동률·지원 형식을 구분한다.
- 관심 점수를 유지하면서 형식 선호를 추천·알림 후보와 이어볼 형식에 반영한다. 정본 기사 주소에서 형식을 열어 옛 주소의 쿼리 제거를 피한다.
- 기존 에디터 사전의 안정 ID로 계정 팔로우를 저장하고 실제 작성자 관계를 레터 추천에 사용한다.
- 저장 레터의 서버 완료 필터와 계정별 cursor 검사를 연결한다.
- 사용자가 선택한 브라우저 북마크의 계정 이관·부분 거부·같은 목록 재처리·해제 보존을 구현한다.
- v1.53 SQL·현재 API/동작·운영 인수 경계를 문서에 반영한다.

## 결정

- 이슈 레터는 한 형식만 제공하므로 4형식 선호 분석에서 제외한다. 읽음·팔로우·알림 동의는 북마크 가져오기로 자동 생성하지 않는다.
- 원본 브라우저 북마크·팔로우 키를 보존하고 현재 계정 데이터로 자동 병합하지 않는다.
- 운영 DB·배포·외부 푸시 발송·커밋·push는 수행하지 않는다.

## 다음

- 의미 유사도·품질 평가와 가져오기 영수증 보존 정책은 별도 범위다.
