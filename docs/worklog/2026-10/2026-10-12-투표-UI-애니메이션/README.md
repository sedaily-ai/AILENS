# 투표 UI 개선 — 끊김 없는 선택·차오르는 결과 (2026-10-12)

- 문제: 투표를 누르면 보기 줄이 갑자기 늘어나고(결과 영역 등장) 결과가 한 번에 나타나 끊기는 느낌. 선택 반응 전에 서버 응답을 기다림. 이전 디자인 피드백(파란 테두리·무거운 장식 싫음)과도 어긋남.
- 한 일: 모아쓰기 레터 투표(`LetterVote`)와 1기사 레터 투표(`PostVote`)가 같은 `shared/ui/form/PollOptions.tsx`를 쓰도록 통일.
  - 줄 높이 고정: 결과 영역(퍼센트)을 처음부터 자리만 잡아 두어 눌러도 레이아웃이 밀리지 않음.
  - 누르는 순간 즉시 반응: 고른 보기에 체크가 그려지고(스트로크 애니메이션), 나머지는 살짝 흐려짐. 서버 응답 전에도 반응.
  - 집계가 도착하면 막대가 왼쪽에서 오른쪽으로 부드럽게 차오르고(0.9초 감속 곡선, 보기마다 70ms씩 시차), 퍼센트 숫자도 0에서 같이 올라감.
  - 선택은 파란 테두리 대신 채움 색·체크·굵은 글씨로 표현(평면, 그라데이션 없음). 우려류는 앰버, 모름은 회색 채움.
  - 움직임 줄이기 설정이면 애니메이션 생략(`prefers-reduced-motion`).
- 스크린샷: after_before-vote(투표 전), after_pending(누른 직후), after_done(결과). 정지 화면이라 움직임 자체는 직접 눌러 확인해야 함.
- 미확인: 운영 화면의 실제 클릭 감각, 느린 네트워크에서의 체감, 모바일. 전체 동작은 로컬 개발 서버 화면으로만 확인.
- 참고: 옛 CMS 글 안의 `InteractiveBlock`(퀴즈·투표 마커)은 저장·집계가 없는 별도 구조라 이번에는 건드리지 않음.
