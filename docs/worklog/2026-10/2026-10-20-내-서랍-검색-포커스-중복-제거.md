# 내 서랍 검색 포커스 중복 제거

## 배경

검색창을 클릭하면 내부 입력칸과 바깥 영역에 여러 강조선이 생겨 복잡하게 보인다는 요청.

## 한 것

- `myLensDrawerStyles.ts`의 검색창 `:focus-within` 외곽선을 제거하고 기존 1px 테두리 색만 변경한다.
- 검색 입력칸의 기본 appearance·outline·box-shadow를 국소적으로 초기화했다. 더 구체적인 선택자로 `.ml-page input:focus-visible` 규칙과의 중복도 제거한다.
- 다른 입력칸의 포커스 표시는 유지한다.
- 실제 `DrawerPanel`과 스타일을 Chrome에서 렌더링했다. 기존 스타일로 내부·외부 outline이 동시에 표시되는 현상을 재현한 뒤 수정본에서 모두 사라지고 테두리 한 겹만 남는 것을 확인했다.
- 1440/768/390/320px에서 가로 넘침과 포커스 전후 크기 변화가 없었다. 클릭·키보드 포커스, 문장 검색 결과, 레터·기사 필터별 검색창, 다른 입력칸 포커스를 검증했고 390px 캡처를 직접 확인했다.
- 프로덕션 빌드, 타입 검사, 변경 파일 ESLint, `git diff --check` 통과. 빌드 중 외부 API DNS 경고가 있었으나 완료됐다.

## 결정

- 키보드로도 현재 입력 위치를 알 수 있도록 검색창 전체의 테두리 색 변화는 남긴다.
- 추가 브라우저 엔진이 설치돼 있지 않아 실제 실행 검증은 Chrome에서 수행했다.
