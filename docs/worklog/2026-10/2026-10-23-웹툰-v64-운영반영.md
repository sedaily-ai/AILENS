# 웹툰 v64 운영 반영·모델 비교 갱신

## 배경

사용자가 v64 생성·배포·커밋·push·PR 생성·병합과 v64 결과로 비교 PDF 갱신을 승인했다. 기존 운영은 webtoon v63·이미지 v30이었다. R2는 로컬 추가 지침이어서 정식 버전으로 통합할 필요가 있었다.

## 한 것

- v64에 기사별 주제 소품, 두 성인 외형의 독립 문장, 옷깃·머리 구분, 계획·완료·발사·운용 관계, 거래 비중 분모, 핵심 연도·수량의 화면 글 검수를 통합했다. 8컷 JSON과 기존 합성 계약은 유지했다.
- 최종 대본 2건을 실제 CMS 요청 구성으로 생성했고 구조 검사를 통과했다. 초기 후보 2건은 외형 문구 불일치로 제외했다. B의 화면 글 4컷을 편집했으며 이미지 지문은 원출력 그대로다.
- 실제 Ultra·SD 3.5·Codex 18장을 새로 생성했다. 최종 각 6장 평균은 12.37초·9.84초·23.18초다. Codex는 정확한 모델이 미노출인 참고 시안이다.
- 13:50 KST v64 활성화 후 저장본·공개 API·CMS 초안 해시 일치를 확인했다. 이미지 v30은 유지했다. 데이터 활성화가 이번 운영 배포이며 Lambda·ECS·프런트 코드 재배포는 하지 않았다.
- 기존 계약 회귀 테스트 16개 통과. 원출력·편집 이력·측정과 독립 검수 기록은 [평가 기록](../../evaluation/webtoon/2026-10-23-v64/README.md)에 남겼다.
- PDF는 새 18장, 이전 R2와의 비교, 확대 검수, 시간·비용·제외 후보 비용·GPT 제공 한계를 포함해 20쪽으로 갱신했다.

## 결정

- v64를 검수 포함 운영 개선안으로 채택한다. 얼굴·소품 연속성까지 해결한 버전은 아니다. Ultra/SD 3.5 B8 의상 변화와 B4 위성 표현 실패를 보고서에 공개했다.
- AI LENS 재작성 기사에 포함된 관계 오류를 그대로 입력하지 않고 서울경제 원보도를 사용했다. 이전 R2와 입력이 달라 v64 단독 효과로 해석하지 않는다.
- 현 운영 Ultra 유지, SD 3.5는 비용 절감 후보. Bedrock GPT 이미지 제공 일정·ID·비용 미확인. 직접 API를 연결하지 않는다.
- 기존 미추적 작업은 보존했다. 원격 main에 동일·확장된 v63 기록이 존재해 별도 백업 후 최신 main 기반 `feat/webtoon-prompt-v64`에서 작업했다.
