## 배경

사용자 요청에 따라 운영 사용자 웹과 로그인한 **나의 LENS**를 내부 브라우저로 검증했다. 관리자 CMS(`lensdb.sedaily.ai`)는 사용자의 최종 범위 정정에 따라 제외했다. 이번 작업은 검증과 보고만 수행했으며 서비스 코드·콘텐츠·설정은 수정하지 않았다.

전수 범위는 **페이지 유형과 주요 사용자 흐름**으로 잡았다. 저장소의 `page.tsx` 65개를 라우트 목록과 대조하고, 공통 템플릿을 쓰는 기사·날짜·페이지 번호는 실제 표본으로 확인했다. 수천 개의 개별 기사 URL, 모든 과거 날짜, 모든 필터 조합을 전부 열었다는 의미는 아니다. 기사 본문은 9개 분야 대표 기사, 레터는 당시 목록에 공개된 5편 전체를 확인했다.

### 검증 방법과 판단 기준

- Codex 내부 브라우저에서 실제 운영 화면을 열고 링크·탭·검색·필터·달력·재생·복사를 조작했다. 소스는 관찰 결과의 원인을 보조 확인하는 용도로만 읽었다.
- `frontend-harness`의 평가 전용 원칙을 적용했다. 사용자의 내부 브라우저·스크린샷 금지 조건에 맞춰 PNG를 생성하는 기본 CLI 대신 브라우저에서 시나리오를 직접 수행했다. 자동 하네스 실행·점수 산출을 완료했다고 주장하지 않는다.
- **스크린샷을 촬영·저장하지 않았다.** 근거는 렌더링된 문구, 접근성 트리, DOM 배치 치수, 링크 목적지, 선택 상태, 미디어 길이·재생 상태다. 픽셀 단위 겹침, 이미지 안 글자, 영상 자막의 모든 프레임, 색 대비의 육안 검증은 포함하지 않는다.
- 데스크톱 1280/1440px, 모바일 390×844, 태블릿 768×1024에서 확인했다. 모든 페이지를 모든 크기로 교차 검사한 것은 아니다. 아래 범위표에 구분했다.
- 초기 서버 렌더링·로딩 상태를 장애로 단정하지 않고, 주요 컨트롤 출현과 후속 상태를 다시 확인했다. 복사는 비동기 완료 후 클립보드 결과로 확인했다.
- 운영 계정의 저장·삭제·팔로우·투표·구독·알림 동의·비밀번호 변경은 실행하지 않았다. 서비스 자체의 정상 열람 계측에 따라 읽기 이력·관심 집계는 증가할 수 있다. 글자 크기 시험은 100%로 복원했다.
- P1: 데이터 신뢰 또는 핵심 이용 흐름에 직접 영향. P2: 잘못된 안내·상태·구조로 혼란을 주는 문제. P3: 문구·명칭의 작은 불일치. 장애 등급이나 배포 차단 등급은 아니다.
- 다이어트 후보는 삭제 확정이 아니다. 사용량·제품 목적을 알 수 없는 기능은 가정을 명시했다. 기존 기능은 그대로 유지한다.

### 5. 정상 확인 또는 오탐에서 제외한 사항

- **영상 소개 CTA:** 자동 순환 때문에 관찰 시점과 클릭 시점의 형식이 바뀔 수 있었다. 영상 행을 직접 선택해 순환을 멈춘 뒤 클릭하니 `?v=4`, 영상 선택으로 정상 이동했다. “영상 CTA가 항상 읽기로 간다”는 오류로 기록하지 않았다.
- **링크 복사:** 기사 공유의 복사, 카카오/인스타의 링크 복사, 레터 링크 복사, 타임라인 사건 링크 복사, 내 서랍 문장 복사에서 비동기 완료 뒤 올바른 값 확인. 즉시 읽었을 때 이전 값이던 현상은 실패로 계산하지 않았다. 외부 SNS 게시 완료는 수행하지 않았다.
- **검색 최신 글:** 초기에 빠졌던 18:09 코스피 기사는 재검증 때 108건 결과의 첫 항목으로 나타났다. 영구 검색 누락으로 확정하지 않았다. 검색의 분류·0건 안내·더 보기·정렬·오늘 조건도 동작했다.
- **미디어:** 산업 표본 영상과 음성 모두 재생 위치가 증가했다. “재생이 안 된다”가 아니라 F06의 탭 전환 후 제어 불가 문제다.
- **에디터 소개 듣기:** 클릭 후 “멈추기”로 바뀌고 이후 종료됐다. DOM에 `<audio>`가 없다는 이유만으로 실패로 판단하지 않았다. 소스는 `new Audio()`를 사용한다. 소리 내용 자체는 검증하지 않았다.
- **저장 연동:** 레터 목록/상세의 저장 상태와 내 서랍의 저장 레터 1개가 로딩 후 일치했다. 새 저장·삭제는 하지 않았다.
- **관련 기사:** 저장 문장의 관련 글 3건이 표시되고, 각 추천의 단어 일치 근거가 나왔다. 의미 기반 추천이라고 오인하지 않도록 현재 제한도 표시됐다.
- **기록:** 주·월·연 뷰가 전환됐다. 수집 시작 전 날짜의 `—`와 미래 날짜의 `·`를 데이터 누락으로 판정하지 않았다.
- **반응형:** 관찰한 화면의 문서 폭은 390/768/1280/1440px의 해당 뷰포트 안에 들어왔다. 로딩 완료로 확인한 이미지에서 `naturalWidth=0`인 깨진 자산은 발견하지 못했다. 지연 로딩된 모든 이미지·픽셀 겹침까지 정상이라는 뜻은 아니다.
- **지면·타임라인:** 지면 필터·달력 날짜 이동, 타임라인 사건 이동·관련 기사 펼치기·기사 더 보기·링크 복사는 정상 확인했다.
