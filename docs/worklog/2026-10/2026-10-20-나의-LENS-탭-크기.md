# 2026-10-20 나의 LENS 탭 크기 조정

## 배경

사용자가 나의 LENS의 ‘홈 / 내 서랍’ 탭이 다른 영역보다 작다고 지적했다.
기존 글자 크기는 기본 13px, 화면 폭 420px 이하에서 12px이었다.

## 한 것

- `service/frontend/src/widgets/MyLensPage/myLensStyles.ts`에서 기본 글자를 18px, 420px 이하를 16px로 확대했다.
- 탭에 최소 너비 64px, 최소 높이 56px, 사방 여백 12px을 적용했다. 비선택 탭에도 투명한 3px 하단 테두리를 두어 선택 여부에 따른 높이 차이를 없앴다.
- `myLensEngagementStyles.ts`의 최소 높이 40px 덮어쓰기를 제거했다.
- `npm run build --workspace=service/frontend`, 프론트엔드의 `npx tsc --noEmit`, 변경한 두 파일의 ESLint, `git diff --check` 통과.
- 브라우저 검증 도구는 기존 Chrome 프로필 사용 충돌로 시작하지 못했다. 실제 화면과 탭 이동 검증은 미완료다.

## 결정

- 나의 LENS 전용 스타일만 변경했다. URL, 메뉴 구성과 데이터 처리 동작은 유지했다.

## 다음

- 실제 화면에서 크기와 여백 확인.
- 운영 배포는 아직 실행하지 않았다.
