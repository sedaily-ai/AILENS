## 배경

[사용자 웹 전수 검증 보고서](2026-10-15-사용자웹-전수검증.md)의 F01–F21만 수정했다. **코드 수정 13건, 기사 데이터 정정 8건**이다. 사용자 최종 지시는 **“로컬 수정·검증만 진행”**이므로 운영 배포·DB 수정은 수행하지 않았다. 기사 데이터 정정 8건은 대상 기사 5건의 정정안을 만들고 로컬 검증 데이터에 적용한 상태다.

다이어트 후보 D01–D20과 미확정 관찰 R01–R03은 변경 대상으로 삼지 않았다. F09의 투표 복구와 F10의 동일 요약 중복 제거만 기존 오류의 범위에서 처리했고, 나머지 공유·구독·종료 안내·비교 카드·게임 기능은 유지했다.

### 기사 5건의 정정안

- [정정 데이터](../../../service/lens-cms-api/seed/2026-10-15-audit-corrections.json): 수정 전·후 값을 함께 보관한다. 대상은 산업 20101714, 금융 20101638, 경제 20101715, 사회 20101767, ETF 20099924다.
- [적용 스크립트](../../../service/lens-cms-api/scripts/apply_publication_corrections.py): 기본 검증 모드, 적용 시 계획 SHA와 신규 백업 파일 요구, 기존 값 일치 검사, 단일 트랜잭션을 준비했다. **DB에 연결하는 검증 모드와 적용 모드 모두 실행하지 않았다.** 실제 DB 스키마·프로젝션과의 통합 실행은 미검증이다.
- 스크립트의 순수 데이터 변환 함수는 필드 보존·편집 충돌·미디어 URL 변경 거부를 로컬 단위 테스트로 확인했다. URL·발행 상태·이미지/음성/영상 파일은 변경하지 않는다.
- F15 근거: [서울경제 원문](https://www.sedaily.com/article/20101767)의 부제에는 5,829명이 남아 있지만, 본문과 인용에 5,901명 중 **5,289명(89.6%)**이 반복되고 산술도 일치한다. 본문·인용을 기준으로 인원을 정정했으며 비율을 98.8%로 바꾸지 않았다.
- F16 근거: [서울경제 원문](https://www.sedaily.com/article/20099924)의 세부값은 각각 **248억 8,290만 / 248억 8,890만 달러**다. 제목을 약 249억 달러로 반올림해 부제와 맞췄고 세부값은 보존했다.
- 이미지 내부에 그려진 문구, 실제 녹음 발화·영상 전체 프레임을 재생성하거나 전수 대조하지 않았다. F12·F15의 이번 정정은 대본·요약·텍스트 캡션 등 명시한 필드에 한정한다.

### 검증 환경과 검사 결과

- 내부 브라우저에서 실제 Next.js 로컬 화면을 조작했다. 반응형 본문 검증은 390×844와 1440×1000에서 진행했고 검증 후 화면 크기 설정을 복원했다.
- 임시 로컬 API(`127.0.0.1:4319`)는 공개 기사 조회 결과에 정정 대상 5건을 덮어씌웠다. 나머지 공개 자료는 읽기 요청으로 사용했다. 계정 쓰기는 차단하고 투표 응답은 로컬 메모리에서만 처리했다. 운영 계정·투표 데이터를 변경하지 않았다.
- `npm run test --workspace service/frontend -- --reporter=dot`: **29개 파일, 132개 테스트 통과**. 형식별 리다이렉트·빠진 형식·404와 단어장 수집/중복/정본 링크 회귀 검증 포함.
- 변경된 프런트엔드 TypeScript 파일 22개에 `npx eslint` 실행: **오류·경고 없이 통과**.
- 전체 프런트엔드 린트는 **기존 오류 20개·경고 4개로 실패**했다. `ChronicleChart`, `TimeMachineRewind`, `TodayNewsPlayer` 등 변경하지 않은 코드의 기존 문제는 이번 21건 범위에 포함하지 않았다. 전체 린트 통과로 보고하지 않는다.
- `npx tsc --noEmit -p service/frontend/tsconfig.json` 통과. 최종 빌드 내 TypeScript 검사도 통과.
- `NEXT_PUBLIC_CMS_API_URL=http://127.0.0.1:4319 NEXT_PUBLIC_API_URL=http://127.0.0.1:4319/account npm run build --workspace service/frontend`: **최종 빌드 성공**, 정적 페이지 63개 생성. 이는 로컬 검증 API를 사용한 결과이며 운영용 산출물을 배포하지 않았다.

## 결정

- 운영 DB 조회를 위한 SSM 실행은 자동 승인 검토에서 구체적 운영 접근 권한 부족으로 거절됐다. 이후 사용자가 로컬 수정·검증만 요청했으므로 재시도하지 않았다. 운영 DB 조회·수정, 원격 실행, 웹/CMS 배포를 수행하지 않았다.
- 커밋·push·PR 작업은 수행하지 않았다. 로컬 코드와 정정안을 검토 가능한 변경으로 남겼다.
- 기존 사용자 변경 `2026-10-15-나의LENS-배포준비.md`를 보존했다. SHA-256은 `fa6a2bb2c54f3da9344680d72876eed960f93a826070f195ef7bd8cb125cd8f5`로 기존과 같다.
- 이번 완료 범위는 **21개 오류의 로컬 코드·정정안과 해당 재현 시나리오의 검증**이다. 운영 해결 완료 또는 모든 콘텐츠·모든 미디어 무결점 판정이 아니다.

운영 반영은 이번 요청 범위에서 제외되어 있다. 별도 요청 시 웹/CMS 변경과 기사 5건의 실제 저장 구조를 대조하고, 백업·조건부 정정·배포 후 운영 화면을 재검증해야 한다. 특히 단어장 F19는 웹과 CMS 양쪽 변경이 필요하고 콘텐츠 오류 8건은 정정안만으로 운영 데이터가 바뀌지 않는다.
