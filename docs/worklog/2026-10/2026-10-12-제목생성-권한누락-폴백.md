# 1기사 레터 제목 생성 권한 누락과 기사 제목 폴백 (2026-10-12)

작성: 문영광 + Claude Code
관련: PR #77, #78, 운영 IAM 정책 `frontpage-auto-access`, 로그 `/ecs/sedaily-lens-frontpage-auto`

## 문제 발견
- 10/12 07:00 지면 1면 실행 결과 발행 4건 중 2건의 제목이 기사 제목 그대로였다(성수동 "[단독]MZ 성지…", 씨티·BofA "…웃돌다").
- 나머지 2건(사우디 공항, 세라젬)은 레터형 제목이었다.
- 실행 로그에는 제목 관련 오류가 한 줄도 없었다(`제목 생성 실패` 로그 없음).

## 문제 정의
- 제목 전용 생성(`pipelines/common/headline.py`)이 운영에서 동작하지 않았다.
- 로컬에서 같은 두 기사로 재현하면 레터형 제목이 정상 생성됨 → 프롬프트·규칙 문제가 아니라 운영 환경 문제.

## 원인(Why)
| 항목 | 내용 |
|---|---|
| 호출 모델 | `lens-letters-sonnet-46` (프로파일 nrr81xvevv5k) |
| 운영 태스크 역할 정책 | Bedrock 허용 목록에 위 ARN이 없었음 → 권한 오류 |
| 오류가 안 보인 이유 | `headline.generate`가 호출 예외를 삼키고 `None` 반환 → 호출부가 기사 제목으로 폴백, 로그 없음 |
| 검증이 놓친 이유 | 어젯밤 제목 생성 검증을 로컬 자격 증명(yeonggwang)으로만 했음 |
| 레터형 2건 | 제목 전용 생성이 아니라 본문 프롬프트가 쓴 제목을 파싱한 폴백 경로로 추정(미확인) |

## 한 일(How)
| 구분 | 내용 |
|---|---|
| 정책 | 운영 역할 정책 4개 구문에 ARN 추가(사용자가 직접 `put-role-policy` 실행, 한 구문에 중복 2회 — 동작 영향 없음) |
| 코드 | `headline.py`에 후보 생성 실패, 사실 확인 호출 실패, 통과 후보 없음(탈락 사유) 로그 추가 |
| 되돌리기 | 성수동 글 제목을 레터형으로 변경("팝업스토어 뒤편 사무실엔 직장 내 괴롭힘 진정이 282% 늘고 있거든요"), 씨티·BofA 글도 본문 범위 수치로 변경("자산 격차는 10~12배인데 보안 인력 격차는 34~47배거든요") |
| 재발 방지 | 리팩토링 1단계(모델 ARN 정본)로 정책·코드 정합 테스트 추가([2026-10-12-리팩토링-01-정본-단일화.md](2026-10-12-리팩토링-01-정본-단일화.md)) |

## 가설과 검증
| 가설 | 검증 방법 | 상태 |
|---|---|---|
| 권한 추가 후 다음 실행(10/13 07:00)에서 기사 제목 폴백 비율이 낮아진다 | 10/13 발행 글 중 headline == 기사 제목인 비율(정치 제외). 기준: 0~1건/4건 | 미확인(내일) |
