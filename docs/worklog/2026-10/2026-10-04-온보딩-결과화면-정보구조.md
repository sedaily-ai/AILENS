## 사이클 1 — 결과를 "버튼 → 바로 체험"으로

### 문제 발견
- 초안 결과 화면: 유형 이름 + 기사 미리보기 카드 + "지금 보러 갈래요" 버튼 — 사용자 지적: "바로 볼 수 있게"
- 레터 포맷을 기사 페이지 컴포넌트로 그리면 본문 깨짐 확인("01/06스코프3" 붙음) — 소제목 스타일이 `LensViewClient` 내부 CSS에 종속
- 기사 페이지의 포맷 이동 버튼(`FormatStepNav`)은 상단 탭 DOM 클릭 방식 → 온보딩에서 동작 불가

### 문제 정의
- 결과 직후 추가 클릭 1회가 이탈 지점 / 기존 컴포넌트 재사용 시 스타일·동작 종속 3건

### Why
- 사용자 요청 + 클릭 최소화 원칙(질문 구조 문서 참조)

### How
- 선택: 오늘 지면 1면 첫 기사를 고른 포맷으로 같은 화면에서 즉시 렌더
- 레터: 동일 파서(`parseLetterBlocks`) + 온보딩 전용 최소 스타일(`LetterInline`) / 나머지 3종: 기존 `LensFormatPanel` 재사용
- 이전/다음 형식 버튼: 동일 문구·순서로 새로 구현, 패널 내부 원본은 CSS로 숨김(선택자 의존 — 기사 페이지 라벨 변경 시 숨김 해제 위험)

### 판정
- 적용 완료 · 4개 포맷(레터·웹툰·팟캐스트·영상) 전부 기사 렌더 확인(레터 본문 1,622자 등)

## 사이클 2 — 유형을 "페르소나 + MBTI 예시"로 설명

### 문제 발견
- 결과 = 이름 한 줄뿐 → 사용자 의견: "페르소나·일상이 그려져야", "MBTI는 간접적으로 녹이는 것"

### 문제 정의
- 이름만으로는 "내 모습"이 연상되지 않음 / MBTI는 입력 항목이 아니라 연상 보조 장치

### Why
- 상황 4 × 선택지 4 = 16조합이 우연히 페르소나 16종 구조와 일치 → 질문 증가 없이 결과만 풍성하게 가능

### How
- 16종 페르소나: 하루 한 장면 1문장(`lib/personas.ts`) + MBTI 예시 2개 — 칩은 "같은 분들께 잘 맞아요" 형태의 약한 표현
- 질문 카드(1·2단계)에도 "예를 들면 ISTJ ENTJ" 칩 추가 — 11px, 선택 항목 아님
- 상황 제약으로 포맷이 바뀌는 조합은 사유가 문장 안에서 이어지도록 작성(예: "눈은 길에 둬야 해서, 귀로 대신 챙기는 사람")
- 제외: MBTI 입력 UI(사용자 결정)
- ⚠️ 한계: MBTI↔선호 매핑은 근거 데이터 없는 가설 → "특히 잘 맞아요" 수준으로만 표현

### 판정
- 적용 완료 · 배포 완료

## 사이클 3 — 통계 카드(탭 2 × 카드 2)

### 문제 발견
- 사용자 요구: 퍼센트 분포·성향(NT/NF/ST/SF) 분포 노출
- 1차 구현에서 이해 불가 요소 4건 확인(사용자 지적 + 화면 점검): ① 포맷 칩 변경 시 위 제목과 카드 기준 불일치 ② "글 24%"의 의미 문장 단절 ③ NT/NF/ST/SF 약어 미설명, 어떤 콘텐츠를 본 사람인지 불명 ④ 두 설문 답을 섞은 카드("점심 × 그림과 사진 5%")

### 문제 정의
- 통계 구조가 설문 구조와 1:1로 대응하지 않음 + 약어·범례 부재

### Why
- 분포가 이해되지 않으면 "나와 같은 선택의 비중"이라는 소속감 효과 소실

### How
- 구조: 탭 2개(보는 시간 / 먼저 보는 것) × 탭당 카드 2장(화살표·스와이프) — 각 탭은 자기 질문만 다룸(교차 카드 삭제)
  - 보는 시간: ① 시간대 비중 ② 시간대별 성향 분포
  - 먼저 보는 것: ① 방식 비중 ② 방식별 성향 분포
- 성향 분포: 범례(분석형 NT·감성형 NF·현실형 ST·배려형 SF) + 행마다 100%인 누적 막대 + 내 행 강조 + 결론 한 줄("감성형(NF)이 44%로 가장 많아요")
- 판단 근거: 막대 하나 = 100%로 통일해 행 간 비교 가능
- 기본 펼침(사용자 결정) / 접으면 한 줄 요약("31%가 이 시간에, 24%가 나처럼 봐요")
- 퍼센트 합 보정: 최대잔여법으로 합 100 고정(보정 전 101)
- ⚠️ 통계 수치 전부 샘플(`lib/distribution.ts` `DISTRIBUTION_IS_MOCK=true`) — 사용자 지시로 화면의 "샘플 데이터" 문구 제거 후 배포. 실제 집계 연결 전까지 실데이터 아님
- 목표 구조(미구현): 익명 선택값 Lambda + DynamoDB 카운터, 표본 N 미만 시 카드 숨김

### 판정
- 적용 완료 · 배포 완료(샘플 수치 상태)
- Next: 실집계 연결 또는 카드 숨김 결정 필요 — 현재는 실제 통계로 오인될 위험 상태
