# 2026-10-13 소개 화면(/onboarding) 개편 — 4형식 비교 카드·기능 목록·메일 신청

## 배경

소개 화면이 "매일 아침 메일로 오는 한 통" 하나만 설명하고 있었다. 4형식(읽기·웹툰·팟캐스트·영상)과 다른 기능 소개가 없었고, 확인되지 않은 "매일" 발송을 약속했다. 이 화면이 할 일을 ① 메일을 받을지 결정하게 하기 ② LENS를 한눈에 보여주기 ③ 기능 알려주기로 정하고(로그인 불필요), 범위는 소개 화면 프론트엔드로 한정했다.

## 결정

- 정할 것 4개는 llm-council 투표(claude-sonnet-5.5·gpt-5.6-terra·glm-5)로 정했다: 메일은 현행 "오늘의 한 통" 유지(3:0), 헤드라인 "같은 기사를 읽기·웹툰·팟캐스트·영상으로."(2:1), 게임·사주 제외(2:1), 글자 크기 토큰 추가(3:0)
- 형식 이름은 "팟캐스트": 비교 카드·기사 탭과 같은 공용 상수를 쓴다. 홈 칩의 "듣기"와 맞추는 일은 사이트 전체 이름 결정이라 보류
- 구독 요청에 레터 내용을 계속 넘긴다. 없으면 서버가 daily_letters → 로컬 미러 → MOCK 레터 순으로 폴백하는데, today-letters API가 10/11~10/13 모두 빈 목록이라 가짜 예시 레터가 실제 구독자에게 갈 수 있다. 보낼 레터를 불러오기 전에는 신청 버튼을 막는다
- "오늘의 뉴스를 귀로"는 기능 목록에서 뺐다(전용 목록 페이지 없음). "자세히"는 새 법적 문구 대신 개인정보처리방침(뉴스레터 수집·이용·파기 항목 있음) 링크로 했다
- 배포는 하지 않는다(이 작업은 로컬 작업과 커밋·푸시까지). 홈·메뉴에서 소개 화면으로 연결하는 일은 이 PR 승인 뒤 따로 한다
