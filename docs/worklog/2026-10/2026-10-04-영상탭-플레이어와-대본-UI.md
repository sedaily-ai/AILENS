## 사이클 1 — 팟캐스트 대본 UI 정리

### 문제 발견(사용자 지적 순서)
- 대본 영역 왼쪽 파란 테두리 → "촌스럽다"
- 흰색 말풍선 배경 → "없애면 안 되나"
- 읽는 위치 강조가 문장 단위 → 클릭 시 즉시 이동하지 않음("정교하게 코딩된 거 맞나?")
- 지금 재생 위치로 이동하는 UI 위치, 대본 펼침·접힘 위치 적절성 질문
- 카피: "AI 음성 브리핑" 표기 제거, 친근한 문구 요청

### How
- 파란 테두리·말풍선 제거 / 현재 읽는 문단만 파랑 굵게(`#2f5fc4`), 나머지 회색(`#7b8798`)
- 추적 단위 문장 → 문단(사용자 결정, 정확도 대비 구현 신뢰성)
- 문단 클릭 시 해당 위치로 즉시 재생(`playFrom`), "현재 위치로" 버튼을 안내 행에 배치
- 카피에서 "AI" 표기 제거, 친근한 문구로 교체
- 가시성: 얇은 맞춤 스크롤바, 위아래 흐림

## 사이클 2 — 영상 탭: 인플레이스 재생과 대본

### 문제 발견
- 사용자 지적: 재생 클릭 시 검정 시네마틱 모드로 전환 → 제거 요청 + 대본을 팟캐스트와 같은 디자인으로
- 기존: 영상 아래 "스크립트(본문 텍스트)" 별도 블록

### How
- 재생 시 화면 어둡게 하던 배경·캡션 색 전환 제거 → 그 자리에서 재생
- 재생 중 컨트롤 2.6초 후 숨김·얇은 진행선만 유지(마우스 이동 시 복귀)
- 대본: 영상 카드 내부로 이동, 기본 펼침 + "대본" 칩으로 접기 / 팟캐스트와 동일 스타일(문단 강조·클릭 즉시 재생·스크롤바·흐림)
- 문단 시각은 글자 수 비례 추정 → 하단에 "대략 따라가요" 고지(정확도 한계 명시)
- 영상 없는 기사에서만 기존 스크립트 블록 유지
- 영상 비율 읽어 세로(9:16)는 중앙 세로 표시, 가로는 기존 유지

### 검증
- 실제 크롬: 8개 문단 모두 표시, 재생에 맞춰 강조 이동 확인
- 알려진 한계: 한글 풀어쓰기 나레이션이 대본에 노출될 수 있음(대본용·음성용 텍스트 분리 필요 — `2026-10-03-영상-포맷-재설계와-실시간-적용.md` 참조)
- 후속 관찰: 온보딩 검증 중 테스트용 브라우저에서 "영상을 재생할 수 없어요" 발생 — 영상 파일 HTTP 200, 테스트 브라우저 H.264 코덱 부재 추정(실기기 확인 대기)
