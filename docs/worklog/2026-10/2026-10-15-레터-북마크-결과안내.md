# 2026-10-15 레터 북마크 결과 안내 보완

## 배경

레터 목록·상세에서 저장 성공 안내가 없고, 나의 LENS에서는 북마크 결과 안내가 자동으로 사라지지 않았다. 배포 사이트에서 제보한 흐름이 현재 소스에도 남아 있어 공통 저장 훅과 표시 컴포넌트를 보완한다.

## 한 것

- useLetterShelf에서 계정 저장·해제 성공이 확정된 뒤 각각 ‘저장한 레터에 담았어요.’, ‘저장한 레터에서 제외했어요.’를 안내한다.
- LetterShelfStatus를 사용하는 목록·상세·대시보드에서 화면 하단에 같은 성공 안내를 표시한다.
- 안내는 성공 후 3초 뒤 숨기며 새 저장 동작에서는 기존 안내를 지우고 새 결과의 표시 시간을 다시 시작한다. 화면이 내려가면 타이머를 정리하고 다른 계정에는 안내를 표시하지 않는다.
- 대시보드의 중복 북마크 안내를 제거하고 관심사·읽을 시간의 간단한 안내에도 자동 숨김을 적용한다.
- 목록·상세의 직접 작성 SVG와 대시보드의 다른 크기 아이콘을 공통 LetterBookmarkIcon으로 통일한다. Lucide Bookmark 22px·선 굵기1.8을 사용하고 저장 여부에 따라 윤곽선/채움을 표시한다. 저장된 상태는 기존 공통 파란색을 유지한다.
- 취소된 요청·저장 실패·로그인 요청을 저장 성공으로 표시하지 않는다. 실패 안내와 재시도, 기존 브라우저 원본 보존은 유지한다.

## 결정

- 수정 범위는 프론트 안내 동작이며 저장 API·DB·리워드·푸시 정책은 변경하지 않는다.
- 검증 로그·화면 캡처는 저장소에 추가하지 않는다. 후속 공유 요청에 따라 기존 PR #109 브랜치에 추가 커밋·push하며 운영 DB와 배포는 건드리지 않는다.
