## 6. 음성 — 영상만 Polly → ElevenLabs

- 현재: 영상 기본 Polly Seoyeon `generative`($30/M자) [코드·검색]. 영상·팟캐스트 설정은 별도(CMS 영상 설정 `PROVIDER`).
- 전환 준비 상태: 비밀 `ai-labs/elevenlabs` 존재, 파이프라인 두 태스크 역할에 읽기 권한 있음 [측정] → **설정 변경만으로 전환 가능**(코드·IAM 변경 없음).
- 영상 음성량 추정 [추정]: 30초 숏폼 약 200자 × 월 약 1,020편 = 월 약 20만 자(15초면 약 10만 자).

| 방식 | 단가 [검색] | 월 비용 (10~20만 자) |
|---|---|---|
| Polly generative | $30/M | $3~6 |
| Polly neural | $16/M | $1.6~3.3 |
| ElevenLabs Flash v2.5 | $50/M | $5~10 |
| ElevenLabs Multilingual v2/v3 | $100/M | $10~20 |
| ElevenLabs Creator 구독 | $22/월 (22만 자 포함) | $22 (고정) |

- 증가분은 월 약 $4~19(0.6~2.7만원)로 미미. 판단 기준은 품질(한국어 발음·숫자 읽기·자연스러움).
- 위험: TTS 실패 시 폴백 없이 예외 → 영상만 빠진 채 발행(`published_no_video`) [코드]. 계정 크레딧 한도 초과·CMS 미리듣기 재생성에 따른 크레딧 소모. 외부 API 장애 의존.
- 팟캐스트까지 전환 시 월 약 100만 자: Multilingual $100 vs Polly generative $30 = +$70(약 +10만원), Flash는 +$20. 별도 판단.
- 제안 선행: 영상 각본 실제 글자 수 집계 → 소수 영상 A/B 청취 → 폴백(Polly) 분기 추가 → 전환.
