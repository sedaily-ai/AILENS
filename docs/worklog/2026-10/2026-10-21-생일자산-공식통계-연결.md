## 배경

처음 기획한 다섯 칸(SK·삼성 주식, 비트코인, 서울 아파트 시세, 금 한 돈)은 상업 이용 근거가 있는 무료 출처를 찾지 못했다(업비트 약관 영리 금지, data.go.kr 주식시세 공공누리 4유형, 실거래가 API 활용신청 전, 금 원자료 재배포 조건). 2026-10-21 사용자가 권장안을 승인했다: 스무 살 생일(아직 스무 살 전이면 태어난 날)에 100만 원을 현금·정기예금·달러·서울 아파트에 뒀다면 지금 어떻게 됐는지를 한국은행 ECOS 공식 통계로만 계산해 고정 순서로 보여 준다. 화면을 본 사용자가 "21살이면 의미가 없다"고 짚어, 같은 날 기준일을 "서른 살 생일이 지났으면 스무 살 생일, 아니면 태어난 날"로 바꿨다. 이어서 현금 칸을 빼고 같은 기간 물가를 칸 목록 아래 한 줄로 남겼다(아래 「결정」). 그날 밤 사용자 요청으로 꺼 두었던 금 한 돈 칸을 켰다(세계은행 Pink Sheet, CC BY 4.0 출처 표시, 원자료 권리는 출시 전 법무 확인). 이어서 사용자 지시("문제 없는 방향으로 모두 수정. ECOS 키 영리·비영리 문제만 남게")로 금을 한국은행 ECOS 404Y016 생산자물가지수 금괴로 바꾸고, 생일 기능 전체 문구·출처를 점검해 고쳤다(아래 「금 교체와 문구·출처 점검」). 2026-10-22에는 사용자 요청("생일 '그때 1억 원' 장면에 짜장면·버스 등 물가 배수 넣기")으로 KOSIS 서울 품목 지수 배수를 1억 원 장면에 더했다(아래 「1억 원 장면 품목 배수」). 서비스는 서울경제신문(영리법인)의 것이라 상업 이용으로 본다.

## 결정

- 기준일: 서른 살 생일이 지났으면(당일 포함) 스무 살 생일, 아니면 태어난 날(사용자 승인 2026-10-21). 처음 규칙(스무 살 생일이 지났으면 스무 살 생일)은 21살이 1년 치만 비교돼 의미가 없었다. 지금은 비교 기간이 늘 10년 이상(또는 태어난 뒤 전체)이다.
  - 서른 살 경계가 1996년생이라, 태어난 날 기준인 사람(1996년 10월 이후 출생)은 정기예금 기록(1996-01~)이 늘 있다.
  - 대가: 2006년 전에 태어난 서른 살 전(지금 20~29살)은 서울 아파트 칸(901Y089, 2006-01~)이 빠져 세 칸이 된다. 2036년이면 서른 살 전이 모두 2006년 이후 출생이라 이 빈칸은 사라진다.
  - 화면 lead는 이유를 먼저 쓴다: "서른 살부터는 스무 살 생일 기준이에요. …" / "서른 살 전이라 태어난 날(…)에 …". 제목("스무 살의 내가" / "태어난 날")과 영수증 소제목은 그대로 기준일 종류를 따른다.
- 현금 칸 제거, 물가 한 줄로(사용자 승인 2026-10-21, `06e85e42`).
  - 현금 칸은 막대가 늘 1배라 비교할 게 없었고, 영수증의 "현금 그대로 100만 원"은 누구에게나 같은 값이었다.
  - 1080×1920 영수증은 줄이 가장 많은 경우 높이를 거의 다 써서, 나중에 켤 금 한 돈 줄이 들어갈 자리가 필요했다. 현금 줄이 빠져 금을 켜도 100만 원 줄은 최대 4개(예금·달러·아파트·금)로 전과 같다.
  - 물가는 다른 칸을 읽는 기준이라 없애지 않고 칸 목록 아래 한 줄로 둔다. 1억 원 장면은 태어난 해 기준이고 100만 원 장면은 기준일 기준이라 기간이 다르므로, 물가 줄은 칸과 같은 기간(기준일이 속한 달 → 최신 물가)으로 계산한다.
  - 영수증에는 물가 줄을 넣지 않는다(이미 "그때 1억 원" 줄이 있다).
- 금 한 돈은 처음엔 코드(`gold`, `allowed=False`)만 두었다가 사용자 요청으로 켰다(`978c299f`, 세계은행 Pink Sheet). 같은 날 밤 원자료(LBMA 기준가)의 제3자 권리와 ICE 라이선스 요구를 확인하고, 금을 한국은행 작성 ECOS 404Y016 생산자물가지수 금괴로 바꿨다(`22ffbc21`). 칸 이름은 '금', 지수 비율로 계산하되 금은 소액 매수가 되므로 100만 원 기준 금액을 보이고, 생산자 가격이라 금은방 판매가와 다를 수 있다고 적는다. 1돈 단가 줄은 지웠다(1돈 반올림 문제도 함께 없어졌다).
- 아파트는 동향조사(901Y093/901Y149)와 섞지 않고 실거래가격지수(901Y089)만 쓴다. 두 계열은 2006-01~ 배수가 2.05배와 3.54배로 달라 이어 붙이면 왜곡된다.
- 1억 원 장면 품목 배수(2026-10-22): 기간은 1억 원 계산과 같은 태어난 해 연평균(`CPI_MONTHLY` 달은 그달) → `CPI_LATEST` 달로 맞췄다. 보고서는 태어난 달 월값을 권했지만, 한 장면에 두 기준이 생기면 "1억 원은 연평균, 짜장면은 그달"이 섞인다. 자료는 연평균이라 번들 정적 JSON으로 두고(요청 없음), 배수만 쓰며 서울 지수라고 밝힌다. 품목 줄의 지금 달이 `CPI_LATEST`와 다르면 목록을 그리지 않고, 테스트가 두 달이 같은지 확인한다.

### 월 1회 수동 갱신 절차

ECOS에 서울 아파트 실거래가격지수(901Y089) 새 달이 올라온 뒤 한 번 한다. 100만 원 칸 자료는 모두 ECOS다(금도 404Y016). 1억 원 장면 품목 배수(KOSIS)는 5단계에서 따로 본다.

1. 수집 실행(ECOS 키는 SSM에서 스크립트가 직접 읽는다. 키를 환경변수·명령줄·파일에 넣지 않는다):

   ```sh
   cd service/backend && AWS_DEFAULT_REGION=us-east-1 uv run --no-project --with boto3==1.35.0 --with requests==2.32.3 python scripts/build_birthday_assets.py
   ```

2. 확인:
   - 출력 줄의 `files=`가 연도 파일 수 + 1(`latest.json`)인지(2026년 기준 64), 계열별 마지막 시점(`cpi`·`deposit_rate`·`usdkrw_daily`·`usdkrw_monthly`·`apartment`·`gold`)이 지난번보다 앞으로 갔는지.
   - `git -C /Users/ldy/Desktop/Code/Sedaily/AILENS diff --stat -- service/frontend/public/data/birthday-assets/`로 바뀐 파일이 올해 연도 파일과 `latest.json` 정도인지. 오래된 연도 파일이 많이 바뀌면 ECOS가 과거값을 고친 것이니 커밋 전에 원인을 본다.
   - `latest.json` 값 2~3개(예: 마지막 달 CPI, 마지막 영업일 환율, 마지막 달 아파트·금괴 지수)를 ECOS 화면 값과 대조.
3. 커밋: 바뀐 파일을 이름으로만 스테이징하고 `git diff --cached --name-only`로 확인한 뒤 커밋한다(`git add -A`·`.`·`-u`, `commit -a` 금지).
4. 웹 배포(`service/frontend/deploy.sh`)는 사용자 확인 뒤에만 한다(ECOS 키 이용형태 확인 전에는 배포하지 않는다).
5. 1억 원 장면 품목 배수(2026-10-22 추가): 품목 자료의 지금 달은 1억 원 장면 `CPI_LATEST`(`…/birthday/data/birthdayCatalog.ts`, 지금 2026-09 고정)와 같아야 한다. 그래서 매달 자산 갱신 때는 다시 받지 않는다. `CPI_LATEST`를 새 달로 바꿀 때만 같은 달로 다시 받는다(KOSIS 키는 SSM `/sedaily-mbti/kosis-api-key`에서 스크립트가 직접 읽는다):

   ```sh
   cd service/backend && AWS_DEFAULT_REGION=us-east-1 uv run --no-project --with boto3==1.35.0 --with requests==2.32.3 python scripts/build_birthday_item_prices.py --now YYYY-MM
   ```

   - 출력 줄에 다섯 품목의 건수·마지막 달(= `--now`)이 나오는지, `git diff --stat`으로 `birthdayItemPrices.json` 하나만 바뀌었는지 본다. 지난 해 연평균이 여럿 바뀌면 KOSIS가 과거값을 고친 것이니 커밋 전에 원인을 본다.
   - `cd service/frontend && npm test` — `birthdayItemPrices.test.ts`가 품목 지금 달 = `CPI_LATEST.period`, 월값 달 = `CPI_MONTHLY` 키를 확인한다. 1990 화면 값 테스트는 지금 달이 바뀌면 함께 고친다.
   - 그달 KOSIS 값이 아직 없으면 스크립트가 파일을 쓰지 않고 멈춘다.
