## 배경

처음 기획한 다섯 칸(SK·삼성 주식, 비트코인, 서울 아파트 시세, 금 한 돈)은 상업 이용 근거가 있는 무료 출처를 찾지 못했다(업비트 약관 영리 금지, data.go.kr 주식시세 공공누리 4유형, 실거래가 API 활용신청 전, 금 원자료 재배포 조건). 2026-10-21 사용자가 권장안을 승인했다: 스무 살 생일(아직 스무 살 전이면 태어난 날)에 100만 원을 현금·정기예금·달러·서울 아파트에 뒀다면 지금 어떻게 됐는지를 한국은행 ECOS 공식 통계로만 계산해 고정 순서로 보여 준다. 화면을 본 사용자가 "21살이면 의미가 없다"고 짚어, 같은 날 기준일을 "서른 살 생일이 지났으면 스무 살 생일, 아니면 태어난 날"로 바꿨다. 이어서 현금 칸을 빼고 같은 기간 물가를 칸 목록 아래 한 줄로 남겼다(아래 「결정」). 그날 밤 사용자 요청으로 꺼 두었던 금 한 돈 칸을 켰다(세계은행 Pink Sheet, CC BY 4.0 출처 표시, 원자료 권리는 출시 전 법무 확인).

### 375px·1280px 확인

Playwright(시스템 Chrome, 375×812·1280×900, localhost 밖 요청 차단)로 10경우 × 2뷰포트 = 20회 실패 0건(1990·1955·1940·2010·1977생, 연도 공유 1990, 오류 → 복구, 로딩, 첫 화면, 2026-10-21생).

- 가로 넘침 없음. 보이는 글자 최소 13px(캡션), `.lead`·안내·오류 설명 16px, 제목 375px 24px·1280px 32px.
- 터치 타깃: 기사 보기 링크 79×44·91×44(간격 16px), 다시 불러오기 110×44. 키보드 포커스 `:focus-visible` solid 2px.
- 증감은 ▲ `(+N%)`·▼ `(−N%)`와 같은 회색 글자(색만으로 구분하지 않음). '1등'·'준비 중' 문구 없음.
- 로딩은 스켈레톤 + 스크린리더 상태 문구. 자산 요청은 경우마다 `{연도}.json`·`latest.json` 두 주소뿐(1940생·첫 화면 0건).
- 대비는 기존 클래스 색만 썼다(`.barDetail`·`.source` #6b7280/#fff ≈ 4.8:1, 링크 #1d4ed8/#fff ≈ 6.7:1). 자동 측정은 하지 않았다.
- 기준일 규칙 변경 뒤(`257befee`): 사용자 dev 서버(localhost:3000)에서 위 재검산 7경우 × 2뷰포트 = 14회 실패 0건. lead가 새 문구로 나오고, 가로 넘침 없음, 최소 13px·lead 16px, 요청은 기준일 연도 파일·`latest.json`뿐(1996-05-01생 → `2016.json`). 연도 공유 문장이 375px에서 '출생연도만 / 공유된', '넣었다고 / 보고', '1월 1일 / (2010년 1월 1일)'로 끊겨 `nb()`로 묶고 괄호를 뺐다. 1964년 이전 안내(1940생·연도 공유 1940)는 문구 그대로, 16px, 요청 0건.
- 현금 칸 제거 뒤(`06e85e42`): 위 재검산 6경우 + 2026-03-01생(물가 줄 % 표기) × 2뷰포트 = 14회 실패 0건. 칸 순서 정기예금 → 달러 → 서울 아파트, '현금' 문구 없음, 물가 줄은 칸 목록 바로 아래·출처 줄 위에 16px 한 줄(1944·1940생은 없음), 가로 넘침 없음, 최소 13px. 영수증은 1990-05-15에 금 응답과 가짜 1면 제목 2줄을 끼워 넣은 최대 줄 경우(100만 원 줄 4개)까지 하단 고지가 영수증 안에 든다.
- 금 켬 뒤(`978c299f`·`e027f3e6`, 자산 브랜치 작업 트리, 사용자 dev 서버 localhost:3000, 밖 요청은 모두 abort): 금 검산 6경우 + 1940-01-01 × 2뷰포트 = 14회 실패 0건. 칸 순서 정기예금 → 달러 → 서울 아파트 → 금 한 돈, 가로 넘침 없음, 보이는 글자 최소 13px(1940 안내 16px), 요청은 기준일 연도 파일·`latest.json`뿐. 금 칸이 보이는 10회 모두 두 출처 줄에 'Pink Sheet(CC BY 4.0)'이 한 줄 안에 있고, 2026-10-01·1940-01-01은 금 표기가 없다. 영수증은 실제 금 데이터로 최대 줄 경우(1990-05-15, 내 생일 넣기 켬, 1면 가짜 제목 2줄)를 그려 하단 고지가 영수증 안에 드는 것을 직접 봤다.

## 결정

- 기준일: 서른 살 생일이 지났으면(당일 포함) 스무 살 생일, 아니면 태어난 날(사용자 승인 2026-10-21). 처음 규칙(스무 살 생일이 지났으면 스무 살 생일)은 21살이 1년 치만 비교돼 의미가 없었다. 지금은 비교 기간이 늘 10년 이상(또는 태어난 뒤 전체)이다.
  - 서른 살 경계가 1996년생이라, 태어난 날 기준인 사람(1996년 10월 이후 출생)은 정기예금 기록(1996-01~)이 늘 있다.
  - 대가: 2006년 전에 태어난 서른 살 전(지금 20~29살)은 서울 아파트 칸(901Y089, 2006-01~)이 빠져 세 칸이 된다. 2036년이면 서른 살 전이 모두 2006년 이후 출생이라 이 빈칸은 사라진다.
  - 화면 lead는 이유를 먼저 쓴다: "서른 살부터는 스무 살 생일 기준이에요. …" / "서른 살 전이라 태어난 날(…)에 …". 제목("스무 살의 내가" / "태어난 날")과 영수증 소제목은 그대로 기준일 종류를 따른다.
- 현금 칸 제거, 물가 한 줄로(사용자 승인 2026-10-21, `06e85e42`).
  - 현금 칸은 막대가 늘 1배라 비교할 게 없었고, 영수증의 "현금 그대로 100만 원"은 누구에게나 같은 값이었다.
  - 1080×1920 영수증은 줄이 가장 많은 경우 높이를 거의 다 써서, 나중에 켤 금 한 돈 줄이 들어갈 자리가 필요했다. 현금 줄이 빠져 금을 켜도 100만 원 줄은 최대 4개(예금·달러·아파트·금)로 전과 같다.
  - 물가는 다른 칸을 읽는 기준이라 없애지 않고 칸 목록 아래 한 줄로 둔다. 1억 원 장면은 태어난 해 기준이고 100만 원 장면은 기준일 기준이라 기간이 다르므로, 물가 줄은 칸과 같은 기간(기준일이 속한 달 → 최신 물가)으로 계산한다.
  - 영수증에는 물가 줄을 넣지 않는다(이미 "그때 1억 원" 줄이 있다).
- 금 한 돈은 처음엔 코드(`gold`, `allowed=False`)만 두었다가 사용자 요청으로 켰다(`978c299f`). Pink Sheet는 CC BY 4.0이라 상업 이용이 되고 출처·라이선스 표시가 의무라서, 금 칸이 보일 때 두 출처 줄에 "세계은행 Pink Sheet(CC BY 4.0)"를 적는다. 원자료(Bloomberg·LBMA 등)의 제3자 권리는 세계은행이 보증하지 않아 출시(웹 배포) 전에 법무 확인을 받는다.
- 아파트는 동향조사(901Y093/901Y149)와 섞지 않고 실거래가격지수(901Y089)만 쓴다. 두 계열은 2006-01~ 배수가 2.05배와 3.54배로 달라 이어 붙이면 왜곡된다.
- 첫 화면 제목 "내 생일에 샀다면, 지금은?"은 이번에 바꾸지 않았다(D11, 사용자 확인 대상).

   - 출력 줄의 `files=`가 연도 파일 수 + 1(`latest.json`)인지(2026년 기준 64), 계열별 마지막 시점(`cpi`·`deposit_rate`·`usdkrw_daily`·`usdkrw_monthly`·`apartment`·`gold`)이 지난번보다 앞으로 갔는지.
   - `latest.json`의 `gold`가 엑셀 마지막 금값 달·값과 같은지(금·환율 월평균이 둘 다 있는 달을 쓰므로, 환율 월평균이 아직 안 나왔으면 엑셀 마지막 달보다 한 달 이전일 수 있다). 엑셀 `Mismatch Details` 시트에 금(Gold) 행이 있으면 과거 금값이 고쳐진 것이니 바뀐 연도 파일을 본다.
   - `git -C /Users/ldy/Desktop/Code/Sedaily/AILENS diff --stat -- service/frontend/public/data/birthday-assets/`로 바뀐 파일이 올해 연도 파일과 `latest.json` 정도인지. 오래된 연도 파일이 많이 바뀌면 ECOS가 과거값을 고친 것이니 커밋 전에 원인을 본다.
   - `latest.json` 값 2~3개(예: 마지막 달 CPI, 마지막 영업일 환율, 마지막 달 아파트 지수)를 ECOS 화면 값과 대조.
4. 커밋: 바뀐 파일을 이름으로만 스테이징하고 `git diff --cached --name-only`로 확인한 뒤 커밋한다(`git add -A`·`.`·`-u`, `commit -a` 금지).
5. 웹 배포(`service/frontend/deploy.sh`)는 사용자 확인 뒤에만 한다(금 법무 확인 전에는 배포하지 않는다).

이 절차를 예약 실행(EventBridge·Lambda 등)이나 별도 저장소(S3 등)로 옮기면, 리소스를 만들기 전에 [`docs/architecture/비용태깅_규칙.md`](../../architecture/비용태깅_규칙.md)를 다시 읽고 `Service` 태그를 붙인다. 2026-10-01 이후 새로 만드는 것은 `Service=lens`다(2026-09-30까지는 `atlas4`). 태그는 소급되지 않으니 생성 시점에 붙이고 생성 뒤 실제 태그를 재조회한다.
