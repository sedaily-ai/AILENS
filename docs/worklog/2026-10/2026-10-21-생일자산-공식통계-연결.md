### 375px·1280px 확인

Playwright(시스템 Chrome, 375×812·1280×900, localhost 밖 요청 차단)로 10경우 × 2뷰포트 = 20회 실패 0건(1990·1955·1940·2010·1977생, 연도 공유 1990, 오류 → 복구, 로딩, 첫 화면, 2026-10-21생).

- 가로 넘침 없음. 보이는 글자 최소 13px(캡션), `.lead`·안내·오류 설명 16px, 제목 375px 24px·1280px 32px.
- 터치 타깃: 기사 보기 링크 79×44·91×44(간격 16px), 다시 불러오기 110×44. 키보드 포커스 `:focus-visible` solid 2px.
- 증감은 ▲ `(+N%)`·▼ `(−N%)`와 같은 회색 글자(색만으로 구분하지 않음). '1등'·'준비 중' 문구 없음.
- 로딩은 스켈레톤 + 스크린리더 상태 문구. 자산 요청은 경우마다 `{연도}.json`·`latest.json` 두 주소뿐(1940생·첫 화면 0건).
- 대비는 기존 클래스 색만 썼다(`.barDetail`·`.source` #6b7280/#fff ≈ 4.8:1, 링크 #1d4ed8/#fff ≈ 6.7:1). 자동 측정은 하지 않았다.

### 월 1회 수동 갱신 절차

ECOS에 서울 아파트 실거래가격지수(901Y089) 새 달이 올라온 뒤 한 번 한다.

1. 수집 실행(ECOS 키는 SSM에서 스크립트가 직접 읽는다. 키를 환경변수·명령줄·파일에 넣지 않는다):

   ```sh
   cd service/backend && AWS_DEFAULT_REGION=us-east-1 uv run --no-project --with boto3==1.35.0 --with requests==2.32.3 --with openpyxl==3.1.5 python scripts/build_birthday_assets.py
   ```

2. 확인:
   - 출력 줄의 `files=`가 연도 파일 수 + 1(`latest.json`)인지(2026년 기준 64), 계열별 마지막 시점(`cpi`·`deposit_rate`·`usdkrw_daily`·`usdkrw_monthly`·`apartment`)이 지난번보다 앞으로 갔는지.
   - `git -C /Users/ldy/Desktop/Code/Sedaily/AILENS diff --stat -- service/frontend/public/data/birthday-assets/`로 바뀐 파일이 올해 연도 파일과 `latest.json` 정도인지. 오래된 연도 파일이 많이 바뀌면 ECOS가 과거값을 고친 것이니 커밋 전에 원인을 본다.
   - `latest.json` 값 2~3개(예: 마지막 달 CPI, 마지막 영업일 환율, 마지막 달 아파트 지수)를 ECOS 화면 값과 대조.
3. 커밋: 바뀐 파일을 이름으로만 스테이징하고 `git diff --cached --name-only`로 확인한 뒤 커밋한다(`git add -A`·`.`·`-u`, `commit -a` 금지).
4. 웹 배포(`service/frontend/deploy.sh`)는 사용자 확인 뒤에만 한다.

이 절차를 예약 실행(EventBridge·Lambda 등)이나 별도 저장소(S3 등)로 옮기면, 리소스를 만들기 전에 [`docs/architecture/비용태깅_규칙.md`](../../architecture/비용태깅_규칙.md)를 다시 읽고 `Service` 태그를 붙인다. 2026-10-01 이후 새로 만드는 것은 `Service=lens`다(2026-09-30까지는 `atlas4`). 태그는 소급되지 않으니 생성 시점에 붙이고 생성 뒤 실제 태그를 재조회한다.
