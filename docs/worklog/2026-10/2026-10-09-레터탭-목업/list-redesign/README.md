# 레터 목록 화면 재구성 (2026-10-09 밤)

## 문제
- 레터 탭에 들어가면 소개 문구, 분류 칩, 검색, 관심사 안내 카드가 레터보다 먼저 쌓여 첫 레터가 화면 아래로 밀렸다
- 관심사를 고르면 "내 관심사 레터"가 별도 구역으로 생겨 아래 목록과 같은 카드가 두 번 나왔다
- 메일 신청 폼이 목록 한가운데 큰 박스로 끼어들었다

## 개선
| 구분 | 이전 | 이후 |
|---|---|---|
| 상단 | 큰 소개, 칩, 검색이 세 줄 | 소개 두 줄 + 분류 칩과 검색을 한 줄 도구줄로 |
| 관심사 | 큰 안내 카드, 선택 후 중복 추천 구역 | 얇은 한 줄 바(내 관심사 칩, 관심사 레터만 N, 수정, 메일로 받기) |
| 추천 표시 | 별도 구역 | 같은 목록(최신순 유지)의 카드에 "왜 맞는지" 한 줄만 덧붙임 |
| 메일 신청 | 목록 중간 큰 박스 | 바의 "메일로 받기"를 눌렀을 때 바 아래로 펼침 |
