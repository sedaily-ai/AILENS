# 2026-10-15 모바일 앱 웹 디자인 정합

작성: 사용자 + Claude Code
관련: PR #116(`fix/mobile-design-parity`), `docs/architecture/apps-mobile-홈-설계.md`

## 배경

앱 1차 이식 뒤 "글꼴·투표 애니메이션·스타일이 웹과 다르다, 영상이 왼쪽으로 쏠린다, 용어 해설이 촌스럽다"는 지적이 있었다. 웹앱 뷰에서는 같게 보였으나 Expo 네이티브 화면에서 어긋난 것이다.

## 한 것

- 글꼴: Pretendard 5굵기 + Noto Serif KR Bold를 한글 KS X 1001 2,350자 + 라틴 서브셋(약 3.6MB)으로 `apps/mobile/assets/fonts`에 포함. `src/ui/Text.tsx` 래퍼가 `fontWeight`를 굵기별 글꼴 이름으로 변환(안드로이드는 커스텀 글꼴에서 fontWeight가 먹지 않음). 모든 화면의 Text/TextInput 교체, 루트에서 `useFonts`.
- 기사 상세: 머리 순서를 웹과 동일하게(카테고리·"4가지 시선" → 세리프 제목 → 리드 → 바이라인 → 사진 캡션 → 30초 핵심 → 형식 선택기 → 본문), 형식 선택기 알약 슬라이드.
- 레터 본문을 웹 `.lread` 규격으로 재작성, 투표 `PollOptions`(막대 0.8초 차오름·70ms 지연·숫자 카운트업·체크 그리기) 공용화, 용어 말풍선 `TermPopover`.
- 영상 왼쪽 쏠림 원인: 음수 마진 + `aspectRatio`(안드로이드) → 칼럼 폭 안 배치로 수정.
- `react-native-svg` 추가: 손으로 그은 구분선, 불규칙 타원 모서리 면, 투표 체크 경로를 웹 SVG와 같은 값으로 재현(`src/ui/Hand.tsx`).
- 확인 환경: 안드로이드 에뮬레이터(Pixel 7급, `ailens_pixel`)를 만들어 개발 빌드 APK를 설치하고 Metro(`10.0.2.2:8081`)에 연결, `adb screencap`으로 앱 화면을 직접 확인. 웹 기준 화면은 headless Chrome 모바일 폭 캡처.

## 결정

- 용어 형광펜은 글자 아래 55%만 칠하기가 인라인 텍스트에서 불가능해 옅은 노란 면으로 근사.
- 웹 UI 컴포넌트는 재사용하지 않고 앱에서 새로 만들고, 로직만 `@ailens/domain`으로 공유(기존 방침 유지).
