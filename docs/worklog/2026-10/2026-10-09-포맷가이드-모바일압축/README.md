# 2026-10-09 "오늘 이슈, 어떻게 볼래요?" 모달 모바일 압축

작성: 문영광 + Claude Code
대상: `service/frontend/src/features/news-feed/components/cards/LensFormatGuide.tsx`(홈 "눌러서 미리 보기")

## 문제
- 작은 폰에서 모달이 한 화면에 안 들어와 스크롤이 생기고, 하단 CTA("지금 웹툰 보러 갈래요")가 화면 밖으로 잘림
- 로컬 Chrome(원격 디버깅, 모바일 에뮬레이션 DPR 2)로 열어서 실측

## 실측(패널 높이 / 내용 높이, 스크롤 여부)

| 화면 | Before | After |
|---|---|---|
| 390×844 | 711 / 711, 스크롤 없음(화면의 약 84%) | 471 / 471, 없음(약 56%) |
| 375×667 | 614 / 679, 스크롤 있음(65px, CTA 잘림) | 470 / 470, 없음 |
| 360×640 | 589 / 679, 스크롤 있음(90px) | 469 / 469, 없음 |
| 320×568 | 523 / 775, 스크롤 있음(252px) | 511 / 511, 없음 |
| 데스크톱 1280×900 | 666 / 666 | 666 / 666(변화 없음) |

## 변경
- 폭 480px 이하 또는 높이 760px 이하에서만 압축 적용(데스크톱은 그대로)
- 여백·제목·그림(96×76 → 68×54)·글자 크기를 줄이고, 선택되지 않은 행은 제목·시간만 보이고 설명은 선택된 행에만 표시
- 하단 CTA 버튼을 패널 안에서 고정(sticky)해 내용이 길어져도 항상 보이게 함
- iOS 주소창 높이를 반영하도록 `92vh` 대신 `92dvh`(지원 시)
