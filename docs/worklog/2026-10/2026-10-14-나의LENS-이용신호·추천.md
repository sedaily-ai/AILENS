# 나의 LENS 이용 신호·추천·홈 집계

## 배경

계정 저장만으로는 브라우저 밖의 이용 기록이나 뉴스 본문의 등록 용어를 개인화에 연결할 수 없었다. 서버에서 계정의 약한 이용 신호와 콘텐츠 메타데이터를 집계하고 직접 관심·저장 문장과 함께 추천하도록 확장한다.

## 한 것

- 세션/이벤트/계정 view SQL과 원자적 저장·소유권·중복·시간/빈도 검증을 추가했다.
- 공개 콘텐츠의 경량 메타데이터, 90일 서로 다른 콘텐츠 집계와 저장 문장 단어 입력을 서버에서 조회한다.
- 직접 선택/관찰/저장 문장 근거를 나눈 뉴스·레터 규칙 추천, 문장별 관련 글과 홈 집계 API를 구현했다.
- 실제 상세의 visible/활성 형식을 수집하고 대시보드·근거 필터·문장 관련 글을 서버 응답에 연결했다.
- 첫 묶음의 신규 계정 동시 생성 충돌도 보완했다.
- 최신 구현 범위와 API·SQL·프론트·운영 후속 사항을 제품 문서에 반영했다.

## 결정

- 약한 열람 신호와 완료/리워드 판정을 분리한다. method=exact로 표시하고 의미 모델은 추가하지 않는다.
- 운영 DB·AWS·배포·커밋·push는 이번 작업에 포함하지 않는다.
- 문장/등록 용어 근거가 없는 필터 추천에 무관한 최신 글을 넣지 않는다.
