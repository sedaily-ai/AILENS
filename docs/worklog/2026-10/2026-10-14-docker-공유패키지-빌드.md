# Docker 프론트 빌드의 공유 패키지 누락 수정

## 배경

Docker 설치 후 사용자가 실행한 배포가 이미지 빌드 단계에서 `@ailens/api-client`와 `@ailens/auth`를 찾지 못해 실패했다. 두 패키지는 `dist/index.js`를 공개하지만 Dockerfile이 `domain`만 빌드하고 있었다. `.dockerignore`는 로컬 dist를 제외하므로 로컬 프론트 빌드에서는 드러나지 않던 누락이다.

## 한 것

- `service/frontend/Dockerfile`에서 프론트 빌드 전에 domain → api-client → auth 순서로 공용 패키지 세 개를 빌드하도록 수정했다.
- 빌드가 필수인 패키지에는 `--if-present`를 쓰지 않아 빌드 스크립트 누락을 즉시 실패로 처리한다.

## 결정

- Dockerfile의 빌드 순서만 변경한다. 대시보드 관련 파일, 앱 코드, AWS 배포 설정은 수정하지 않는다.

## 다음

- 수정한 Dockerfile을 배포 빌드에 반영한다. ECR push와 ECS 배포는 별도 작업으로 진행한다.
