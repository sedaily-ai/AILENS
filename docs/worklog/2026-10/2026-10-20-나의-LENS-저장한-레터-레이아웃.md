# 나의 LENS 저장한 레터 레이아웃

## 배경

내 서랍의 저장한 레터가 제목과 작성자 문자열만 표시해 실제 레터 탭과 차이가 컸다. 레터 탭처럼 에디터 사진을 함께 보여 달라는 요청을 반영했다.

## 한 것

- `DashboardLetter`에 상세 목록 표시 옵션을 추가하고 `DrawerPanel`의 저장한 레터에서 사용한다.
- 레터 탭의 `EditorAvatar`와 날짜 표시 함수를 공개 API로 재사용한다. 발행일, 명조체 제목, 두 줄 요약, 에디터 사진·이름, 기사 수, 주제 태그를 표시한다.
- 에디터 이름 뒤에 일괄 추가하던 ‘에디터’를 제거해 중복 표기를 없앴다.
- 서랍 전용 스타일로 여백과 모바일 제목 크기를 조정하고 북마크 클릭 영역을 44px로 확보했다.
- `npx tsc --noEmit`, 변경 파일 ESLint, `git diff --check`, `npm run build --workspace=service/frontend` 통과. 빌드 중 외부 API DNS 조회 실패 경고가 있었으나 정적 페이지 생성과 빌드는 완료됐다.
- 실제 컴포넌트를 사용한 로컬 Chrome 검증: 1440/768/390/320px에서 사진 2개 로드, 요약·주제 표시, 가로 넘침 없음 확인. 북마크 콜백, 에디터 링크, 메타데이터 없는 항목도 검증했다. 1440/390px 캡처를 직접 확인했다.

## 결정

- 에디터가 없는 레터는 AI LENS로 표시하고 사진을 추정하지 않는다. 기사 수가 제공되지 않고 소스 목록도 비어 있으면 기사 수를 생략한다.
- 주제 태그는 정보 표시용으로 둔다. 저장한 기사에는 이 스타일을 적용하지 않는다.
- 홈의 기존 카드 크기는 유지하고 내 서랍의 저장한 레터에서 상세 목록 옵션을 켠다.
