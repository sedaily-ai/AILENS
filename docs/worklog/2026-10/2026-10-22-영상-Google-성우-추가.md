# 2026-10-22 영상·PRISM 음성에 Google(Gemini) 성우 추가

작성: 김현지 + Claude Code
관련: 브랜치 `feat/google-tts-voices`, 시크릿 `ai-labs/google-tts`, 작업 정의 `sedaily-lens-video-lab:8`

## 배경

마케팅팀이 PRISM 영상 음성을 Polly 말고 구글 AI 스튜디오 음성으로 바꾸고 싶어 했다. 성우를 하나로 고정하지 말고 전부 넣어 그때그때 고르게 해 달라는 요청. AI 스튜디오 음성은 Gemini TTS API로 그대로 쓸 수 있다.

## 한 것

- `pipelines/common/google_tts.py` 신설 — Gemini TTS 호출(모델 `gemini-3.8-flash-tts`, 성우 30종). 응답은 WAV(24kHz·모노).
- `pipelines/video/src/lib/tts.ts` — 제공자 `google` 추가. WAV를 ffmpeg로 mp3로 바꿔 기존 경로(캐시·S3 업로드)를 그대로 쓴다.
- `pipelines/video/src/lib/resolveAudio.ts` — Google이 한 컷이라도 끝내 실패하면 **영상 전체**를 발행 설정의 Polly 성우로 다시 읽는다. 하루 할당량 소진(429, 재시도 대기 20초 초과)·키 오류는 재시도 없이 바로 넘어간다.
- `pipelines/common/video_settings.py` — 설정 문서에 `GOOGLE_VOICE`, provider `google`. 렌더 환경변수 `GOOGLE_TTS_*`. 키를 못 읽어도 렌더는 막지 않는다.
- `admin/backend/routes/chat_ws.py` — 미리듣기 `provider=google`(WAV를 그대로 S3에 올려 재생), 렌더 override.
- CMS 화면 — 영상 탭·PRISM 탭의 제공자를 **Polly / Google**로(ElevenLabs는 화면에서만 숨김, 코드는 유지). 팟캐스트는 그대로 Polly/ElevenLabs.
- AWS
  - 시크릿 `ai-labs/google-tts`(887078546492) — 회사 구글 계정 AI Studio에서 만든 키.
  - IAM: `sedaily-mbti-admin-api-dev-role`(AdminPromptTestOpenAIKeyRead), `sedaily-lens-frontpage-auto-task-role`(frontpage-auto-access)의 기존 시크릿 읽기 문장에 위 ARN 추가.
  - 배포: CMS 백엔드 Lambda, CMS 화면, 실험실 영상 렌더 이미지 `video-lab-google-20261022b` → `sedaily-lens-video-lab:8`. LENS 자동 발행(`:latest`)은 손대지 않았다.

## 결정

- 표기는 "Google"(Polly와 나란히). AI 스튜디오 음성 = Gemini TTS.
- 팟캐스트는 이번 범위에서 제외 — 음성 코드가 별도(파이썬)이고 대본이 길어 따로 검증이 필요.
- 실패 시 컷 단위가 아니라 영상 전체를 Polly로 — 컷마다 바꾸면 한 영상 안에서 목소리(성별까지)가 섞인다.
- 결제 연결은 나중에(사용자 결정). 기능부터 완성.

### 추가: LENS 자동 발행 반영(같은 날 오후)

- 사용자 요청: "CMS에서 적용한 음성이 자동 파이프라인에도 반영돼야 한다".
- IAM: `sedaily-lens-mustknow-auto-task-role`(mustknow-auto-access)에 `ai-labs/google-tts` 읽기 추가.
- `sedaily-lens-frontpage-auto:latest`를 `video-lab-google-20261022b`(커밋 3fec9c6f)로 교체 — 새 빌드 없이 ECR에서 이름표만 옮김(digest `sha256:fc33da1c…`). 직전 latest는 `typofix-6d012b43`(`sha256:1e5cea9e…`). 6d012b43 이후 pipelines/ 변경은 이번 Google 작업뿐이라 다른 변경은 섞이지 않았다.
- LENS 설정(video-settings)은 Polly 서연 그대로라 목소리는 안 바뀐다. CMS LENS 영상 탭에서 Google로 저장하면 다음 자동 발행부터 반영(결제 연결 전에는 Polly로 나감).
- 되돌리기: scratchpad `lens_step2_latest.py rollback`과 같은 방식으로 `typofix-6d012b43`에 latest를 다시 붙인다.
