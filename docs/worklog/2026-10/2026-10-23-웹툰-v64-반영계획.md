# 웹툰 v64 반영 계획

## 배경

사용자가 v64 신규 버전 생성·운영 반영·커밋·push·PR 생성·병합과 동일 버전의 모델 비교 PDF 갱신을 승인했다. v63와 이미지 설정 v30이 기준이다. R2는 로컬 추가 지침이며 CMS 버전이 아니다.

## 한 것 / 실행 순서

- [x] 최신 main과 CMS active/latest 63·30, 초안 및 기존 파일 백업 확인.
- [x] v63 계약을 유지하면서 기사별 핵심 소품, 장면 다양성, 외형·옷깃 고정, 수치 분모·발사/운용 관계 검수 규칙을 v64 본문에 통합.
- [x] 원보도 두 건으로 CMS의 실제 요청 구성 함수를 거쳐 대본 생성. 전체 16컷의 근거·조건·대사와 1·4·8컷 지문 검수.
- [x] 같은 지문으로 Ultra·SD 3.5·Codex 참고 시안 각 6장 생성. 비용·시간·해상도·이미지 결함 기록.
- [x] 본문 해시가 일치하는 v64 저장·활성화 및 공개 API·CMS 초안 조회 검증. v30 유지.
- [x] PDF 교체, 전 페이지 렌더 검수, 기존 Desktop PDF 백업.
- [ ] 관련 정본·평가 기록·worklog만 커밋·push·PR·병합 후 원격 상태 확인.

## 결정

- 제품 코드 변경 없이 CMS 프롬프트 데이터 배포로 처리한다. 운영 본문·실제 생성 입력 해시가 같아야 한다.
- 직전 비교의 AI LENS 재작성 본문과 이번 원보도 본문은 다르다. 프롬프트만의 통제 실험으로 주장하지 않는다.
- Codex 이미지의 정확한 모델 ID는 미노출이다. 특정 GPT 모델이나 Bedrock GPT 결과로 표시하지 않는다.
- 얼굴·배경·무문자 일치와 확대 무손실을 보장하지 않는다. 불합격 컷을 숨기거나 재생성 비용을 누락하지 않는다.

## 다음 / 검증 초점

1. 거래 비중과 주택·공실 비율을 혼동하지 않는지 원문과 화면 글을 대조한다.
2. 계획을 완료로, 함께 운용을 함께 발사로 바꾸지 않는지 대조한다.
3. 주제 소품과 의상·인물의 실제 변화는 이미지를 열어 기록한다.
4. 이미지 v30의 기존 비율·합성 계약을 유지하고 대본 구조 검증을 실행한다.
5. 저장·활성화 직전 동시 변경을 확인한다. GPT 제공 여부·비용은 공식 근거와 실제 계정 조회 범위를 구분한다.
