# 2026-10-14 나의 LENS 계정 알림·동의·푸시 연결

관련: `feat/my-lens-account-storage`, [구현 상태](../../product/나의LENS/알림·푸시_구현상태.md)

## 배경

계정 저장·추천·완료/리워드 묶음에 이어 개인화 알림을 계정 설정부터 전달 원장까지 연결한다. 운영 DB·배포·실제 발송은 이번 요청 범위에서 제외한다.

## 한 것

- v1.51 SQL에 계정 알림 설정·동의/감사·암호화 구독·전달/기기 대상 원장·편집 승인 후속 관계를 추가했다.
- 기존 공개 Lambda와 내부 FastAPI 구조에 알림 저장·동의/철회·기기 연결/해제·서버 미리보기 API를 추가했다.
- 선택 source 기반 뉴스·레터 후보, 일정 계획, DB lease, 전송 직전 조건 검사, 결과 분류를 구현했다. 별도 oneshot worker와 기본 dry_run/live adapter를 추가했다.
- 프론트 설정·명시적 동의·기기 상태·서버 후보/상태·로그아웃 해제, Web Push 전용 service worker를 연결했다. 기존 이메일 구독은 별도 유지한다.
- 실제 API·SQL·환경 변수·미적용 운영 작업을 구현 문서로 정리했다.

## 결정

- 설정 저장·수신 동의·브라우저 권한·구독·provider 접수·기기 수신은 각각 구분한다.
- 저장 문장 source는 기본 꺼짐, 후속 관계는 편집 승인 필요, 무관한 최신 글을 알림 후보로 채우지 않는다.
- default dry_run은 외부 전송 없이 simulated 원장을 사용한다. 결과 미확정 timeout/lease는 자동 재전송하지 않는다.
- 초기 전송은 단일 DB lock으로 직렬화한다. 규모 확대 시 lock 순서·공정한 worker 분할은 별도로 개선한다.

## 다음

- 별도 운영 승인 후 SQL/권한·Gateway·배포·비밀 공급/회전·편집 관계/품질 기준·worker 스케줄/관제를 인수한다.
- 승인된 기기의 실제 권한·provider 접수·수신을 확인한다. 이번 요청은 실제 발송을 포함하지 않는다.
