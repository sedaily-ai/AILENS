# 사용자 웹 통합·반영 상태

## 배경

- 사용자 웹 잔여 구현은 [PR #120](https://github.com/sedaily-ai/AILENS/pull/120)으로 병합됐다. 최신 로컬 `main`과 원격 기준은 `28f4b7fef3f3e0ca5247b49be9388717af68feb2`이다.
- 이번 후속 작업은 `docs/remove-obsolete-web-audit-records`에서 중복된 과거 검증·조사·준비 기록을 정리한다. 제품 코드·테스트·설정과 운영 데이터는 변경하지 않는다.

## 한 것

- PR #120에 포함됐던 과거 기록 14개를 현재 로컬 작업 트리에서 삭제했다. 별도 보관본을 새로 만들지 않았다. 기존 Git 이력은 재작성하지 않는다.
- 이 통합 기록에 현재 반영 상태와 필요한 후속 조건을 남겼다. 삭제 문서를 참조하던 배포 안내와 P01·P02 기록은 유효한 참조로 정리했다. 새 검증 보고서 파일을 추가하지 않는다.
- PR #118·#119의 원래 작업 기록은 유지한다. PR #119 배포 뒤 운영에서 내 서랍 조회·영상 29초 표시·나의 LENS 네 탭·미디어 전환을 관찰했다. 새 로그인·운영 장애 강제 주입·컨테이너 SHA 대조까지 검증한 것은 아니다.

| 반영 내용 | Git 상태 | 운영 상태 |
| --- | --- | --- |
| 오류·린트, 화면 정리 1~7, E01~E04, N01 프론트 | PR #118 병합 | 사용자 배포 완료 통보 후 주요 흐름 확인 |
| P01 내 서랍 조회 복구·P02 미디어 시간 표시 | PR #119 병합 | 사용자 배포 완료 통보 후 위 시나리오 확인 |
| F19 기사 용어의 CMS 목록·요약 → 단어장 전달 | PR #120 병합 | 이번 통합분 배포·운영 검증은 아직 확인하지 않음 |
| N01 탭별 계정 API 집계 | PR #120 병합 | 이번 통합분 배포·운영 검증은 아직 확인하지 않음 |
| 기사 5건 정정안·기본 읽기 전용 검사·릴리스 포함 | PR #120 병합 | 실제 데이터 정정은 미실행·보류 |

- 보존 브랜치 `chore/preserve-local-main-20261016`의 6개 커밋(`ec3e3cba`까지)은 과거 원본 이력이다. 해당 제품 변경은 PR #118·#120에 반영되어 추가 push·병합할 구현이 아니다. 이 브랜치는 변경하지 않았다.
- PR #120 당시 검증: 프론트 162개, 계정 API 49개, CMS 관련 19개, 로컬 DB 10개 통과. 린트·타입·빌드·pyflakes 및 모의 계정·저장소 기반 내부 브라우저 단어장·네 탭 확인을 마쳤다. DB 시험은 PostgreSQL 17.11이며 운영 PostgreSQL 16 검증과 구분한다. 이번 문서 정리에서 다시 실행한 결과는 아니다.
- 이번 자체 검토에서 삭제 대상 14개의 부재와 전체 추적 파일의 잔여 참조 없음, 수정 문서의 로컬 링크 3개, `git diff --check` 통과를 확인했다. 변경은 문서 17개뿐이며 제품 코드·테스트·설정은 그대로다. 실행·UI 변경이 없어 제품 테스트·빌드·브라우저 검증은 반복하지 않았다.

## 결정

- 관리자 웹과 다음 다이어트 후보는 제외한다. 기록 정리만으로 배포나 기사 정정을 실행하지 않는다.
- 기사 정정 대상은 `20101714`, `20101638`, `20101715`, `20101767`, `20099924`의 13개 필드다. 최신 운영 값 재대조, 백업 내구성·적용 영수증·조건부 복구·동시 편집 보호가 준비되지 않아 실제 적용을 보류한다. 기본 읽기 전용 도구와 수동 적용 옵션의 존재가 운영 실행 승인이나 준비 완료를 뜻하지 않는다.
- 이번 통합 변경에는 새 DB DDL·의존성·환경변수 계약이 없다. 기사 정정 도구는 CMS 배포로 자동 실행되지 않는다.

## 다음

1. 문서 정리 PR을 검토·병합한다. 이 문서만의 정리는 서비스 재배포가 필요하지 않다.
2. PR #120의 기능을 반영하려면 승인된 환경에서 CMS API → 계정 API → 프론트 순서로 배포하고 각 상태를 확인한다. 프론트만 배포하면 전체 연결이 완료되지 않는다.
3. 운영에서 단어장 실제 용어·검색·원문 이동, 나의 LENS 네 탭·설정값 보존·실패 시 복구, 기존 P01·P02·미디어 전환을 재확인한다.
4. 기사 5건의 운영 정정은 별도 준비·승인 대상으로 남긴다. 다음 다이어트 후보는 보류한다.
