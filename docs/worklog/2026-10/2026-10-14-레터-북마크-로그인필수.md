# 2026-10-14 레터 북마크 로그인 필수와 계정 대시보드 표시

관련: feat/my-lens-account-storage · [레터 북마크 계약](../../product/모아쓰기레터/북마크_동기화_연동요구사항.md)

## 배경

계정 북마크 API는 구현됐지만 공개 레터의 비로그인 브라우저 저장 분기가 남아 있었다. 북마크를 로그인 후 계정에 저장한다는 정책에 맞추고 오래된 연동 요구사항을 현재 코드로 갱신한다.

## 한 것

- 공통 저장 훅에서 비로그인 저장·해제를 차단하고 기존 로그인 안내 dialog를 북마크에서도 사용한다.
- 로그인 복귀 주소의 query·hash를 유지하고 로그인 후 자동 저장하지 않는다.
- 기존 공용 브라우저 북마크는 조회용으로 보존한다. 서버 계정 목록과 자동 병합하거나 삭제하지 않는다.
- 상세의 저장 분석 이벤트는 서버 성공이 확정된 뒤 기록한다.
- 대시보드 홈과 내 서랍의 저장한 레터는 서버가 제공한 최근 저장순을 그대로 사용한다.
- 북마크 전용 문서를 현재 API·테이블·인증·보존·대시보드 흐름으로 교체하고 관련 인수 문서의 최신 정책 링크를 갱신한다.

## 결정

- 공개 레터 열람·메일 구독·글자 크기·브라우저 읽음 표시는 유지한다.
- 기존 브라우저 데이터의 계정 가져오기는 별도 후속 범위다.
- 운영 DB·배포·실제 외부 발송은 수행하지 않는다.

## 다음

- 운영 반영 시 기존 대시보드 마이그레이션과 개인 API Gateway 경로를 별도 인수한다.
