# 나의 LENS 저장한 기사 레이아웃

## 배경

홈 추천 뉴스에서 정리한 기사 제목·요약·여백을 내 서랍의 저장한 기사에도 적용해 달라는 요청을 반영했다. 기존 저장 기사는 레터용 클래스를 사용해 요약이 숨겨지고 제목 크기와 간격이 달랐다.

## 한 것

- `DashboardArticle.tsx`를 추천 뉴스의 `ml-news-item`, `ml-news-meta`, `ml-news-context` 스타일에 연결했다. 제목 옆 이동 아이콘과 두 줄 요약을 표시한다.
- 분야 옆에 저장일을 표시하고 오른쪽에 기존 저장 해제 버튼을 둔다. 저장 해제 중 비활성화와 공개 종료 안내를 유지한다.
- `myLensNewsStyles.ts`의 공통 제목 규칙을 저장한 기사의 공개 종료 제목에도 적용한다. 제목은 데스크톱 20px, 600px 이하 18px이며 간격과 요약도 추천 뉴스와 같은 규칙을 사용한다.
- `myLensDrawerStyles.ts`에는 저장 기사 상단 배치와 44px 저장 해제 버튼 영역만 추가했다.
- 프로덕션 빌드, `npx tsc --noEmit -p service/frontend/tsconfig.json`, 변경 파일 ESLint, `git diff --check` 통과. 빌드는 외부 API DNS 조회 경고 후 완료됐다.
- 실제 컴포넌트를 Chrome에서 1440/768/600/390/320px로 확인했다. 제목 크기, 두 줄 요약, 가로 넘침 없음, 저장일·분야·링크·아이콘을 검증하고 데스크톱·모바일 캡처를 직접 확인했다.
- 키보드 포커스와 저장 해제 콜백, 처리 중 버튼 비활성화, 요약·날짜 누락, 공개 종료 기사의 제목·요약·링크 비노출을 검증했다. UI 검증은 로컬 샘플 데이터로 수행했다.

## 결정

- 뉴스 공통 스타일을 재사용해 추천 뉴스와 저장한 기사 사이의 디자인 차이가 다시 생기지 않도록 한다.
- 저장일은 발행일과 혼동하지 않도록 ‘저장’ 표시를 붙인다.

## 다음
