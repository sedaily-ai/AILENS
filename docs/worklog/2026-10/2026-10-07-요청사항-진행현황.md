## 4. 바로 시작할 수 있는 것 (승인 불필요, 코드·문서만)

1. 시스템 흐름도·아키텍처 그림 + 표준 문서 체계
2. 캐시 가이드 문서
3. 품질 게이트(분량·숫자 대조·형식 검증)를 파이프라인에 편입
4. 목록 쿼리 N+1·날짜 캐스팅 수정(DB 부하 감소)
5. 검색 405 원인 확인(구 Lambda `search`가 POST로 호출, 서버는 GET 전용)

## 5. 제안 순서

1. 이번 주: 위 5개 + Sonnet 5 시험(CMS 프롬프트 랩)
2. 승인 즉시: 삭제(A 분류), 온보딩 저장, 이미지 직접 API 시험
3. 시험 통과 후: Sonnet 5 전환, 캐시 적용, ElevenLabs 전환

가장 먼저 풀어야 할 막힘: **#1(IAM)** 과 **#2(삭제 결정 2건)**. 비용 절감의 시작점.
