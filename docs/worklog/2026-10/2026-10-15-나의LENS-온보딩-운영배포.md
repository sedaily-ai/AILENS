## 결정

- 마스터 비밀번호는 Claude가 다루지 않고 사람이 SSM 세션에서 직접 입력했다(CMS 서버 역할에 Secrets Manager 권한이 없음).
- ⑥ worker 정기 실행은 보류: CMS 서버 메모리 913MB 중 여유 약 149MB. 1분 주기 상시 작업 추가 전에 인스턴스 크기를 검토한다. 알림 구독자도 아직 없다.
- 12시 회차 중 CMS 재시작은 "발행 1건 누락 가능"을 감수하고 진행(파이프라인 `create_post`에 재시도 없음). 결과 누락 없음.

## Windows PC에서 배포할 때 막힌 점

- 계정 권한: 처음엔 `SedailyDevEc2ReadOnly`(SSM SendCommand 금지)·`iam:PassRole` 없음 → 권한 관리자가 InfraOps+Deployers 그룹으로 이동해 해결
- 배포 스크립트가 Mac/Linux 기준: `/tmp` 경로를 Windows용 AWS CLI가 못 읽음, 체크아웃이 CRLF, Git Bash에 `zip` 없음, `docker login`이 Windows 자격 증명 저장소에서 실패
  - 해결: `git -c core.autocrlf=false archive`로 LF 파일을 꺼내 Docker 리눅스 컨테이너 안에서 원래 스크립트를 그대로 실행(프론트는 `docker.sock` 공유)
- `aws configure export-credentials` 임시 권한은 프론트 빌드(약 44분) 중 만료 → push 직전에 다시 꺼낸다
- 프론트 빌드: Mac(ARM) 약 1분(10-01 기록) vs 이 PC(x86, arm64 에뮬레이션) 약 44분
- PC 시계가 늦으면 SigV4 서명·로그인 갱신 실패 → Windows 시간 동기화
