# 2026-10-14 나의 LENS 백엔드 리뷰 보완

관련: `feat/my-lens-account-storage`, [보완 계약](../../product/나의LENS/백엔드_리뷰_보완.md)

## 배경

운영 반영 전에 네 개발 묶음 전체의 인증·입력·저장·콘텐츠 조건·완료·알림 동작을 확인하고 필요한 오류를 수정한다. 운영 DB·배포·실제 발송은 범위에서 제외한다.

## 한 것

- 빈 본문·공백 URL·미래 게시 자료의 추천/완료 조건을 보완하고 TEXT/JSONB 스키마 차이를 반영했다.
- 기존 rendition source 문장 연결과 서랍 active 계정 검사·입력 오류·장애 응답·공유 헤더 변경 문제를 수정했다.
- 활성 기기 전체 집계, 해제 후 전달 상태 정리, live 미확정 target 보존, 실제 시각/lease 검사를 보완했다.
- 알림 원천/후보의 메타데이터 변경을 signature/hash로 확인하고 부모 잠금 뒤 다시 읽게 했다.
- worker의 계정별 실패를 분리하고 batch 회전용 v1.52 SQL·내부 POST due 계약을 추가했다.
- 실제 구현 문서와 운영 인수 경계를 갱신했다.
- 형식 선호·계정 연결까지 확장해 알림 사전 필터링, 후속 후보 최소1자리와 계획 순서 유지, 가져오기 UUID/거부 항목 재시도를 보완했다.
- 가져오기 응답 손실 시 동일 UUID를 유지하고 저장 목록 오류·운영 푸시 준비 상태를 화면에서 구분했다.
- 레터 작성자 표시에서 담당 주제 추정을 제거하고 실제 작성자 관계로 맞췄다.
- 기존 영수증을 유지하는 v1.54 SQL과 운영 적용의 선행조건·단계·되돌리기 문서를 추가했다.

## 결정

- public/준비 상태만으로 빈 자료나 미래 게시 글을 유효 이용 콘텐츠로 간주하지 않는다.
- live 전송 여부가 불명확하면 unknown 흔적을 보존하고 자동 재발송하지 않는다.
- 설정 revision과 worker의 검사 시각을 분리하고 기본 dry_run을 유지한다.
