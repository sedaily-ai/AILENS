# 2026-10-19 AI LENS 기능 다이어트

작성: 이도연 + Kiro
관련: 브랜치 `feat/feature-diet`(PR1). 이어서 `feat/saved-articles`(PR2, 저장한 기사 — [작업 기록](2026-10-20-저장한-기사.md))

## 배경

출퇴근길 5분 안에 오늘 경제 이슈를 보는 서비스에, 쓰는 사람이 적거나 같은 일을 두 번 하는 기능이 쌓여 있었다(읽기 시간 예산, 읽음 표시, 주간 스탬프·보상, 형식 통계, 웹 푸시, 관련 글 추천, 비교 카드, SNS 공유 묶음 등). 도연님이 대상을 하나씩 정하고("대상 · 처리 방법 · 완료 조건"), 코드 근거로 유지·축소·제거를 판단한 뒤 정리했다.

## 한 것

기본 규칙: UI와 코드는 지우고 DB 칸·데이터는 남긴다. 배포 사이 응답 모양을 맞추고 호환 코드는 "다음 정리 때 제거"로 표시한다. 브라우저 localStorage 옛 값은 자동으로 지우거나 옮기지 않는다.

| 대상 | 처리 |
|---|---|
| 북마크 아이콘 | 문장 담기 버튼을 lucide `Bookmark`로 통일 |
| 다 읽었어요·읽을 시간 | `read_minutes` 웹·모바일·관리자·CMS·메일·생성 프롬프트에서 제거. 형식 탭 "약 N분"만 유지 |
| 읽음 배지·안 읽은 글 필터·팔로우 제안 | 제거(70% 읽음 표시 포함). 옛 `read` 쿼리·커서는 받되 거르지 않음 |
| 웹 푸시 | 설정 화면·`pushDevice`·`lens-push-sw.js` 제거. 백엔드 알림은 유지(운영 dry_run) |
| 나의 LENS 탭 | '홈'·'내 서랍' 두 탭. 형식 선호·주간 스탬프·읽기 보상·기간별 기록·알림 설정 화면 삭제 |
| 완료 판정 내부 | 보기 신호(`visible_ms`)만. `completion_rules`·`format_preference_repo`·`reading_records_repo` 삭제, CMS `/activity`·`/rewards`·`/format-preference` 제거, 대시보드 옛 키는 `unavailable()` |
| 옛 주소 | 브라우저에서 정리: `/?tab=archive` → `/my-lens?tab=archive`, `tab=dna·feed·records·settings`·`sentence=` 제거. 서버 리다이렉트는 CloudFront 캐시 키에 쿼리가 없어 되돌림 |
| 구·신 서랍 중복 | 옛 홈 서랍 삭제, 내 서랍에 '이전 문장 더 보기'(200개씩) |
| 5분·10분 필터 | 제거. 웹 대시보드 쿼리 `minutes=0`, 계정 API는 옛 preference 모양을 400 없이 수용 |
| 불필요한 조회 | 대시보드가 알림 설정을 조회하지 않음, 서랍 탭은 대시보드를 부르지 않음, 영역별 응답 검증 |
| 저장 문장 관련 글 | 웹·계정 API·CMS 끝까지 제거(단어 하나만 겹쳐도 무관한 글이 추천됐다). `/sentences/{id}/recommendations` 404 |
| 비교 카드 | 버튼 제거. `/card/{id}`·`og.png`·`story.png`는 유지 |
| 형식별 통계·완료 달력·이용 기록 | 제거. 서랍 탭의 빈 오른쪽 레일 제거, 모바일 '이번 주 읽은 글·연속 읽은 날' 제거 |
| 중복 공유 버튼 | 기사마다 '공유' 하나(`shareLink`, `ArticleShareButton`, `BottomToast`). SNS 버튼 묶음·레터 하단 공유 삭제 |

| 게임·사주 홍보 | 게임은 '쉬어가기'로 유지. 사주 카드를 사이드 레일에서 게임 섹션 끝으로 이동 |

| 레터 에디터 줄·n개씩 보기 | 세로 스크롤 막대 제거(밑줄용 -1px 넘침 → 안쪽 그림자), 셀렉트 화살표를 상자 안 아이콘으로 |
| 죽은 코드 | 호출처 없는 `fetchTodayLetters`, 여는 곳이 사라진 홈 달력 팝업 삭제 |

전체 검증 뒤 독립 리뷰(웹·서버 각 1)에서 나온 문제도 고쳤다.
- 계정 API만 되돌리면 대시보드 전체 503 → CMS가 `preferences.minutes`·카드 `read_minutes`(DB 값)를 호환용으로 계속 싣는다.
- 처리 중 버튼 `disabled`로 키보드 포커스가 맨 위로 튐 → `aria-disabled`.
- 오디오 재생 버튼이 북마크 제거로 30px 치우침 → 오른쪽 빈 칸.
- 저장 시각 없는 문장에서 '이전 문장 더 보기'가 반응 없음 → 끝으로 처리.

## 결정

- 웹 푸시 불필요(이메일 구독으로 충분). 백엔드 알림 워커는 남겼다 — 전체 제거는 아래 '다음'.
- 나의 LENS는 홈·내 서랍 두 탭. 게임은 유지, 사주 홍보만 옮김.
- 옛 주소는 서버 미들웨어가 아니라 브라우저에서 정리한다: CloudFront 캐시 키에 쿼리가 없어(`cache-policy-rsc-aware.json`) 서버 리다이렉트가 같은 키('/')의 모든 응답으로 캐시될 수 있다.
- 취향 질문형 온보딩(`/start`) **보류**. 받은 답을 어디에도 쓰지 않는다. 선택지: A) `/start`를 지우고 오늘의 기사로 보낸다, C) 남기고 답을 기사 첫 탭(형식)으로 쓴다. 도연님 결정 대기.
- 남긴 추천 로직(분야 + 팔로우 에디터)은 계정 API·CMS 테스트로 동작을 확인했다.
