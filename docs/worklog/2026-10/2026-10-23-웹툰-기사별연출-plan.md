# Webtoon Prompt Improvement Implementation Plan

**Goal:** 기사별 연출·대화와 내레이션 혼합·화풍 일관성을 기존 CMS에서 개선한다.

**Architecture:** 기존 대본 생성·이미지 생성·합성 함수의 입력 계약을 그대로 사용하는 프롬프트 변경이다. 실제 운영 코드와 같은 조립 경로로 시험하고 CMS에 새 버전을 저장한다.

**Tech Stack:** CMS PostgreSQL 프롬프트 API, Bedrock Sonnet 5(중간 후보)·Opus 5(최종 대본)·Stable Image Ultra, Python 검증 및 기존 Pillow 합성.

**Spec:** `docs/worklog/2026-10/2026-10-23-웹툰-기사별연출-design.md`

## Global Constraints

- Bedrock application inference profile의 Service=lens를 호출 전에 확인한다.
- 정확히 8컷 또는 generation_status=needs_article; 이름·소개 없음; 최대 2명.
- 기존 이력 보존. 프롬프트 개선 시점에는 Git 작업·새 UI·코드 배포 없음. 후속 사용자 요청으로 정본과 검증 기록을 별도 문서 PR에 보존한다.

## Review Focus

- 짧은 기사: 꾸며서 8컷을 채우지 않고 서버 계약으로 보류.
- 수치·예정·검토: 원문과 같은 확정 수준과 단위 유지.
- 비부동산 기사: 공사장 등 무관한 장면 강제 없음.
- 2인 설명: 화자와 실제 인물·좌우·외형·대사 위치 일치.
- 동시 편집: 활성화 직전 버전·본문을 재조회하고 예상과 다르면 적용 중지.
