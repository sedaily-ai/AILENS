# 리팩토링 3·4단계: 삼킨 오류에 로그, 폴더·파일 이름 정리 (2026-10-12)

작성: 문영광 + Claude Code
관련: PR #78(오류 로그), #80(이름·폴더), #87(seo 분할), #89(searchIndex)

## 문제 발견
- 로그 없이 `except`로 삼킨 운영 코드가 있어 장애 원인이 가려졌다(10/12 제목 생성 권한 오류가 대표 사례).
- `features/letter/components` 파일 20개, `shared/lib/seo` 11개(폴더당 약 10개 기준 초과), 일반명 `shared/utils`, 실제로는 발행 모듈인 `publish_utils`.

## 문제 정의
- 폴백은 유지하되 원인은 항상 남긴다. 이름과 위치만으로 역할을 알 수 있어야 한다.
