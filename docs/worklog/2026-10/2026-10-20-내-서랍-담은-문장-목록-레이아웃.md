# 내 서랍 담은 문장 목록 레이아웃

## 배경

담은 문장의 박스형 카드를 저장한 레터·기사처럼 넓은 목록으로 정리하고, ‘저장한 문장을 모두 보여드려요. 이전 서랍의 저장·삭제 기록과 연결돼요.’ 안내를 제거해 달라는 요청.

## 한 것

- `DrawerPanel.tsx`의 원문 링크와 복사·삭제 버튼을 한 영역으로 묶었다. 일반 화면에서는 같은 줄에, 작은 화면에서는 원문과 버튼이 나뉘어 표시된다.
- `myLensDrawerStyles.ts`에서 2열 그리드를 없애고 모든 폭에서 한 열을 사용한다. 사방 테두리와 둥근 박스를 제거하고 항목 사이 구분선과 24px/22px 세로 여백으로 정리했다.
- 담은 날짜, 줄바꿈이 보존되는 문장 전문, 원문 링크 순서로 표시한다. 문장 글씨는 데스크톱 18px·모바일 16px이며 긴 단어도 영역을 넘치지 않는다.
- 복사·삭제·삭제 확인 버튼의 최소 높이를 44px로 확보했다. 삭제 확인과 실패 시 문장 보존 흐름을 유지한다.
- 요청한 하단 안내를 제거했다. 더 불러올 문장이 있을 때만 ‘검색은 현재 불러온 문장 안에서 찾아요.’를 표시한다.
- 프로덕션 빌드, 타입 검사, 변경 파일 ESLint, `git diff --check` 통과. 빌드 중 외부 API DNS 경고는 있었으나 빌드는 완료됐다.
- 실제 `DrawerPanel`을 Chrome에서 1440/1024/768/390/320px로 확인했다. 한 열 전체 폭, 긴 문장·원문 제목의 가로 넘침 없음, 줄바꿈 보존, 버튼 높이, 원문 링크, 안내 문구 제거를 검증했다. 데스크톱·모바일 캡처를 직접 확인했다.
- 로컬 샘플로 복사 성공·실패, 삭제 확인·취소·실패·성공, 처리 중 비활성화, 검색, 이전 문장 더 보기 동작을 확인했다. 실제 계정의 문장은 삭제하지 않았다.

## 결정

- 문장은 줄 수 제한 없이 전문을 표시한다.
- 홈 오른쪽 담은 문장 미리보기에는 서랍 전용 배치 변경을 적용하지 않는다.

## 다음

- 로컬 변경이며 배포하지 않았다.
