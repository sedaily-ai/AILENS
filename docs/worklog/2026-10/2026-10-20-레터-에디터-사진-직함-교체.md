# 2026-10-20 레터 에디터 사진·표시 이름 교체

관련: `feat/letter-editor-profiles`, `service/frontend/src/features/letter/`, 사용자 제공 `에디터.docx`

## 배경

레터 에디터 8명의 사진을 문서에 제공된 이미지로 교체하고, 기존 사람 이름 대신 괄호 안 직함을 표시한다. 긴 직함에 맞춰 탭의 사진 아래에 이름을 배치하며, 소개 설명은 이름 부분 외에 수정하지 않는다.

## 한 것

- DOCX의 문단과 이미지 관계를 확인해 사진 8개를 추출했다. 문서와 배포용 PNG의 SHA-256이 모두 일치한다.
- 표시 이름을 전략 분석 에디터, 오피니언 에디터, 팩트 큐레이터, 트렌드 캐스터, AI·테크 전략가, 생활경제 큐레이터, 정책·거버넌스 분석가, 국제·라이프 에디터로 교체했다.
- `editors.ts`의 이미지 경로를 새 파일로 연결하고, 소개 문구에서는 기존 이름을 말하는 부분만 제거했다. 변경 전후 비교로 나머지 소개 내용·담당 분야·추천 상황·내부 ID가 유지됨을 확인했다.
- 탭을 48px 원형 사진 아래 직함이 오는 세로 배치로 변경했다. 단어 단위로 줄바꿈하며 좁은 화면에서는 가로 스크롤과 선택 탭 자동 노출을 유지한다.
- 소개 카드, 목록·상세의 작성자, 구독·로그인 안내, 팔로우 목록, 나의 LENS와 페이지 메타데이터에서 중복 직함·에디터 접미사를 제거했다.
- 기존 이름이 포함된 소개 음성 4개는 데이터 연결을 해제해 재생 버튼을 숨겼다. 음성 파일 자체는 변경하지 않았다.
- 검증: 레터 관련 Vitest 21개, TypeScript, 변경 컴포넌트·데이터·메타데이터 ESLint 통과. Next.js 프로덕션 빌드 성공. 빌드 환경에서 외부 API DNS 조회 실패 경고가 발생했으므로 이 빌드를 운영 데이터 검증 근거로 사용하지 않는다.
- Playwright로 1440·768·390·320px에서 8개 탭의 선택, 사진 로딩, 사진 아래 이름 배치, 기존 이름 미노출, 화면 가로 넘침 없음을 확인했다.
- 모바일 구독창의 직함 8개·선택 표시와 가로 넘침을 확인했다. 실제 구독 요청은 보내지 않았다.
- `/letter/editors/yerin` 직접 진입에서 선택 탭 자동 노출·중복 없는 페이지 제목·실제 레터 3편 조회를 확인했다. 첫 레터 상세에서도 새 작성자 이름과 에디터 한마디 표기가 정상이고 가로 넘침이 없었다.
- 로컬 스크린샷: `.playwright-mcp/lens-editors-desktop.png`, `.playwright-mcp/lens-editors-mobile.png`, `.playwright-mcp/lens-editors-subscribe-mobile.png`.
- 후속 요청: ‘전체’ 탭에 48px 원형 배경과 전체 보기 아이콘을 추가하고, 아래 문구를 다른 탭의 이름과 같은 높이에 정렬했다. 폭은 88px로 늘렸으며 선택하면 파란색으로 강조한다. 320·390·1440px에서 전체 선택 복귀·정렬·가로 넘침 없음을 확인했다.
- 후속 구독 확인: 사용자가 실제 신청 대신 기능 존재 확인으로 범위를 지정했다. 8개 에디터 화면의 기본 선택과 POST 본문을 브라우저에서 가로채 확인했고, 모두 해당 기존 ID를 정확히 전송했다. 운영 API에 POST를 보내거나 확인 메일을 발송하지 않았다.
- 서버 코드에서 `subscribe` → `set_subscription_editors` → `letter_subscription_editors` 저장, 확인 토큰으로 `pending` → `active` 전환, 작성 에디터와 구독 에디터를 조인하는 발송 대상 선정 경로를 확인했다. 운영 DB 저장과 메일 수신을 실측한 것은 아니다.
- 기존 제한: 이미 `active`인 이메일로 다시 신청하면 에디터 변경 없이 동일한 `pending` 응답을 반환한다. 기존 구독을 임의로 덮어쓰지 않도록 하는 회귀 테스트도 존재한다. 따라서 현재 신청 화면은 활성 구독자의 에디터 추가·변경 기능을 제공하지 않는다.
- 후속 검증: 프런트엔드 테스트 21개·ESLint 통과. 백엔드 테스트 실행은 시스템 Python에 `pytest`가 없어 진행하지 못했다. 관련 서버 로직은 코드로 확인했으며 서버 코드는 수정하지 않았다.
- 추가 후속 요청: 전체를 제외한 8개 에디터 탭에 소개 툴팁을 추가했다. `editors.ts`에 기존 소개·담당 분야를 한 문장으로 요약한 `summary`를 작성했으며 원래 상세 설명은 유지했다.
- 마우스 호버·키보드 포커스에서 제목과 요약을 표시한다. 기본은 탭 아래, 아래 공간이 부족하면 위에 표시하며 좌우 화면 경계 안으로 위치를 보정한다. 스크롤 영역에 잘리지 않도록 body 포털을 사용했다.

## 결정

- 문서가 지정한 직함 안의 ‘에디터’는 유지하고, 이름 뒤에 별도로 덧붙이던 ‘에디터’만 제거한다.
- 내부 ID·탭 순서는 유지해 기존 작성자·팔로우·구독 연결과 URL을 보존한다. 사진은 문서 순서가 아니라 이름에 맞춰 연결했다.
- 웹 화면 변경 범위로 수행했다. 운영 DB의 에디터 레코드·실제 발송 메일 데이터는 변경하지 않았다.
