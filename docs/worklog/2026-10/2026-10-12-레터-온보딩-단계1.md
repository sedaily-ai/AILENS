# 레터 페르소나 제안의 에디터 방식 반영: 이유 표시·측정·온보딩 단계 1 (2026-10-12)

작성: 문영광 + Claude Code
관련: PR #76, 설계 `docs/product/모아쓰기레터/온보딩_설계.md`, 원 제안서 `마스터DB/06_콘텐츠/레터/ailens_페르소나 설정_261008.html`(원본 미수정)

## 문제 발견
- 페르소나 제안서의 전제는 독자가 자기 유형을 아는 것이다. 실제 독자는 입장 시점에 자기 상황을 말하지 않는다.
- 현재 개인화 신호는 구독 다이얼로그 안에만 있어, 구독하지 않는 독자는 신호가 0이다.
- 카드의 추천 이유는 관심 주제 겹침만 있었고, 팔로우한 에디터가 쓴 글이라는 이유는 표시되지 않았다.

## 문제 정의
- 질문보다 행동(읽기·저장·팔로우)을 먼저 관찰하고, 추정은 독자에게 보여 주고 고치게 한다. 이유 문구는 사실만 쓴다(중립 원칙). 직업·소득·직무는 수집하지 않는다.
