## 배경

사용자가 뉴스룸 배경 고정, 선택적 대화, 뉴스 중요도에 따른 구성, 컷별 이미지 완성도, 화풍·등장인물·배경의 일관성을 요청했다. 첨부한 웹툰 이미지 12장은 화풍·명암·인체 비율·실내 공간 표현의 참고로 사용했다. 이미지 속 기사 문구는 뉴스 사실의 근거로 사용하지 않았다.

사용자는 기존 CMS 버전 관리에 새 버전을 쌓는 방식으로 계속 진행하도록 요청했다.

## 한 것

- 버전 이력 확인 시 최신 저장본은 v47, 운영 활성본은 v46이었다. v46과 v47의 content는 같았다.
- 운영 v46·v47은 둥근 머리·점 눈·무명암의 벡터형 캐릭터를 지시하고 캐릭터 동일성을 후순위로 두고 있었다. 사용자 레퍼런스의 성인 비율·선화·셀 명암과 충돌했다.
- 이미지 모델은 `sd_ultra`, `BUBBLE_STYLE`·`BUBBLE_DETECT`는 off였다. 코드의 `_generate_cut_once`는 기본 Stability 경로에서 별도의 STYLE·CHARACTER 설정을 붙이지 않는다. 실제 편집 대상은 `webtoon/published`가 만드는 컷별 `image_prompt`다.
- 새 지침을 CMS의 기존 `PUT /internal/admin/prompts/webtoon/published`에 `activate=false`로 저장했다. `sections`는 기존 편집기와 같은 `{kind, label, description, instructions, files}` 구조다.
- 저장 결과는 **v48**, 이름은 **뉴스룸 고정 · 레퍼런스 웹툰 · 핵심뉴스 우선**이다. 저장 시각은 **2026-10-20 23:41:51 KST**.
- 저장 후 content와 sections를 재조회해 전송한 내용과 완전히 같은지 확인했다. v46·v47 상세 응답과 운영 활성값 v46도 이전과 같았다.

## 결정

- 뉴스 중요도 1~6점 체계를 유지하고, 5~6점 핵심 내용과 이해에 필요한 근거에 8컷 중 5~6컷을 우선 배정하는 목표를 추가했다. 사실이 부족하면 점수나 사건을 만들어 목표를 채우지 않도록 했다.
- 레퍼런스의 성인 인체 비율, 선명한 선화, 2~3단계 명암, 차분한 네이비·블루·웜그레이·아이보리 팔레트를 고정 문구로 정의했다.
- 동일 뉴스룸의 벽·화면·유리 파티션·책상·테이블·광원을 모든 컷의 완결된 프롬프트에 반복한다. 기사 속 다른 장소는 뉴스룸 화면 내부의 설명 삽화로만 표현한다.
- A/B 진행자의 외형·헤어·복장을 고정하되 컷마다 0~2명 중 필요한 구성만 쓴다. 카메라·동작·설명 화면으로 변화를 준다.
- 기본은 설명 자막형이다. 현재 합성 코드에서 하단 설명은 `narration`으로 그리므로 긴 문구를 작은 `caption` 박스에 넣지 않는다. 대화형은 명시적으로 선택할 때 사용한다.
- 현재 코드의 8컷, 가로 3:2, 한국어 `image_prompt` 요구와 맞췄다. 운영 v46의 6컷·4:5·영어 지시와 코드 보강 지침 간 충돌을 새 버전에서는 피했다.
- 중요도·장면·인물 정보는 프롬프트가 담당한다. 코드, 모델, 운영 활성 버전, 기존 편집 중인 초안은 변경하지 않았다.

## 검증과 다음

- CMS와 배치의 실제 챕터 추출 함수를 네트워크 호출 없이 실행해 새 지침 전문이 보존되는지 확인했다.
- 실제 CMS 호출 조립 함수와 두 경로의 컷 정규화 함수를 이용한 정적 호환 확인에서 8컷, 한국어 지침, narration·dialogue·image_prompt 필드가 보존됐다.
- CMS의 200KiB 필드 상한 이내임을 확인했다(17,408바이트).
- 실제 모델 추론과 이미지 생성은 실행하지 않았다. 화풍 유사도·얼굴 동일성·공간 일관성은 아직 이미지로 검증되지 않았다. 첨부 이미지를 모델에 직접 전달한 것도 아니며, 관찰한 특징을 지침으로 작성한 상태다.
- CMS 테스트에서 v48을 선택해 기사 한 건의 8컷 결과를 확인하고, 필요하면 다음 버전으로 개선한다. 운영 전환은 별도 적용 작업이다.
