# 2026-10-15 대시보드 스키마·권한 호환 보완

관련: PR #109 머지 후속 · fix/dashboard-schema-array-types · [운영 적용 단계](../../product/나의LENS/운영적용_남은단계.md)

## 배경

대시보드 구현을 main에 통합한 뒤 실제 DB 적용 순서를 준비한다. 별도 스테이징이 없어 운영 DB를 사용하지 않는 로컬 리허설을 진행하며, 최소 테스트 스키마와 기존 서비스 역할 사이에서 놓친 호환 문제를 보완한다.

## 한 것

- PR #109가 머지된 main을 로컬에 반영하고 미커밋 운영 적용 문서 수정은 보존했다.
- 레터 분야 추천의 VARCHAR[]와 TEXT[] 비교를 TEXT[]로 통일했다. 실제 category_slug 타입을 사용하는 회귀 검사를 추가했다.
- 발송 직전 후속 관계의 FOR SHARE가 SELECT 전용 앱 역할에서 실패하는 경로를 전용 잠금 함수 호출로 교체했다.
- v1.55 SQL에 마이그레이션 역할 소유의 잠금 함수를 추가하고 PUBLIC 실행 권한을 회수했다. 앱에는 EXECUTE만 부여하며 후속 관계의 쓰기 권한은 확대하지 않는다.
- 인계 문서의 적용 순서를 v1.48~55로 갱신하고 함수 준비 후 CMS 갱신 조건, 검증용 UI·문구 정리 단계를 명시했다.

## 결정

- 저장소 원본 DDL과 변경 기록으로 로컬 기준 스키마를 재구성한다. 로컬에서 다루지 않은 확장·실제 운영 스키마·역할·자료량은 별도 환경 확인 대상으로 유지한다.
- 운영 DB·AWS 리소스·배포·실제 발송은 수행하지 않는다. 합성 자료·로그·백업·화면 캡처는 저장소에 포함하지 않는다.
- 이번 변경은 후속 로컬 수정이며 아직 커밋·push하지 않았다.

## 다음

- 후속 코드와 v1.55를 공유한 뒤 기존 DB 버전·역할과 메타데이터 공급 조건을 확인한다.
- DB와 함수가 준비된 환경에서 CMS·공개 계정 API를 연결하고 검증용 UI·문구 정리 후 프론트 배포로 이어간다.
