# 2026-10-20 모바일 내 관심(분야·섹터·화두) 담기

작성: 사용자 + Claude Code
관련: `apps/mobile/src/features/interests/*`, 공개 API `/api/v2/issue-letters/topics`

## 배경

"종목이 아니라 요즘 경제·금융의 화두, 특정 섹터 기반 관심"을 보고 싶다는 요구. 관심의 단위를 3층으로 올렸다.

## 한 것

- 3층 관심: 분야(9) → 섹터(분야 세부 분류) → 화두(주제어 75개, 분야 연결). 화두 사전은 공개 API, 실패 시 에디터 담당 주제어. 최대 20개, 기기 저장, 옛 "관심 분야" 저장값 자동 이전.
- 매칭: 분야=분류 일치, 섹터=분류+세부 일치, 화두=제목·요약 포함(별칭 AI·공모주·IPO·통상 등). 실데이터 2,879건 검증(시그널 794·국내증시 389·반도체 188·인공지능 299).
- 홈 "내 관심" 칩 줄(칩별 최근 24시간 새 소식 건수), 관심별 소식 목록(`/interest`, 최신 40건).
- 담기 화면 재설계: 3탭을 폐기하고 "주제" 한 가지로 통일, 전체 화면, 3개 목표 진행 막대, 분야별 칩 구름, 추천("오늘 N건")·검색·분야 전체 받기, 선택 시 튀어 오르는 애니메이션. 추천·검색 로직 14건 검증.
- 칩 아이콘: 이모지는 기기마다 모양이 달라 "AI 느낌"이라 폐기 → Phosphor 선 아이콘 한 세트(약 100개 주제 매핑, `topicIcons.ts`).

## 결정

- 사용자에게 "분야·섹터·화두"라는 말을 노출하지 않고 "주제"로 통일(내부 구분은 유지).
- 관심도 추이("요즘 뜨는 화두")는 기사 출현 빈도라 독자 관심이 아님 → 이름은 "요즘 많이 나오는 이야기" 계열. 독자 관심(투표·저장 인기순)은 서버에 인기순 집계 API가 없어 협의 필요. 아직 미구현.

## 계획 B 구현(같은 날 이어서)

- 홈 "요즘 많이 나오는 이야기": 화두 사전의 주제별 최근 3일 기사 수를 직전 7일(3일치로 환산)과 비교해 급상승(최근 3건 이상 + 기준선의 1.6배 이상)·꾸준(2건 이상)으로 분류, 7일 막대 추이와 함께 상위 5개 표시. 실데이터 검증: 바이오·중국·SK하이닉스·플랫폼이 급상승으로 나옴. 이름은 "조회수 순위가 아님" 문구를 붙임.
- 나의 LENS "내 관심의 흐름": 담은 주제별 이번 주 대 지난주 기사 수(+N/-N)와 7일 추이.
- 로직은 `interests/trend.ts` 순수 함수(검증 12건).
