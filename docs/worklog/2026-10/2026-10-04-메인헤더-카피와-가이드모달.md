## 사이클 1 — 깨진 가이드 모달 재설계

### 문제 발견
- 사용자 스크린샷: 가이드 모달의 일러스트 이미지 깨짐
- 원인: 형식별 일러스트를 외부 파일(`/lens/role-N.png`)로 불러오는데 파일 부재

### 문제 정의
- 외부 이미지 의존이 깨짐 원인 + 요청: 토스 톤 + 서비스 개성(스케치·아날로그 느낌)으로 전면 재설계, 움직이는 튜토리얼 요청

### How
- 일러스트를 인라인 SVG로 교체(파일 요청 0건, 깨질 수 없음): 레터=종이·연필 / 웹툰=말풍선 4컷 / 팟캐스트=헤드폰·파형 / 영상=재생 화면·진행선
- 스케치 표현: 가는 잉크선 + 면을 선에서 일부러 어긋나게 깔기(인쇄 어긋남 느낌), 앰버 손밑줄
- 1차 시안 지적 → 색 정리: 형식별 보라·분홍·초록·노랑 → 서울경제 파랑 옅은 면 + CI 파랑 선 + 앰버 포인트 2곳, 버튼은 거의 검정에서 `#1f2937`로 완화
- 줄바꿈을 의미 단위(구)로 정리, 375px에서 일러스트가 글자와 겹치던 문제 수정, 320px에서는 구 안 줄바꿈 허용(가로 넘침 방지)
- 튜토리얼 모션: 3.6초마다 형식 자동 전환 + 행별 반복 애니메이션 + 진행 막대 + 호버·클릭 시 자동 넘김 정지(제어 수단 부재 지적 반영) + 움직임 줄이기 시 정지
- 버튼 카피를 현재 형식에 맞게 변경("지금 읽으러/웹툰 보러/들으러/영상 보러 갈래요 →") + 누르면 오늘 지면 1면 기사를 해당 형식 탭(`?v=1~4`)으로 이동
- 사용자 지적 반영: "알겠어요" 카피 → 행동 유도 카피로

### 판정
- 적용 완료 · 배포 완료(사용자 직접 관찰 기반 조정)
- 미확인: 연필·소리 막대 등 짧은 움직임은 정지 화면 캡처로 확인 한계

## 사이클 2 — 메인 헤더 카피(페인포인트 → 해결)

### 문제 발견
- 사용자 요구: 뉴스를 보고 싶어지는 카피, 매일 아침 안정감 있는 타이포, 처음 온 사람이 가이드를 쉽게 찾게

### How(카피 이터레이션, 사용자 피드백으로 수정)
- 1안 "어려운 경제 뉴스, 아침 3분이면 충분해요" → 사용자 지적: 경제 뉴스만이 아니라 실생활 유용 이슈를 편집팀이 선정한 것
- 2안 "쏟아지는 뉴스 중, 내 생활에 닿는 이슈만 골랐어요" → "와닿지 않는다"
- 3안 "오늘 뉴스, 이것만 보면 돼요" + 제작 방식 고지(AI 요약·편집팀 검수) → 사용자: 고지는 여기 불필요(기사 하단 안내·푸터에 존속)
- 최종: 사용자 문안 채택 — "뉴스 챙겨보기 어려우시죠?"(질문, 앰버 손밑줄) + "당신의 일상에 맞춘 뉴스를 준비했어요."(해결)
- 배운 점: 후보 카피의 근거(페인포인트 3종: 시간 없음·어려움·양 과다)를 제시해도 최종 선택은 사용자 문안이 더 와닿음 → 이후 카피는 사용자 원문 우선
- (i) 아이콘 → 텍스트 버튼 → 칩 흐름: 처음 온 사람에게만 링 3회 퍼짐 / 대비 4.6:1(`#3d70de`)
- 시선 흐름 설계: 질문 → 답 → "읽기 → 웹툰 → 듣기 → 영상" 네 칩을 화살표로 연결(한 줄 유지: 데스크톱·390px·320px, 350px 이하는 아이콘 숨김), 6초 주기 불빛 흐름, 호버·포커스 시 정지, 움직임 줄이기 시 정지
- 칩 질감: 그라데이션·3겹 그림자가 "AI 티" 난다는 지적 → 단색 `#f4f7fe` + 거의 안 보이는 테두리 + 2겹 그림자로 축소
