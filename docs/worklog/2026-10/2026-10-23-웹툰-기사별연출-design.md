# 기사별 뉴스 웹툰 프롬프트 개선

사용자는 현행 v61/v29의 평가 뒤, 기사별 장면 중심 또는 최대 2인 설명형을 선택하고 대화·내레이션 혼합과 일관된 화풍을 복원하는 권장안의 실행을 요청했다.

- 목표: 사실 중요도·출처·확정 수준을 유지하며 기사에 맞는 장면과 설명 방식을 만든다. 같은 기사 안에서 인물·장소·색감을 유지하고 다른 기사까지 동일한 구성을 강제하지 않는다.
- 접근 비교: 기존 진행자 구성을 전 기사에 복원하면 단순하지만 장면 반복이 크다. 코드에 새 선택 UI를 추가하면 제어가 명확하지만 이번 문제보다 범위가 크다. 이번에는 기존 JSON과 생성 함수를 이용해 프롬프트에서 기사별 연출을 정하는 권장안을 적용한다.
- 변경 범위: 새 대본·이미지 설정 버전. CMS UI·모델·배포 코드는 변경하지 않는다. 현재 Stable Image Ultra와 정확히 8컷 계약, 한국어 후합성, 이름·소개 없음, 최대 2인 조건을 유지한다.
- 설계: 완성형 영어 프롬프트마다 동일한 짧은 2D 화풍 문장을 반복한다. 설명형은 기사별 확정 A/B 외형을 반복하고 장면 중심은 필요한 인물만 등장시킨다. 8가지 장면 강제·사실당 1컷 강제·20자 인용 제한을 없앤다. 출력에 generation_status를 복원해 실제 서버의 근거 검증을 적용한다.
- 검증: 운영 코드와 로컬 동일성 확인, 실제 Bedrock 대본의 구조·출처·내용 검수, 짧은 기사 보류, Ultra 대표 3컷과 텍스트 합성 검수. 실제 얼굴 동일성·확대 무손실을 약속하지 않는다.
- 반영: 비활성 새 버전 저장 후 본문 재조회, 활성 버전 동시 변경 확인, 검증 통과본 활성화, 공개 소비 API와 편집 초안 동기화 확인. 직전 버전과 응답을 로컬에 보존한다.
