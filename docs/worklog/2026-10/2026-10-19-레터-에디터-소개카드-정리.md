# 2026-10-19 레터 에디터 소개 카드·선택줄 정리와 소개 음성 재생 바

작성: Kiro
관련: `feat/letter-editor-ui-cleanup` → `main`

## 배경

레터 탭의 에디터 소개 카드와 선택줄에 사용자가 굳이 알 필요 없는 안내 문구와 전환 버튼이 남아 있었다. 사용자 지시로 문구와 버튼을 걷어내고, 밑줄 텍스트 링크라 오디오로 읽히지 않던 "소개 듣기"를 재생 막대로 바꿨다.

## 한 것

- 에디터 소개 카드(`features/letter/components/list/EditorIntro.tsx`)
  - 역할 줄의 "· AI 에디터"를 지웠다. 8명 카드 공통.
  - "팔로우는 로그인 후, 이메일 구독은 로그인 없이" 안내 줄과 스타일(`styles/list.ts`, `styles/mobile.ts`의 `.lt-eintro-policy`)을 지웠다.
  - "소개 듣기" 텍스트 링크를 재생 막대로 바꿨다. 막대 전체가 재생·멈춤 버튼이고, 원형 재생/일시정지 아이콘·"민철 소개 듣기"·전체 길이·진행 막대를 보여 준다. 재생 중에는 "듣는 중"·작은 막대 애니메이션·`0:04 / 0:09`, 끝나면 처음 상태로 돌아간다. 재생 실패 시 막대 아래에 안내를 띄운다. 음성 파일이 있는 4명(민철·하은·준서·소율)만 해당.
  - 시간 표기는 기존 공용 함수(`shared/lib/media/mediaPlayerFormat`의 `clock`, `spoken`)를 썼다. 길이를 먼저 보여 주려고 `preload="metadata"`로 파일 앞부분만 받는다.
  - `data/editors.ts` 머리 주석의 "화면에 AI 에디터로 표시한다"를 현재 동작에 맞게 고쳤다.
- 에디터 선택줄(`EditorTabs.tsx`): "현재 목록 에디터 / 전체 에디터" 전환 버튼과 글 없는 에디터를 숨기던 필터를 지워 8명을 항상 보여 준다. `LetterListView`가 넘기던 `publishedEditorIds`도 지웠고, 테스트(`EditorTabs.test.ts`)를 새 동작 기준으로 다시 썼다.
- 레터 저장 안내: 로그인 사용자에게 보이던 "로그인한 계정의 레터 저장은 서버에 보관돼요. 로그인 전 브라우저 저장과는 자동으로 합치지 않아요."를 지웠다.
  - `useLetterShelf`의 로그인 안내를 빈 문자열로 바꾸고 안 쓰는 문구 상수(`LETTER_SHELF_NOTICE.browser`)를 지웠다.
  - 레터 목록·상세는 안내가 있을 때만 줄을 그리고, 저장 버튼의 `aria-describedby`도 그때만 붙인다.
  - 나의 LENS는 로그인 사용자 전용이라 안내가 항상 비므로 안내 줄·`storageNotice` prop·북마크 버튼의 `aria-describedby`를 지웠다.
  - 비로그인 안내("레터를 저장하려면 로그인해 주세요.")는 그대로 둔다.

## 결정

- 소개 음성은 6~12초로 짧아 드래그 탐색은 넣지 않았다. 진행 막대는 보기 전용이다.
- 재생 아이콘은 흰 바탕 윤곽선으로 두어 카드의 주 버튼(메일로 구독)과 경쟁하지 않게 하고, 파랑은 진행 막대에만 쓴다.
- 막대·아이콘 테두리는 기존 레터 카드와 같은 연한 선(`--line`, `#d5dbe6`)이라 UI 경계선 3:1 기준에는 못 미친다. 아이콘·글자 대비로 버튼임을 알 수 있어 그대로 두었고, 진하게 바꿀지는 결정이 필요하다.
- 재생 중 강조색(`#eef3ff`, `#b7cdf5`)·호버 테두리(`#cbd5e1`)는 대응 토큰이 없어 레터 스타일에서 이미 쓰던 값을 그대로 썼다.
