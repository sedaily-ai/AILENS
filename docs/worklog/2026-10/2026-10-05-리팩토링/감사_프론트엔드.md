## 보류 목록 (위험 높음 또는 라우트 동작이 바뀔 수 있음)

1. 캐시/ISR 정책 통일(revalidate 300 vs 1800 vs 60 vs no-store 혼재, 태그 유무 혼재): 캐시 적중과 admin 발행 반영 지연에 직접 영향. 현재 값은 각각 사유가 있는 주석이 있으므로 정책 결정이 선행되어야 한다. 리팩토링이 아니라 설계 변경.
2. 홈 섹션이 서버 프리페치와 별개로 마운트 시 재조회하는 동작을 제거하는 것: 사용자에게 보이는 최신성이 달라진다(10번은 "동작 유지한 채 훅 추출"까지만).
3. layout.tsx의 no-page-custom-font, WebtoonViewClient의 `<img>` → next/image 전환: LCP·이미지 도메인 설정이 바뀜(성능 개편 건이므로 별도 트랙).
4. lensArticlePageShared.tsx의 `revalidate`/`dynamicParams` export 삭제: 라우트 세그먼트 설정이 사라질 수 있음. 실제 라우트 파일이 재선언하는지 검증 전까지 건드리지 않는다.
5. 'use client' 제거(14번 중 부모가 서버 컴포넌트인 경우)와 서버/클라이언트 경계 이동: 직렬화 props와 hydration이 바뀐다.
6. timelineEvents.generated.ts, webtoonCovers.generated.ts: 생성물이므로 손대지 않고 생성 스크립트 쪽에서만 변경.
7. public/games/*, public/audio-worklet/*, infrastructure/*, ecosystem.config.js: knip 미사용이지만 URL/배포 인프라에서 참조되므로 삭제 금지.
8. pretendard 의존성: CSS import이므로 제거 금지(knip 오탐).
9. widgets 간 Header import 구조 변경: 모든 페이지 셸의 조립 방식이 바뀌므로 보류. 규칙 문서에 예외로 명시하는 선에서 정리 권장.
10. 거대 컴포넌트 중 TodayNewsPlayer/ArticleAudioPlayer/SmartSearchOverlay(오디오·스트리밍·키보드 상호작용): 테스트 없이 분리하면 회귀 위험이 높다. 9번(테스트)과 스크린샷 비교 체계 이후로.
