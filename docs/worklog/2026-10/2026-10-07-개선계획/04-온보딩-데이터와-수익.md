# 04. 온보딩 데이터와 수익 연결

결론: `/start` 온보딩 응답 2개가 서버에 저장되지 않아 데이터가 쌓이지 않음. 익명 `session_id` 기반 저장 테이블·공개 API·동의 고지를 도입하고, 이 데이터를 세그먼트 뉴스레터·스폰서 슬롯·B2B로 연결. 결제(PG) 심사가 4개월 이상 걸리므로 결제 없는 모델부터 검증.

조사는 코드 기준. GA4 콘솔의 맞춤 측정기준 등록 여부는 코드로 확인 불가.

## 1. 현황

| 항목 | 내용 |
|---|---|
| 경로 | `/start` → `OnboardingFlow` (`app/start/page.tsx:11`) |
| 질문 1 (moment) | "뉴스, 주로 언제 보게 되나요?" — `lunch` · `commute-home` · `walk` · `bed` |
| 질문 2 (glance) | "그때 뉴스를 열면, 가장 먼저 눈이 가는 건?" — `text` · `comic` · `sound` · `video` |
| 결과 | `resolveFormat`으로 형식(0 레터·1 웹툰·2 팟캐스트·3 영상) 도출 |
| 로그인 | 불필요 |
| 저장 위치 | React state, localStorage(`onboarding-format`·`onboarding-completed`), GA4 이벤트. **서버 없음** |
| 서버 엔드포인트·테이블 | **없음** (`users`·`user_archives`·`subscriptions`는 있으나 취향 컬럼 없음) |
| 읽는 곳 | `onboarding-format`을 읽는 코드 없음(주석은 읽는다고 하나 불일치) |
| 결과 화면 분포 | 하드코딩 샘플 값 (`distribution.ts`) |

GA4 이벤트: `onboarding_moment_select{moment,format}` · `onboarding_glance_select{moment,glance}` · `onboarding_result{moment,glance,format,adjusted}` · `onboarding_result_tab/slide/stats_toggle` · `format_step_click{source:onboarding}`.

## 2. 문제 정의

| # | 문제 | 영향 |
|---|---|---|
| 1 | 응답이 서버에 없음 | 세그먼트·분포·가설 검증 불가, 브라우저 변경 시 소실 |
| 2 | GA4 이벤트에 건너뛰기·뒤로가기·진입이 없음 | 퍼널 이탈 지점 파악 불가 |
| 3 | 전환(구독·로그인)에 온보딩 출처 귀속 없음 | 온보딩 효과 측정 불가 |
| 4 | 결과 화면의 "다른 분들" 분포가 샘플 값 | 신뢰성 문제, 실제 집계로 교체 필요 |
| 5 | 개인정보처리방침에 선호 응답 항목 없음 | 사용자 결합 저장 시 고지 필요 |

## 3. 저장 설계 (제안, 확정 대기)

### 3.1 테이블

```sql
CREATE TABLE onboarding_responses (
  id          BIGSERIAL PRIMARY KEY,
  session_id  UUID        NOT NULL,           -- 클라이언트가 localStorage에 생성
  user_id     VARCHAR(64) NULL REFERENCES users(id),  -- 로그인 후 연결
  moment      VARCHAR(16) NOT NULL CHECK (moment IN ('lunch','commute-home','walk','bed')),
  glance      VARCHAR(8)  NOT NULL CHECK (glance IN ('text','comic','sound','video')),
  format_index SMALLINT   NOT NULL CHECK (format_index BETWEEN 0 AND 3),
  adjusted    BOOLEAN     NOT NULL DEFAULT FALSE,
  created_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE UNIQUE INDEX onboarding_responses_session_uq ON onboarding_responses(session_id);
CREATE INDEX onboarding_responses_mg_idx ON onboarding_responses(moment, glance);
CREATE INDEX onboarding_responses_user_idx ON onboarding_responses(user_id);
```

### 3.2 API

| 항목 | 내용 |
|---|---|
| 엔드포인트 | 공개 `POST /api/v2/onboarding` |
| 요청 | `{session_id, moment, glance, format_index, adjusted}` (자유 텍스트·이메일 수신 안 함) |
| 검증 | enum 4×4 값만 허용, `session_id` UUID |
| 저장 | `session_id` 기준 upsert (결과 화면에서 형식을 바꾸면 `format_index`·`adjusted` 갱신) |
| 방어 | IP별 rate limit, 허니팟 필드 또는 Turnstile 검토 |
| 연결 | 로그인 시 `PUT /me/onboarding`으로 `session_id`에 `user_id` 채움 |
| 구독 연결 | 기존 `subscriptions.extra`의 `onboarding_format`에 형식 전달 |

### 3.3 프론트 변경

| 파일 | 변경 |
|---|---|
| `OnboardingFlow.tsx` | 결과 확정 시 POST 호출(실패해도 흐름 유지), 건너뛰기·뒤로가기에 `trackEvent` |
| `shared/lib/onboardingStorage.ts` | `session_id` 생성·보관, 주석과 읽기 코드 불일치 정정 |
| 홈 `LensPreviewSection` | 저장된 형식을 기본 탭으로 사용(주석이 말하는 동작 구현) |
| `distribution.ts` | 샘플 값 → 실제 집계 API(표본 50명 미만 숨김) |
| 구독 폼 | `format`·`interests`에 온보딩 값 전달 |

### 3.4 개인정보·동의

| 항목 | 내용 |
|---|---|
| 현재 방침 | 가입·구독·이용기록·문의 항목만 있음 (`app/(company)/privacy/page.tsx:31-37`) |
| 익명 집계만 저장 | "비식별 통계" 고지 한 줄로 충분한지 **법무 확인 필요** |
| `user_id`와 결합 저장 | 방침 항목·목적(2항) 추가 필요 |
| 동의 지점 | 질문 화면 한 줄 고지 + 로그인·구독 시 연결 동의 |

### 3.5 GA4 보강

| 추가 이벤트 | 용도 |
|---|---|
| `onboarding_start` | 진입 퍼널 시작 |
| `onboarding_skip` | "나중에 할게요" 이탈 |
| `onboarding_back` | 뒤로가기 |
| 구독·로그인 이벤트에 `source=onboarding` | 전환 귀속 |

GA4 콘솔에서 `moment`·`glance`·`format`을 맞춤 측정기준으로 등록해야 보고서에 보임(등록 여부 확인 필요).

## 5. 수익 연결 (아이디어)

제약: 토스페이먼츠 PG 심사 4개월 이상(서비스당 PG 1개 제약). 단기는 결제 없는 모델 우선.

| ID | 모델 | 쓰는 데이터 | 선행 조건 |
|---|---|---|---|
| M1 | 장면별 스폰서 슬롯 (예: 출근길 팟캐스트) | 장면(moment) 분포 + 형식별 청취 지표 | 응답 표본 확보, 광고 슬롯 설계 |
| M2 | 세그먼트 뉴스레터 광고·제휴 | glance·형식 + 구독자 수 | 구독자 규모, 온보딩 연결 |
| M3 | B2B 기사·보도자료 4형식 자동 변환 서비스 | 기사 1건 원가 약 3,000원 | 판매 단가·품질 보증 기준 |
| M4 | 유료 구독 (프리미엄 형식·개인화) | 개인화 데이터 | PG 심사 |
| M5 | 익명 선호 통계 데이터 상품 | 응답 표본 | 표본 규모·개인정보 검토 |

## 6. 성공 지표

| 지표 | 정의 | 목표(제안) |
|---|---|---|
| 응답 저장률 | 완료 이벤트 대비 서버 저장 건수 | 95% 이상 |
| 온보딩 완료율 | 진입 대비 결과 도달 | 현재 값 측정 후 설정 |
| 형식 일치율 | 선택한 장면의 형식과 2주 뒤 실제 시청 형식 일치 | 가설 검증용 |
| 온보딩 후 구독 전환 | `source=onboarding` 구독 / 완료 | 측정 후 설정 |
| 분포 표본 수 | 실제 집계 노출 임계(50명) 도달 시점 | — |
