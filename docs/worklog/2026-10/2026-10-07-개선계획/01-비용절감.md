## 3. 작업 A — 텍스트 Opus 5 → Sonnet 5

**효과**: 월 52~61만원 절감 (Opus $5/$25 → Sonnet 5 $2/$10, 보고서 단가). 산식은 월 환산 토큰 × 단가차. 산정값이며 Sonnet 5의 추론 토큰이 출력에 잡히면 줄어듦.

**현재 모델 구성**: 본문 4형식 Opus 5 · 사실 추출·분류 Sonnet 4.6 · 기사 선정 Sonnet 5.

| 단계 | 작업 | 산출물 | 담당 |
|---|---|---|---|
| A1 | CMS 프롬프트 랩에서 Sonnet 5 시험: 기사 5건 × (레터·팟캐스트·영상) | 비교표(분량·숫자·형식·토큰) | Claude 실행, 품질 평가 영광님 |
| A2 | 합격 기준 판정: 분량 예산 통과 · 숫자 오류 0 · 파싱 통과 · 출력 토큰 증가율 | 형식별 합격 여부 | — |
| A3 | Sonnet 5 추론 프로파일 신규 3개(레터·팟캐스트·영상), 태그 `Service=lens` | 프로파일 ARN | 영광님(IAM 포함) |
| A4 | IAM: 파이프라인 태스크 역할(`mustknow-auto`·`frontpage-auto`)과 CMS admin Lambda 역할에 ARN 추가 | 정책 변경 | **영광님 실행** |
| A5 | 코드 상수 4곳 + CMS `_CATEGORY_BEDROCK` 변경 | 커밋 | Claude |
| A6 | 카나리: 하루 7회 중 1회만 Sonnet 5 → 1주 관찰 | 일별 합격률 | — |
| A7 | 전체 전환, 이미지 배포 | 배포 기록 | 승인 후 |

**웹툰 대본은 별도**: 9/20 시험에서 Sonnet 5가 내부 추론으로 토큰을 소진해 응답 0글자였던 이력(당시 max_tokens 8,000, 현재 16,000). 재시험 통과 시에만 전환.

**롤백 기준** (하나라도 해당 시 즉시 복원): 숫자 오류 1건 이상 · 분량 위반율 30% 초과 · JSON 파싱 실패. 복원은 상수 원복 + 이미지 재배포(다음 실행부터 적용).

**비고**: 모델 상수가 4곳에 분산(`letters/pipeline.py` · `podcast/pipeline.py` · `common/bedrock_client.py` · `webtoon/pipeline.py`). 06 문서의 설정 단일화와 함께 진행하면 전환 비용이 낮아짐.

## 4. 작업 B — 이미지 생성

**현황**: Bedrock us-west-2 Stable Image Ultra 컷당 $0.14. 월 약 10,900회 ≈ $1,530. 오류·스로틀은 14일 2건뿐이라 자동 재시도는 비용 원인이 아님.

| 안 | 컷당 | 월 효과 (산정) | 위험 |
|---|---|---|---|
| B1 Stability 직접 API Ultra | $0.08 (검색 기준) | 약 -92만원 (-43%) | 외부 키·선불 크레딧, 비용 태그 체계 이탈, 장애 시 대체 경로 |
| B2 Core로 전환(전체) | $0.04 (Bedrock) | 약 -153만원 | 품질 하락 큼 (9/20 Core→Ultra 전환 이력) |
| B3 하이브리드(표지·핵심 컷만 Ultra) | 혼합 | 절반 Core 시 약 -77만원 | 컷 간 화풍 일관성 |
| B4 수동·테스트 호출 억제 | — | 약 -33만원 | 운영 규칙 필요 |
| B5 컷 수 8 → 6 | — | 이미지 약 -21% (-45만원) | 기획 결정(스토리 완성도) |

**B1 시험 설계**: 동일 프롬프트·시드로 기사 5건 × 8컷을 Bedrock vs 직접 API로 생성해 비교.

| 평가 항목 | 판정 |
|---|---|
| 캐릭터·화풍 일관성 | 컷 간 동일 인물로 보이는가 |
| 한국인 외형 | 어색함 여부 |
| 말풍선 여백 | 텍스트 합성 영역 확보 |
| 텍스트 깨짐 | 이미지 내 글자 오류 |
| 콘텐츠 필터 거부율 | 거부 건수 |
| 시드 재현성 | 같은 시드 동일 결과 여부 |
| 지연·요청 한도 | 컷당 초, 분당 한도 |

**전제 작업**: 이미지 호출을 공급자 교체 가능한 어댑터로 분리(`webtoon_image.py`). 직접 API 장애 시 Bedrock으로 폴백.

**기타 후보(검색 단가)**: Imagen 4 Ultra $0.06 · FLUX.2 pro $0.03 · GPT Image 1.5 $0.04~0.12. 화풍·일관성 시험 통과 시에만 검토.

## 6. 작업 D — 영상 음성 Polly → ElevenLabs (영상만)

**준비 상태**: 비밀 `ai-labs/elevenlabs` 존재, 두 태스크 역할에 읽기 권한 있음 → CMS 영상 설정 `PROVIDER` 변경만으로 전환 가능. 영상·팟캐스트 설정은 분리.

| 방식 | 월 비용 (영상 월 10~20만 자 추정) |
|---|---|
| Polly generative ($30/M자, 현행) | $3~6 |
| ElevenLabs Flash v2.5 ($50/M자) | $5~10 |
| ElevenLabs Multilingual v2/v3 ($100/M자) | $10~20 |
| ElevenLabs Creator 구독 ($22, 22만 자 포함) | $22 고정 |

증가분은 월 약 0.6~2.7만원. 판단 기준은 한국어 품질.

| 단계 | 작업 |
|---|---|
| D1 | 영상 각본 실제 글자 수 집계로 월 사용량 확정 |
| D2 | 영상 5편을 Polly·ElevenLabs로 만들어 청취 A/B (영광님 평가) |
| D3 | `video/src/lib/tts.ts`에 Polly 폴백 추가 — 현재 TTS 실패 시 예외로 영상만 빠진 채 발행(`published_no_video`) |
| D4 | CMS 설정 전환, 크레딧 한도·미리듣기 소모 모니터링 |

팟캐스트까지 전환하면 월 약 100만 자: Multilingual 기준 +약 10만원(Flash +약 3만원). 별도 판단.

## 8. 검증·모니터링

| 대상 | 방법 |
|---|---|
| 모델별 호출·토큰 | CloudWatch `AWS/Bedrock` (ModelId=프로파일 ID) 일별 |
