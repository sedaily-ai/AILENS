# 나의 LENS 홈 레터 레이아웃

## 배경

‘오늘, 나를 위한 레터’의 첫 카드가 고정된 제목 폭과 줄마다 쌓인 추천 이유·작성자·읽기 링크로 높게 표시됐다. 홈 추천과 ‘다시 펼쳐볼 레터’도 레터 목록처럼 에디터 사진을 포함해 정돈해 달라는 요청을 반영했다.

## 한 것

- `DashboardLetter.tsx`: 홈 카드에도 에디터 사진·이름, 발행일, 제공된 기사 수를 표시한다. 추천 이유와 대표 카드의 읽기 링크는 작성자 아래 한 영역으로 묶는다.
- `MyLensPage.tsx`: ‘다시 펼쳐볼 레터’에 기존 상세 목록 옵션을 적용해 내 서랍과 같은 요약·작성자·주제 표시를 사용한다. 저장 목록의 불필요한 추천 이유는 표시하지 않는다.
- `myLensStyles.ts`: 대표 제목의 26ch 제한을 해제하고 명조체 제목, 연한 배경, 간격·하단 정렬을 조정한다. 1000px 이하에서는 추천 카드가 한 열로 배치된다. 저장 섹션 제목과 링크는 작은 화면에서 자연스럽게 줄바꿈한다.

- 실제 컴포넌트를 Chrome에서 렌더링해 1440/1024/768/760/390/320px의 사진 로딩·가로 넘침·한 열/두 열 배치를 확인했다. 북마크 콜백, 읽기 링크, 키보드 포커스, 저장 목록 요약·사진과 추천 문구 생략도 검증했다. 데스크톱·모바일 캡처를 직접 확인했다.
- 변경 파일 ESLint, 최종 프로덕션 빌드와 `npx tsc --noEmit -p service/frontend/tsconfig.json`, `git diff --check` 통과. 빌드 중 외부 API DNS 조회 경고가 있었으나 빌드는 완료됐다.

## 결정

- 기존 카드와 `EditorAvatar`를 재사용하고 신규 의존성을 추가하지 않는다.
- 추천 이유 원문과 추천 순서를 유지하고 시각적 배치만 바꾼다.
- 저장한 기사에는 홈 레터 전용 스타일을 적용하지 않는다.
