## 검증 범위

최종 본문을 CMS의 `build_script_call`로 구성해 Bedrock Opus 5를 두 번 호출했다. 해당 요청 구성 소스는 앞서 조회한 운영 소스와 동일했다. 운영 공개 API에 저장된 본문과 실제 추론 입력 해시가 일치한다. 브라우저에서 생성·서비스 발행까지 수행한 종단 시험은 아니다.

두 기사 모두 AI LENS에서 선정한 서울경제 원보도를 입력했다. [입력 출처](input-provenance.json)를 확인한다. 이전 R2는 재작성 본문이므로 버전만 바꾼 통제 실험이 아니다.

- 대본: 기사당 8컷, 총 16컷. 서버 계약·메타데이터·고정 외형 문구 검증 통과.
- 그림: 기사별 1·4·8컷, Ultra·SD 3.5·Codex 각 6장. 참조 입력 없이 개별 생성. 총 18장, 이미지 재생성 0회.
- 모든 모델의 핵심 image_prompt는 최종 v64 원출력 그대로다. Bedrock은 CMS의 공통 무문자 제약과 옵션을 사용하고, Codex는 같은 금지 항목·비율을 문장으로 전달했다. 내부 설정 동등성은 미확인이다.
- A 화면 글은 무수정. B는 [원출력](article-B-story-original.json)과 [최종본](article-B-story.json), [3·4·6·7컷 편집 이력](editorial-changes.json)을 구분한다. 이미지 지문은 변하지 않았다.
- 최종 대본에도 일부 보조 정보(2032년 12차 발사 등)는 생략됐다. 모든 고중요도 수치가 보존됐다고 주장하지 않는다.
- `pytest pipelines/common/test_webtoon_contract.py -q`: 16 passed. pytest가 없던 환경 오류는 임시 의존성 설치 후 해결했다. 새 유료 추론을 대신하는 테스트가 아니다.

## 실제 품질과 선택

두 Stability 경로 모두 B8에서 복장이 바뀌고 B4 위성이 휴대 기기처럼 보였다. A의 아파트 모형은 주택 형태로 바뀌기도 했다. Codex는 의상 구분과 위성 표현이 상대적으로 나았지만 얼굴·소품·공간 동일성은 불완전했다. v64는 검수 포함 운영 개선안이며 무검수 자동 발행 품질을 입증한 버전이 아니다.

현 운영 Ultra를 유지한다. SD 3.5는 비용 절감 평가 후보이며 이번 6장만으로 모델 품질 우열을 확정하지 않는다. GPT 이미지는 현재 Bedrock 공식 지원표상 이미지 생성 도구 미지원이다. Codex 시안의 정확한 모델 ID·품질·토큰·비용은 미노출이고, 특정 GPT 모델 또는 Bedrock 결과로 볼 수 없다.
