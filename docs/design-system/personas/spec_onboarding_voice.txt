[모듈] 온보딩 페르소나 보이스 — 리드 4인 톤·맥락별 카피
출처: frontend-next/src/app/onboarding/data/editorPersonas.ts
용도: 온보딩에서 에디터 선택 시 보여주는 톤/약속 카피 + 보조 accent

각 페르소나는 4개 맥락(commute 출근길 / lunch 점심 / bedtime 잠들기 전 /
study_break 쉬는 시간)별로 약속 카피를 가진다.

────────────────────────────────────────
NT · 민철 (NT-min) — 분석가
  archetype blurb : 변수·구조·시나리오로 사건을 풀어요
  톤 헤드라인     : 데이터로 본질만 짚어요
  톤 부연         : 감정은 변수에서 빼고, 구조만 봐요
  집중 영역       : 거시경제 / IT·산업 / 정책
  accent / bg / soft : #7c3aed / #f5f3ff / #ede9fe
  맥락별 약속:
   - 출근길 : 출근길 지하철, 오늘 시장의 핵심 변수 셋을 챙기실 수 있게 정리해드릴게요.
   - 점심   : 점심시간 3분, 시장의 구조 변화를 짚어드릴게요.
   - 잠들기 : 잠들기 전, 내일 시장을 바라볼 변수 셋을 정리해드릴게요.
   - 쉴때   : 지치실 때, 오늘 짚어둘 핵심 변수 셋을 정리해드릴게요.

────────────────────────────────────────
NF · 하은 (NF-ha) — 이야기꾼
  archetype blurb : 인물·결·여운으로 사건을 풀어요
  톤 헤드라인     : 숫자 뒤 사람의 이야기를 함께 읽어요
  톤 부연         : 수치보다 결을, 결론보다 사람을 봐요
  집중 영역       : 사회 / 문화 / 국제
  accent / bg / soft : #e11d48 / #fff1f2 / #ffe4e6
  맥락별 약속:
   - 출근길 : 출근길에 마음이 한 번 멈출 만한 이야기를 한 편 전해드릴게요.
   - 점심   : 점심 한 끼에 마음이 따뜻해질 이야기 한 편 전해드릴게요.
   - 잠들기 : 잠들기 전, 숫자 뒤에 있던 사람의 이야기를 한 편 전해드릴게요.
   - 쉴때   : 지치실 때, 마음이 한 번 쉬어갈 이야기 한 편 전해드릴게요.

────────────────────────────────────────
ST · 준서 (ST-jun) — 팩트 큐레이터
  archetype blurb : 결론·근거·종목으로 사건을 풀어요
  톤 헤드라인     : 결론부터 말해요
  톤 부연         : 3분 안에 핵심만, 결론 → 근거 → 끝
  집중 영역       : 금융·증시 / 기업 / 실용 정보
  accent / bg / soft : #059669 / #ecfdf5 / #d1fae5
  맥락별 약속:
   - 출근길 : 출근길 3분 안에 오늘 시장의 결론을 챙기실 수 있게 정리해드릴게요.
   - 점심   : 점심시간 3분, 시장의 핵심만 결론부터 정리해드릴게요.
   - 잠들기 : 잠들기 전, 내일 챙겨야 할 결론 셋을 정리해드릴게요.
   - 쉴때   : 지치실 때, 결론부터 3분 컷으로 정리해드릴게요.

SF · 소율 (SF-soy) — 트렌드 캐스터
  archetype blurb : SNS·핫·가벼움으로 사건을 풀어요
  톤 헤드라인     : 친구한테 카톡 보내듯 가볍게
  톤 부연         : 오늘 뭐가 핫한지, 한 컷으로
  집중 영역       : 라이프 / IT·트렌드 / 문화
  accent / bg / soft : #d97706 / #fffbeb / #fef3c7
  맥락별 약속:
   - 출근길 : 출근길에 오늘 핫한 트렌드 한 컷, 가볍게 보내드릴게요.
   - 점심   : 점심 잠깐, 오늘 SNS에서 뜨는 트렌드 한 컷 챙겨드릴게요.
   - 잠들기 : 잠들기 전, 오늘 가볍게 챙겨갈 트렌드 한 컷 보내드릴게요.
   - 쉴때   : 지치실 때, 가볍게 웃을 만한 트렌드 한 컷 챙겨드릴게요.

[accent 매칭] 이 온보딩 accent = 캐릭터 상세(editorsData) accent 와 동일 계열.
