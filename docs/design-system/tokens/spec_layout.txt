[모듈] 레이아웃 — 컨테이너·거터·spacing 토큰
출처: frontend-next/src/app/globals.css

■ 컨테이너
  --max-container : 1080px        최대 본문 폭
  .max-w-container 클래스로 적용. 모바일 우선, 중앙 정렬 단일 컬럼.

■ 거터(좌우 패딩)
  --gutter         : 20px         고정 거터 (.px-gutter)
  --spacing-gutter : min(32px, 5vw) 반응형 거터 (@theme, Tailwind spacing)
  두 토큰 공존 — 좁은 화면 20px, 넓은 화면 최대 32px 의도.

■ 스크롤/접근성 유틸 (globals.css)
  html: overflow-y: scroll (레이아웃 점프 방지), 폰트 스무딩 antialiased
  .skip-link        : 키보드 접근 스킵 링크 (focus 시 노출, 검정 배경 흰 글씨)
  .scrollbar-hide   : 가로 스크롤 영역 스크롤바 숨김 (탭/칩 캐러셀용)
  .no-hover         : hover 밑줄 제거

■ 기본 골격
  - 다크모드 없음, 화이트 베이스
  - 모바일 퍼스트 단일 컬럼, 데스크톱은 1080px 중앙
  - Tailwind v4 (CSS @theme 기반, tailwind.config 파일 없음)
  - 타이포 플러그인: @tailwindcss/typography (레터/본문 prose)

[디자이너 참고]
페이지 폭 1080 / 본문 거터 20~32px / 단일 컬럼 기준으로 시안 작성.
카드·리스트 중심 UI, 토스·당근 류의 부드러운 그림자·넉넉한 여백 톤 지향
(과한 그라데이션·굵은 테두리 지양).
