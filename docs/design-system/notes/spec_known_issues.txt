아카이빙 시점(2026-05-17) 코드 기준. 디자이너가 모르면 잘못된 시안이 나오는 항목만 추림.

1) 색 팔레트 2종 공존 — 통일 결정 필요 (최우선)
   같은 그룹인데 화면마다 hue가 다름:
     NT  피드/태그=blue #3B82F6   vs  캐릭터/온보딩=violet #7c3aed
     NF  피드/태그=violet #8B5CF6 vs  캐릭터/온보딩=rose   #e11d48
     ST  피드/태그=green #22C55E  vs  캐릭터/온보딩=emerald#059669 (근접)
     SF  피드/태그=orange #F97316 vs  캐릭터/온보딩=amber  #d97706 (근접)
   NT·NF는 아예 다른 계열. → "그룹 1색 = 정본" 한 벌로 통일하고 전 화면 적용 권장.

2) 캐릭터 일러스트 4/12만 존재
   실제 일러스트(PNG)는 그룹 리드 4인뿐: 민철(NT)·하은(NF)·준서(ST)·소율(SF).
   나머지 8인은 Dicebear notionists API(자동 생성 SVG)로 임시 대체 중:
     NT 지훈·서연 / NF 수빈·예린 / ST 도윤·시우 / SF 유나·다은
   페르소나를 12인 체계로 노출·확장하려면 8인 신규 일러스트 필요.
   현 우선순위: 리드 4인이 콘텐츠 화자와 1:1 → 4인 일러스트 품질이 1순위.

3) 이름 표기 드리프트
   리드 이름 정본 = 민철/하은/준서/소율 (editorsData + 콘텐츠 프롬프트 v3 일치).
   단 코드 일부 주석/구버전 온보딩 잔재에 시현/지원/정훈/하은 표기 존재.
   디자인 라벨·시안엔 민철/하은/준서/소율 사용할 것.

4) 그룹 아이콘이 이모지
   NT 📊 / NF 💡 / ST ✅ / SF 💬 — 현재 OS 이모지 그대로 노출.
   브랜드 아이콘 세트가 필요하면 4종 픽토그램 디자인 항목으로 별도 산정.

5) 폰트 미번들
   레포에 폰트 파일 없음. Pretendard Variable + Noto Serif KR 정품을
   디자이너가 별도 확보(둘 다 SIL OFL, 무료·상업 가능). 출처는 spec_fonts.txt.
   토큰의 Merriweather/Playfair는 실사용 안 됨 — 시안에 쓰지 말 것.

6) globals.css --color-primary 충돌
   :root 에서 #2563eb, @theme inline 에서 #ffffff 로 재정의(상충).
   주 액션 컬러 시안 잡을 때 개발과 1색 합의 필요.

7) 캐릭터 원본 한계
   현재 자산 = 1024x1024 정사각 단일 아바타 1컷씩.
   포즈·표정·전신·일러스트 변형 없음. 캐릭터 활용도(온보딩·레터 헤더·SNS)
   넓히려면 컷 베리에이션 신규 제작 범위로 잡아야 함.
