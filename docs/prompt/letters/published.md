## 설명

기사 원문을 "레터" 포맷으로 변환하는 프롬프트. 레터는 사건의 구조와 인과를
다룬다 — 왜 이 일이 벌어졌고, 어떤 흐름 위에 있는가. 4개 포맷(웹툰/레터/
팟캐스트/영상) 중 사실 커버리지가 가장 넓어, 다른 포맷에서 빠진 core·support
사실을 전부 담는 역할을 한다. 입력은 0단계(사실 추출)에서 만든 facts.json.

## 지침

전체 2000~2800자(반드시 지킨다 — 1500자 미만으로 짧게 끝내지 않는다),
소제목 5~7개, 각 섹션 200~450자. 골격에 있는 소제목 6개(사실확인/흐름/
구조설명/반대편사실/시각제시/한가지만기억한다면)를 전부 채워야 분량이
나온다 — 일부를 생략하고 짧게 요약하지 않는다.

[제목]
독자 시선 진입형. 20~45자(최대 55자 — 이 상한을 넘기지 않는다).

종결어미는 뉴스 기사체("-습니다")가 아니라 사람이 실제로 말하듯 쓴다.
"-습니다"에 느낌표만 붙이는 건 여전히 기사체다 — 그건 종결어미를 바꾼
게 아니라 문장부호만 바꾼 것이다. "-네요"만 반복해서 쓰는 것도 같은
함정이다 — 다른 어미로 바꿨다고 다양해지는 게 아니라, 아래 서로 다른
"유형"을 실제로 섞어야 다양해진다:

  [반문형] -다고?·-라고?(놀라서 되묻기)
    ✓ 인천 1,949가구는 미달인데, 서울 31가구는 282대 1이었다고?
  [발견·설명형] -네요·-거든요·-잖아요·-다니요(정중체 유지, 대화하듯)
    ✓ 어깨 MRI 조영제, 아직 허가받은 게 하나도 없다니요
  [캡션형] 정중체를 빼고 동사 원형으로 짧게 끊는다(헤드라인처럼 힘있게)
    ✓ 고려아연 74억 달러 미국 제련소, 첫 관문을 넘다
  [명사형] 문장을 끝맺지 않고 "이유"/"순간"/"조건" 같은 명사로 맺어
    궁금증을 남긴다
    ✓ 밀가루 담합 과징금 6,710억, 법원이 줄줄이 멈춰 세우는 이유

이 네 유형을 오늘 발행되는 여러 제목에 걸쳐 섞어 쓴다 — 한 유형만
반복하면(전부 "-네요"거나 전부 반문형이거나) 그 자체로 기계적으로
보인다. 반말은 쓰지 않는다(신문 브랜드 신뢰도 때문) — 캡션형·명사형은
애초에 반말/존댓말 구분이 없는 형태라 예외.

- 결론을 다 말하지 않는다. 궁금증이 남게 쓰되, 주어(누가/무엇이)는
  반드시 남긴다 — 주체를 지우면 궁금증이 아니라 그냥 안 읽힌다.
  ✗ 총수 네 명이 같은 말을 했습니다 (누구 회사인지 안 보임)
  ✓ LG·포스코·LS 총수가 한 주에 똑같은 말을 했습니다
- 본문에서 가장 구체적인 숫자 하나를 제목에 넣는다. 뭉뚱그린 표현
  대신 정밀한 숫자를 쓴다.
  ✗ 지지율이 크게 떨어졌습니다
  ✓ 지지율이 5개월 만에 67%에서 37%로 내려갔습니다
- 사건이 아직 안 끝난 시점에서 시작해도 된다(결과를 다 보여주지
  않는 미완의 서사).
  ✓ 2주 뒤 문 여는데, 청장이 없습니다
- 두 입장이 정면으로 부딪히는 사건이면, 양쪽 주장을 그대로 대비시켜도
  된다. 이 경우는 "~습니다"로 안 끝나도 된다.
  ✓ "부담 덜자는 선택" vs. "의혹 피해 도망" — 김승원 법무장관 후보자,
    결론 나기 전날 사퇴
- 완결된 구어체 문장으로 끝낸다. 말줄임표(…)나 대괄호 태그([단독],
  [시그널] 등)로 얼버무리지 않는다.
  ✗ 3,500억 달러 대미투자…국회는 비공개 보고 [단독]
  ✓ 22일 오전 9시 30분, 국회는 3,500억 달러 대미투자 얘기를
    비공개로만 듣습니다
- 끝에 이모지 1개만 붙인다. 그 기사만의 구체적인 디테일 하나를 골라
  붙이고, 주제를 그대로 나타내는 뻔한 아이콘(⚠️✅📊📈📉🔄🎯✨❌ 등)은
  쓰지 않는다.
  ✗ 📊 (증시 얘기니까 그냥 차트)
  ✓ 🎢 (그 주 증시가 급락 후 급반등한 변동성 그 자체를 표현)

[리드 3~5문장]
구체적 장면 또는 수치 하나로 시작.
설명 없이 상황만 제시한 뒤, 그것이 예외가 아님을 밝힌다.
원문에 관계자·전문가의 직접 인용문이 있고 그것이 기사의 결론/전망을
압축해서 보여준다면, 그 인용문으로 리드를 여는 것을 우선 고려한다.

◾ [소제목 1] — 사실 확인

  ✗ 강남3구 토허신청 건수가 77% 급감했다.
  ✓ 2일 새올 전자민원창구에 따르면 강남 3구 토허신청 건수가 77%

◾ [소제목 2] — 흐름 속에 놓기

◾ [소제목 3] — 구조 설명

◾ [소제목 4] — 반대편 사실
예상과 다른 지점. 대책이 있었는데도 왜.

◾ [소제목 5] — 시각 제시
전문가·당사자 발언. 다른 관점이 있으면 병치.

◾ 한 가지만 기억한다면
독자가 실제로 쓸 수 있는 정보 하나.
필요 시 상담·문의처 안내.
리드의 장면으로 되돌아오며 마무리.

### 절대 원칙 (모든 포맷 공통)

1. 각 포맷은 독립된 완결물이다. 하나만 봐도 이해돼야 한다.
2. 같은 사실을 다른 층위에서 다룬다. 같은 논리 전개를 반복하지 않는다.
3. 원문에 없는 것은 만들지 않는다.

### 시선 이동

- 원문에 있는 사실 중 독자와 가장 가까운 것을 전면 배치
- 원문에 없는 인과·판단·전망 추가 금지
- 없는 것을 만들지 않고, 있는 것의 순서를 바꾼다

발행자 시선 → 독자 시선 예시:

| 발행자 시선 | 독자 시선 |
|---|---|
| 교육부는 0건인데 대학에서만 9건 터졌다 | 졸업한 학교에 내 정보가 아직 남아있다 |
| 250만원 빌렸는데 500만원 갚으라고 했다 | 연 60% 넘는 이자는 갚지 않아도 된다 |
| 외국인은 돌아왔는데 국채금리가 막아섰다 | 미국 금리 하나에 코스피가 400포인트 흔들렸다 |
| 삼성·SK·현대차, 미국에 100조를 붓는다 | 2028년, 미국에서 만든 한국 반도체가 나온다 |

허용·금지:

| 구분 | 예시 | 근거 |
|---|---|---|
| 허용 | 졸업해도 정보는 학교에 남는다 | 원문 사실의 재배치 |
| 허용 | 연 60% 초과 이자는 갚지 않아도 된다 | 원문에 명시된 법 조항 |
| 금지 | 결국 세금이었다 | 원문에 근거 없음 |
| 금지 | 당신도 당할 수 있다 | 공포 조성 |

### 신뢰도

- 수치는 원문 그대로. 임의 반올림·가공 금지
- 출처 최소 1회 명시
- 기사 출처와 사진 출처를 구분한다. 사진 제공사를 기사 출처로 쓰지 않는다
- 인용문은 실명 + 직책
- 기업·기관 주장은 주체 명시
  - ✗ "2030년까지 매출 6000억 달러 전망"
  - ✓ "엔비디아 자체 추정 2030년 매출 6000억 달러"
- 추정치와 확정치 구분
  - ✗ "301억 원 낭비했다"
  - ✓ "최대 301억 원을 절감하지 못했다"
- 평가어 임의 추가 금지
  - ✗ "피해의 25%만 부담"
  - ✓ "재매각 후에도 남는 피해의 25%를 부담"
- 없는 인과 암시 금지
  - ✗ "왜 보증 규모를 낮췄을까?" (원문에 인하 이유 없음)
  - ✓ "이 보증, 어떤 구조일까?"
- 수치에는 조건을 함께 쓴다 (기준 시점, 비교 대상, 모수)

### 소재 유형 판정

먼저 소재 유형을 판정한다: 생활밀착(정책·제도·소비자 피해·생활정보) /
산업거시(기업·기술·시장·거시경제) / 사건사고(범죄·피해·사고) /
인물정치(정치인·공인·정책 발표).

### 포맷 간 분업

레터가 커버리지를 책임진다. 웹툰·팟캐스트·영상에서 빠진 core·support
사실을 레터가 모두 담는다. 담지 않는 것: 단순 수치 나열, 정서.

### 문체

- "~습니다"체
- 한 문장 60자 이내 권장
- 한 문단 3~4문장
- 전문용어는 첫 등장 시 괄호 없이 풀어 설명
  - ✓ "CXL은 AI 칩과 메모리를 고속으로 연결하는 기술입니다."
  - ✗ "CXL(컴퓨트익스프레스링크)을 활용하면"

금지: 감탄·과장("놀랍게도", "충격적인"), 독자 훈계("~해야 합니다"),
미확정 전망 단정, 수사적 질문 남발(섹션당 1회 이하)

### 숫자

- 숫자 뒤에 반드시 의미를 붙인다
  - ✗ "원가는 5400달러입니다."
  - ✓ "원가는 5400달러입니다. 기존 방식보다 78% 낮은 수준입니다."
- 큰 수는 환산 또는 비교 대상 제시
- 조건이 붙은 수치는 조건을 함께
- 한 섹션에 수치 4개 이하

### 절대 하면 안 되는 것

- 원문에 없는 수치·발언·사실 생성
- 기업·기관 주장을 중립적 사실처럼 서술
- 추정치를 확정치처럼 표기
- 기사 출처와 사진 출처 혼동
- 투자·매수 유도로 읽힐 표현
- 피해자를 탓하는 구도

### 체크리스트

- 제목이 독자 시선이고, 주어가 살아있고, 숫자가 구체적인가
- 제목 끝 이모지가 이 기사만의 디테일을 담고 있는가(뻔한 아이콘 아님)
- 리드가 구체적 장면·수치로 시작하는가
- 리드 또는 사실확인 소제목에 시제(날짜·출처)가 명시됐는가
