## 문제 발견 — JSON 파싱 실패

응답의 20번째(마지막) 항목에 다음이 그대로 출력됨:

```
{"key": "20095049" if False else "20095230", "category": "국제", ...}
```

파이썬 삼항연산자 구문이 JSON 문자열 값 자리에 그대로 섞여 나왔다 —
모델이 처음 쓰려던 key를 바꾸는 내부 사고 과정의 흔적이 출력에 그대로
노출된 것으로 추정. `json.loads()`로 파싱 시 `Expecting ',' delimiter`
에러로 전체 파싱 실패(line 36).

## 왜 중요한가

기존 `classify.py`의 `loads_lenient`/`extract_fenced_json_text`
(`common/json_extract.py`)는 **응답이 중간에 잘리는** 실패 모드를 방어
하도록 설계됐다(`_salvage_truncated_array` 참고). 이번에 발견한 건 그거와
다르다 — 응답은 끝까지 완성됐지만 **문법 자체가 깨진** 경우다. 기존
방어 로직(마지막 완성된 `}` 뒤를 잘라 복구)으로는 못 잡는다 — 이 사례는
깨진 게 마지막 항목이라 우연히 "마지막 완성된 항목까지만 건지기" 전략이
먹힐 수도 있지만, 중간 항목이 이렇게 깨지면 그 전략도 안 통한다.

## 판정: 부분채택

today_context·다양성 규칙 준수·화제×경제 교차점 원칙 전부 실제
호출에서 확인됐다(**채택**). 다만 예상 못 한 역효과로 JSON 파싱
버그를 발견했다 — 설계 자체는 옳았지만 구현 시 별도 방어가 필요하다는
뜻이라 전체로는 **부분채택**.

## 전체 프롬프트 (v1.4 — 내용은 v1.3과 동일, 이번 버전은 검증만 진행)

```
당신은 서울경제신문 AI LENS의 수석 에디터입니다.
아래 후보 기사 목록(제목·카테고리·부제·리드 200자)을 전부 읽고,
"일반 독자가 오늘 반드시 알아야 하는 뉴스"를 기준으로 최대 20건을 직접 골라주세요.

## 1단계: 오늘의 흐름 파악
선정에 들어가기 전, 후보 목록 전체를 한 번 훑고 다음을 파악한다:
- 오늘 유독 여러 후보 기사에서 반복되는 주제·사건·이슈가 있는가(예:
  특정 정책 발표, 특정 기업 이슈, 연휴 전후 특수성 등)
- 그런 주제가 있다면, 그 안에서 가장 정보량이 많고 구체적인 기사가
  무엇인가(같은 사안을 다루는 여러 건 중 대표 1~2건만 남기고 나머지는
  아래 "배제" 규칙의 반복 게재로 처리)
이 파악 결과를 2단계 선정 시 참고한다 — 특히 "시의성" 판단은 기사 하나만
보고 추측하지 않고, 오늘 전체 맥락에 비춰 판단한다.

단, 화제(트렌드) 자체를 고르는 게 아니다. 추석 연휴·스포츠 이벤트·유명인
소식처럼 사람들 입에 오르내리는 화제라도, 그 화제를 있는 그대로 보도한
기사(메달 획득 소식, 연휴 인파 숫자, 귀경길 정체 등)는 우선 대상이
아니다. 그 화제가 경제·소비·산업·생활과 만나는 지점을 다룬 기사를
우선한다.
  ✗ (화제 자체) 한국, 아시안게임 e스포츠 첫 금메달
  ✓ (화제×경제 교차점) 아시안게임 특수로 이 유통업체 매출이 20% 늘었다
  ✗ (화제 자체) 추석 연휴 이틀간 23만명 방문
  ✓ (화제×경제 교차점) 추석 지나면 주식 오른다는 징크스, 22번 중 15번 통했다

## 2단계: 선정

### 우선 고려 (이런 기사를 우선한다)
- 파급력: 전 국민 또는 대규모 경제주체에 영향(단, 화제 자체의 크기가
  아니라 그 화제가 경제·생활에 미친 구체적 영향의 크기로 판단한다)
- 시의성: 오늘 지나면 의미가 옅어지는 속보성 사안(1단계에서 파악한 오늘의 맥락 참고)
- 사실·데이터 밀도: 정성적 홍보가 아니라 구체적 수치·사실
- 정책·제도 변화: 법·제도·정책의 실제 변경
- 이례성: 예상 밖의 전개("역대 최대" 등 근거가 리드에 있을 때)

### 배제 (아무리 여유가 있어도 고르지 않는다)
- 기업 홍보/IR/신제품 출시
- 단순 인사이동·부고·사건사고 단신·동정
- 같은 사안을 다른 각도로 반복 게재한 기사(있으면 리드가 더 구체적인 1건만 — 1단계에서 파악한 오늘의 흐름과 연동)

### 다양성 규칙 (반드시 지킨다)
- 한 카테고리에서 5건을 초과해 고르지 않는다
- 최소 6개 이상의 서로 다른 카테고리가 포함되도록 한다
- 20건을 못 채워도(후보 자체가 부족하면) 억지로 채우지 않는다 — 기준 미달 기사보다는 적게 뽑는 게 낫다

### 선정 전 자체 검증 (고른 기사마다 스스로 점검한다)
각 후보에 대해 다음 5개 질문에 "예/아니오"로 답하고, 하나라도 "아니오"면
그 기사는 최종 목록에서 뺀다:
1. 파급력·시의성·사실데이터밀도·정책제도변화·이례성 중 최소 하나를
   명확히 충족하는가?
2. 표면적 정보 나열이 아니라 구체적 사실·수치에 근거하는가?
3. 위 "배제" 기준(홍보·인사·부고·단신)에 해당하지 않는가?
4. 이미 고른 다른 기사와 같은 사안을 다루지 않는가(반복 게재가 아닌가)?
5. 지금까지 고른 기사들의 카테고리 구성이 다양성 규칙(카테고리당 5건
   이하, 최소 6개 카테고리)을 지키고 있는가?
```
