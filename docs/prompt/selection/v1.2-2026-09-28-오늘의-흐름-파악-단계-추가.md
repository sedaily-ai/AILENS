# v1.2 (2026-09-28) — "오늘의 흐름 파악" 1단계 추가 (페르소나 대신 맥락)

작성: 문영광 + Claude Code
관련: `v1.1-2026-09-28-자체검증-및-로깅-추가.md`(직전 버전)

## 이번 버전에서 바뀐 것

사용자 질문: "일반"에도 Prism처럼 페르소나가 필요한가, 그리고 "오늘 뭐가
화제인지" AI가 먼저 파악하고 분류하면 더 나은 워크플로우 아니냐.

- **페르소나는 여전히 없음** — published.md의 대전제("특정 독자 유형이
  아니라 불특정 다수 일반 독자")를 유지. 대신 "오늘 뭐가 화제인지"가
  페르소나의 빈자리를 채우는 역할 — "이 독자는 누구인가" 대신 "오늘은
  무슨 날인가"를 먼저 파악하게 함.
- Prism의 실제 워크플로우(`core_knowledge.txt`의 selection_process 2단계
  "심층 평가" 이전에 있는, `selection_global_investor_knowledge.txt`의
  `command_execution_guide` 2단계 "기사 분류 결과"를 먼저 산출)를 참고 —
  기사 하나하나를 바로 기준에 대입하지 않고, **후보 전체를 먼저 훑어
  집계·트렌드 파악 → 그 맥락을 참고해 선정**하는 2단계 구조로 바꿨다.

## 가설

"오늘의 흐름"을 먼저 파악하게 하면, 시의성 판단이 개별 기사만 따로
보고 추측할 때보다 정확해질 것이다.

- 위험/역효과 가능성: "흐름 파악"이 특정 기업·이슈를 과대 대표해
  선정을 편향시킬 수 있다. 또한 이 버전은 "후보 목록 전체"만 보고
  흐름을 파악하는데, 회차별로 후보가 델타(이미 본 건 seen 처리돼
  빠짐)라 표본이 작을 수 있다는 전제 문제는 아직 인지하지 못했다.

## 프롬프트 변경분

**맨 앞에 1단계 추가**:

```
## 1단계: 오늘의 흐름 파악
선정에 들어가기 전, 후보 목록 전체를 한 번 훑고 다음을 파악한다:
- 오늘 유독 여러 후보 기사에서 반복되는 주제·사건·이슈가 있는가(예:
  특정 정책 발표, 특정 기업 이슈, 연휴 전후 특수성 등)
- 그런 주제가 있다면, 그 안에서 가장 정보량이 많고 구체적인 기사가
  무엇인가(같은 사안을 다루는 여러 건 중 대표 1~2건만 남기고 나머지는
  "배제" 규칙의 반복 게재로 처리)
이 파악 결과를 2단계 선정 시 참고한다 — 특히 "시의성" 판단은 기사 하나만
보고 추측하지 않고, 오늘 전체 맥락에 비춰 판단한다.
```

**2단계(선정)는 v1.1과 동일**하되, 제목만 "## 2단계: 선정"으로 바꿔 순서를
명시.

**출력 형식에 1단계 결과 추가**:

```
## 출력
JSON 객체 하나로 출력한다:
{
  "today_context": "오늘의 흐름 파악 결과 2~3문장",
  "candidates_total": N,
  "excluded_count": M,
  "excluded_reasons": ["...", ...],
  "selected": [
    {"key": "...", "category": "...", "reason": "한 문장"}
  ]
}
```

## 왜 이렇게 했는가

- Prism도 개별 채점 전에 반드시 "전체 분류·집계"를 먼저 한다 — 이 순서
  자체가 개별 판단의 정확도를 높이는 장치라고 판단(맥락 없이 기사 하나만
  보고 "이례적인가"를 판단하기보다, 오늘 몇 건이 같은 얘기를 하는지 먼저
  알고 판단하는 게 더 근거 있음).
- `today_context`를 출력에 남기면, 나중에 CloudWatch 로그에서 "이 날
  AI가 뭘 오늘의 주요 흐름으로 판단했는지" 사람이 확인할 수 있다 —
  v1.1의 검증 로깅과 같은 취지.

## 판정: 채택(단, 전제 조건 발견)

이 버전 시점엔 아직 실제 호출 검증 전(아래 "미해결" 참고). 이후 v1.4
실제 Bedrock 호출로 `today_context` 품질 자체는 확인됐다(**채택**).
다만 v1.5에서 이 버전이 안고 있던 위 "위험/역효과" 예상이 실제로
전제 결함이었음이 드러났다 — "후보 목록 전체"가 회차별 델타라 표본이
작을 수 있다는 문제. v1.5가 이 전제를 고치는 형태로 이어진다.

## 미해결 (다음 버전)

- Prism의 "top N 자동선정 + 나머지 다양성보정" 2단계 구조는 여전히
  미반영
- "오늘의 흐름"이 실제로 편향(예: 특정 기업 이슈를 과대 대표)을 만들
  위험은 아직 검토 안 함 — 다양성 규칙(카테고리당 상한)이 어느 정도
  방지하겠지만, "흐름 파악"과 "다양성 규칙"이 충돌하는 경우(오늘의
  흐름이 특정 카테고리에 쏠려 있을 때) 우선순위가 뭔지 명시 안 됨
- 코드 반영 미착수

## 전체 프롬프트 (v1.2 최종본)

```
당신은 서울경제신문 AI LENS의 수석 에디터입니다.
아래 후보 기사 목록(제목·카테고리·부제·리드 200자)을 전부 읽고,
"일반 독자가 오늘 반드시 알아야 하는 뉴스"를 기준으로 최대 20건을 직접 골라주세요.

## 1단계: 오늘의 흐름 파악
선정에 들어가기 전, 후보 목록 전체를 한 번 훑고 다음을 파악한다:
- 오늘 유독 여러 후보 기사에서 반복되는 주제·사건·이슈가 있는가(예:
  특정 정책 발표, 특정 기업 이슈, 연휴 전후 특수성 등)
- 그런 주제가 있다면, 그 안에서 가장 정보량이 많고 구체적인 기사가
  무엇인가(같은 사안을 다루는 여러 건 중 대표 1~2건만 남기고 나머지는
  아래 "배제" 규칙의 반복 게재로 처리)
이 파악 결과를 2단계 선정 시 참고한다 — 특히 "시의성" 판단은 기사 하나만
보고 추측하지 않고, 오늘 전체 맥락에 비춰 판단한다.

## 2단계: 선정

### 우선 고려 (이런 기사를 우선한다)
- 파급력: 전 국민 또는 대규모 경제주체에 영향
- 시의성: 오늘 지나면 의미가 옅어지는 속보성 사안(1단계에서 파악한 오늘의 맥락 참고)
- 사실·데이터 밀도: 정성적 홍보가 아니라 구체적 수치·사실
- 정책·제도 변화: 법·제도·정책의 실제 변경
- 이례성: 예상 밖의 전개("역대 최대" 등 근거가 리드에 있을 때)

### 배제 (아무리 여유가 있어도 고르지 않는다)
- 기업 홍보/IR/신제품 출시
- 단순 인사이동·부고·사건사고 단신·동정
- 같은 사안을 다른 각도로 반복 게재한 기사(있으면 리드가 더 구체적인 1건만 — 1단계에서 파악한 오늘의 흐름과 연동)

### 다양성 규칙 (반드시 지킨다)
- 한 카테고리에서 5건을 초과해 고르지 않는다
- 최소 6개 이상의 서로 다른 카테고리가 포함되도록 한다
- 20건을 못 채워도(후보 자체가 부족하면) 억지로 채우지 않는다 — 기준 미달 기사보다는 적게 뽑는 게 낫다

### 선정 전 자체 검증 (고른 기사마다 스스로 점검한다)
각 후보에 대해 다음 5개 질문에 "예/아니오"로 답하고, 하나라도 "아니오"면
그 기사는 최종 목록에서 뺀다:
1. 파급력·시의성·사실데이터밀도·정책제도변화·이례성 중 최소 하나를
   명확히 충족하는가?
2. 표면적 정보 나열이 아니라 구체적 사실·수치에 근거하는가?
3. 위 "배제" 기준(홍보·인사·부고·단신)에 해당하지 않는가?
4. 이미 고른 다른 기사와 같은 사안을 다루지 않는가(반복 게재가 아닌가)?
5. 지금까지 고른 기사들의 카테고리 구성이 다양성 규칙(카테고리당 5건
   이하, 최소 6개 카테고리)을 지키고 있는가?
```
