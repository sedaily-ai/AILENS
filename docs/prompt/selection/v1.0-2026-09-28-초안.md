# v1.0 (2026-09-28) — 일반 카테고리 직접선택 프롬프트 초안

작성: 문영광 + Claude Code
관련: `docs/resources/prism-selection-reference/`,
`service/backend/prompts/mustknow/published.md`(기존 채점 프롬프트, 지면특별코너 4탭은 그대로 유지)

## 왜 이 초안인가

`mustknow_auto`의 "일반"(하루 목표 20건) 선정을 개별 기사 채점(1~10점,
7.0 임계값)에서, 소거를 거친 후보 전체를 LLM에게 한 번에 보여주고
직접 최대 20건을 고르게 하는 방식으로 바꾼다. 이유:

1. 기존 채점 점수가 7.0~7.4에 68.5% 쏠려(2026-09-28 실측) 사실상
   신뢰하기 어려운 이진 신호에 가까움
2. Prism도 최종 단계는 숫자 컷이 아니라 LLM이 후보 목록을 통째로 보고
   판단해서 직접 고르는 구조(`docs/resources/prism-selection-reference/
   inst_global_investor.txt` 참고)

## 전제(이미 확정된 것, 이 프롬프트 호출 전에 코드에서 처리)

- 카테고리 소거: 연예·스포츠·피플·오피니언 + 증권/산업/시그널(이미
  별도 탭으로 라우팅) 제외
- 기존 사전 필터 유지: 최소 300자, AI 프리즘/기업공시 다이제스트 제외,
  제목 유사도 72% 이상 중복 게재 제외

## 프롬프트 초안

```
당신은 서울경제신문 AI LENS의 수석 에디터입니다.
아래 후보 기사 목록(제목·카테고리·부제·리드 200자)을 전부 읽고,
"일반 독자가 오늘 반드시 알아야 하는 뉴스"를 기준으로 최대 20건을 직접 골라주세요.
개별 채점이 아니라, 후보 전체를 한 번에 보고 종합 판단합니다.

## 우선 고려 (이런 기사를 우선한다)
- 파급력: 전 국민 또는 대규모 경제주체에 영향
- 시의성: 오늘 지나면 의미가 옅어지는 속보성 사안
- 사실·데이터 밀도: 정성적 홍보가 아니라 구체적 수치·사실
- 정책·제도 변화: 법·제도·정책의 실제 변경
- 이례성: 예상 밖의 전개("역대 최대" 등 근거가 리드에 있을 때)

## 배제 (아무리 여유가 있어도 고르지 않는다)
- 기업 홍보/IR/신제품 출시
- 단순 인사이동·부고·사건사고 단신·동정
- 같은 사안을 다른 각도로 반복 게재한 기사(있으면 리드가 더 구체적인 1건만)

## 다양성 규칙 (반드시 지킨다)
- 한 카테고리에서 5건을 초과해 고르지 않는다
- 최소 6개 이상의 서로 다른 카테고리가 포함되도록 한다
- 20건을 못 채워도(후보 자체가 부족하면) 억지로 채우지 않는다 — 기준 미달 기사보다는 적게 뽑는 게 낫다

## 출력
JSON 배열. 각 항목: {"key": "...", "category": "...", "reason": "한 문장"}
```

## 알려진 한계 (다음 버전에서 다룰 것)

사용자 검토(2026-09-28)로 확인된, 이 초안이 Prism 대비 축약한 지점:

1. **Prism의 2단계 최종선별 구조가 없음** — Prism은 "상위 3개는 점수
   그대로 자동 선정, 나머지 3개는 아직 안 다뤄진 관심사 영역에서 채운다"는
   명시적 2단계였는데, 이 초안은 "카테고리당 5건 상한 + 최소 6개 카테고리"
   라는 평면적 규칙으로 뭉뚱그렸다. 20건 스케일에 맞게 이 2단계 구조를
   어떻게 확장할지 미정.
2. **Prism의 5개 자체검증 질문(예/아니오 게이트)이 없음** — Prism은 최종
   후보 각각에 대해 "핵심 관심사와 직접 연관되는가/심층 분석인가/실행
   가능한가/균형 잡힌 시각인가/중복 안 되고 상호보완적인가"를 LLM이
   스스로 점검하고 "아니오"가 하나라도 있으면 재고하는 단계가 있다.
   AI LENS "일반 독자" 톤에 맞게 이 5개 질문을 다시 쓸지, published.md의
   감별 기준으로 충분히 대체되는지 미정.
3. 실제 후보 풀 크기(하루 최대 350건, 소거 후도 100~350건)를 프롬프트
   한 번에 넣을 때 토큰 예산·비용이 어느 정도인지 실측 안 됨.

## 추가 확인(2026-09-28, Prism 원본 7개 파일 전수 확인 후)

처음엔 `docs/resources/prism-selection-reference/`에 3개 파일만 보고 이
초안을 썼는데, 나머지 4개까지 마저 읽고 두 가지를 더 발견했다(상세는
그 폴더 README):

1. **Prism은 완전자동이 아니라 사람이 "확인"/"동의"를 입력해야 다음
   단계로 넘어가는 대화형 워크플로우다.** mustknow_auto는 무인 자동
   실행이라 확인 게이트 자체는 못 가져오지만, "분류 통계 + 선정 이유를
   사람이 읽을 수 있게 구조화해서 로그에 남긴다"는 형식은 감사/디버깅
   목적으로 v1.1에 반영할 가치가 있다.
2. **다양성이 카테고리 하나가 아니라 여러 차원**(Prism은 테마·지역·
   자산군·정보유형·시간프레임)일 수 있다는 것도 확인 — AI LENS "일반"도
   카테고리 외 두 번째 차원(예: 정보 유형)을 추가할지는 아직 미정,
   v1 범위 밖으로 일단 보류.
