# 영상 다시 만들기 사용법

자동 발행된 기사 중 영상이 마음에 들지 않는 기사 하나를 골라, 프롬프트로 내용·디자인·길이를 고쳐 다시 만들고 그 기사 영상만 바꾸는 기능이다. 다른 기사와 자동 발행에는 영향이 없다.

## 어디서

CMS → 글 관리 → 기사 클릭(4가지 시선 편집 화면) → 오른쪽 위 **[영상 다시 만들기]**

> 이 편집 화면의 **[저장]은 누르지 않는다.** 영상 썸네일·대본 같은 정보가 지워지는 기존 문제가 있다.

## 순서

| 단계 | 할 일 | 확인할 것 |
|---|---|---|
| ① 원문 | 자동으로 채워진다. 비어 있으면 원문을 직접 붙여넣는다 | 기사 본문이 맞는지 |
| ② 수작업 프롬프트 | 맨 끝 `## 이번 영상 디자인`에 바꾸고 싶은 점을 말로 적고 **[프롬프트 저장]** | "저장 안 됨" 표시가 사라졌는지 |
| ③ 각본 | **[각본 생성]** (1~2분). 필요하면 각본을 직접 고친다 | 맨 앞 `[디자인 메모]`, 모든 `"type"`이 7종 중 하나인지, 숫자·연도가 기사와 맞는지 |
| ④ 렌더 | **[렌더]** (5~8분) | 오른쪽 "새 영상"과 왼쪽 "지금 영상" 비교 |
| ⑤ 교체 | 마음에 들 때만 **[이 영상으로 교체]** | 사이트 기사에서 영상이 바뀌었는지(몇 분 걸림) |

수작업 프롬프트는 한 번 저장하면 다음 기사에서도 그대로 불러온다. 보통은 맨 끝 `## 이번 영상 디자인`만 바꿔 쓴다.

## 프롬프트로 바꿀 수 있는 것

**내용**: 나레이션·자막·숫자·컷 구성. 말로 적으면 된다(예: "나레이션을 더 부드럽게", "가격 담합 부분을 강조").

**디자인·길이**: 말로 적으면 AI가 아래 값으로 바꿔 각본에 쓴다. 원하는 대로 안 되면 값을 콕 집어 적는다.

| 바꾸고 싶은 것 | 고를 수 있는 것 |
|---|---|
| 전체 테마 | 기본(남색) / 종이 질감(paper, 가로형) |
| 강조색 | red · orange · teal · blue · yellow |
| 종이 색 | cream · newsprint · kraft · black · spot(강조색 종이) |
| 컷 화면 | 신문 1면(newsFront) · 도장 숫자(stampNumber) · 도장 찍힌 문서(stampDoc) · 오려 붙인 헤드라인(headline) · 메모 보드(board) · 줄에 걸린 카드(timeline) · 찢은 종이 막대(bars) · 기사 사진(photo) |
| 강조 방식 | 도장(stamp) · 형광펜(marker) |
| 전환 효과 | 덮기(cover) · 찢기(tear) · 넘기기(flip) · 도장 컷(stampCut) · 확대(zoom) |
| 작은 글 | 숫자 위 한 줄·문서 제목(kicker), 헤드라인 아래 글(sub), 테이프 손글씨(note), 감탄 메모(tag), 도장 글자(stamp), 카드 아래 설명 |
| 길이 | 컷 뒤 쉬는 시간(0~5초), 끝 카드 넣기/빼기 |

- 컷 화면·종이 색·작은 글은 **종이 질감 테마에서만** 보인다. 쉬는 시간은 두 테마 모두 반영된다.
- 목록에 없는 디자인(예: 수채화 느낌)은 프롬프트로 만들 수 없다. 코드로 추가해야 한다.

예시:
```
## 이번 영상 디자인
- 종이 질감, 강조색 파랑, 끝 카드 넣기
- 첫 컷은 신문 1면처럼, kicker에 기사 제목
- 숫자 컷은 도장 숫자, 구조 컷은 줄에 걸린 카드
- 마지막 컷 뒤 1.5초 쉬기
```

## 렌더가 실패했을 때

디자인까지 AI가 쓰다 보니 각본 양식이 틀려 렌더가 실패할 수 있다. 실패해도 사이트 영상은 그대로다(교체를 눌러야만 바뀐다).

| 오류 문구에 이런 말이 있으면 | 해결 |
|---|---|
| `Invalid discriminator value`, `type` | [각본 생성] 다시. 그래도 같으면 각본의 `"type"`을 opening·stat·diagram·chart·photo·highlight·closing 중 하나로 고치고 화면 이름은 `"style": { "layout": … }`로 옮긴다 |
| `data.value/unit/label 중 누락` | 그 컷의 `"type": "stat"`을 `"highlight"`로, `"data": {}`로 고친다 |
| `JSON`, `파싱`, `찾지 못했습니다` | 직접 고친 곳을 되돌리거나 [각본 생성] 다시 |
| `points가 1개` | [각본 생성] 다시 |

대부분 [각본 생성]을 한 번 더 누르면 해결된다. 두세 번 연속 실패하면 디자인 요청을 단순하게 줄인다. 그래도 안 되면 기사 제목, 오류 문구 전체, 각본 전체를 복사해 개발 담당에게 보낸다.

## 알아 둘 것

- **영상 두 개 동시 렌더**: 탭을 두 개 열어 각각 하면 된다. 한 창에서는 렌더가 끝날 때까지 [렌더]가 잠긴다.
- **렌더 중에 창을 닫지 않는다.** 렌더는 끝까지 돌지만 창이 결과를 놓쳐 교체할 수 없게 된다.
- **수작업 프롬프트 ≠ 자동 발행 프롬프트.** 여기서 고친 프롬프트는 `video-remake`로 따로 저장돼 자동 발행에 쓰이지 않는다. 자동 발행 프롬프트는 프롬프트 실험실(영상 탭)에서 관리하며, 거기의 **[프로덕션에 적용]은 다음 회차부터 모든 새 기사에 반영**된다.
- 비용: 다시 만들기 한 번에 AI 각본·음성·렌더로 몇십 센트 수준.
