# 타임머신 콘텐츠 추가·수정 방법

타임머신 탭(`/timemachine`)에 올라가는 웹 인터랙티브 콘텐츠를 추가하거나 고치는 작업자용 안내.

## 구조

| 항목 | 위치 |
|---|---|
| 콘텐츠 파일(정적 HTML) | `service/frontend/public/timemachine/<사건>-<날짜>/` (`index.html`, `style.css`, `app.js`, `assets/img/`) |
| 목록 카드 정보 | `service/frontend/src/widgets/TimemachinePage/contents.ts` |
| 목록 화면 | `service/frontend/src/widgets/TimemachinePage/TimemachinePage.tsx` |
| 탭 정의 | `service/frontend/src/shared/lib/headerTabs.ts` (`timemachine`) |
| 공개 주소 | `/timemachine/<사건>-<날짜>/index.html` (예: `/timemachine/nova-20261119/index.html`) |

## 새 콘텐츠 추가

1. `public/timemachine/<사건>-<날짜>/` 폴더를 만들고 HTML 일체를 넣는다. 폴더명은 영문 소문자·숫자·하이픈. 경로는 상대 경로(`style.css`, `assets/img/...`)로 쓴다.
2. `contents.ts` 배열 맨 앞에 항목을 추가한다(최신순).
   - `slug`: 폴더명
   - `event` / `period` / `eventDate`: 사건명 / 시간 범위(예: `1558 → 2026`) / 사건 발생일(`YYYY-MM-DD`)
   - `title` / `description` / `date` / `kind`: 제목 / 설명 / 발행일 / 형식(인터랙티브 등)
   - `href`: `/timemachine/<폴더명>/index.html`
   - `thumbnail`: 목록 카드 이미지 경로
3. 발생일 7일 이내 사건은 목록 카드에 "오늘 발생 / 발생 D+N" 배지가 자동으로 붙는다.

## 기존 콘텐츠 수정

- 해당 폴더의 `index.html`, `style.css`, `app.js`, 이미지를 직접 고친다.
- 제목·설명·썸네일은 `contents.ts`에서 고친다.

## 로컬 확인

```bash
cd service/frontend
npm run dev    # 보통 http://localhost:3000 (사용 중이면 3001)
```

`/timemachine` 목록과 콘텐츠 주소를 직접 열어 확인한다.

## 반영 절차

1. 브랜치 생성: `git checkout -b feat/timemachine-<사건>`
2. 변경 커밋 후 `gh pr create --base main`. PR 본문은 왜 / 무엇이 바뀜 / 영향 범위 3단으로 쓴다.
3. 머지 후 배포는 `service/frontend/deploy.sh`(AWS 권한과 Docker 필요). 배포 전 절차는 `CLAUDE.md`와 `배포_스크립트_지도.md`를 따른다.

## 알려진 사항

- 현재 콘텐츠 HTML에는 `<meta name="robots" content="noindex">`가 있어 검색에 노출되지 않는다. 검색·AI 노출(GEO/SEO)을 열 때 제거하고, 사이트맵·`llms.txt`에 등록해야 한다.
- 콘텐츠 HTML은 사이트 헤더 없는 전체 화면이다. 목록 복귀는 브라우저 뒤로가기뿐이며, 링크 추가 여부는 미정이다.
- 수치는 출처와 기준 시점을 본문에 명시한다.
