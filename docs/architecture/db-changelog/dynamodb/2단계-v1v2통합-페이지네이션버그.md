**성능/정합성 버그 — 페이지네이션 누락**: `posts_repo.list_posts()`,
`cms_posts_ddb_client.list_published_posts()`가 DynamoDB의
`LastEvaluatedKey` 없이 1페이지만 읽어서, 응답이 1MB 한도를 넘으면 뒤쪽
글이 **조용히 사라지는** 버그가 있었다 — 에러 없이 데이터 유실이라 발견이
늦어지는 유형.

**배울 것**: 같은 유형의 버그가 3개 파일에 각각 따로 있다가 3주 뒤에야
공용 헬퍼로 통합됐다 — 처음부터 공용 페이지네이션 유틸을 만들었다면
막을 수 있었던 반복. Postgres 이관 후에는 이런 반복이 구조적으로 사라진다
(LIMIT/OFFSET 또는 keyset pagination을 ORM/쿼리 레이어 한 곳에서 처리).
