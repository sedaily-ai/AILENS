## 반복해서 나온 패턴 (다음 이관 때 참고)

- **페이지네이션 누락**이 3개 파일에서 각각 따로 발생(2단계) — 공용
  유틸이 없어서 같은 버그가 반복됨. Postgres에서는 쿼리 레이어 한 곳에서
  처리되면 구조적으로 재발 안 함.
- **응답 payload가 너무 커서 생기는 장애**가 최소 2번(09-03 Lambda 6MB
  한도, 09-07 GSI 이관 배경) — 둘 다 "필요 이상으로 큰 응답을 그대로
  돌려준다"는 같은 원인.
- **인프라 변경 시 IAM/권한 누락으로 인한 장애**가 최소 1번(09-07,
  신규 GSI ARN을 IAM 정책에 빠뜨림) — Postgres 이관 시 역할·GRANT 설계
  (`14-operations.md` §3)에서 같은 실수를 반복하지 않도록 체크리스트화 필요.
