# v1.19 — 컷오버 전 데이터 재동기화 (2026-09-09)

**왜**: v1.4~v1.18 내내 DynamoDB 원본이 계속 바뀌는 라이브 테이블이라는
점이 반복 확인됐다(v1.10 등). `CMS_DB_BACKEND=postgres` 실제 전환을
앞두고, 마지막 전체 이관(2026-09-08) 이후 누적된 신규 데이터를
반영하기 위해 기존 이관 스크립트 전체를 재실행했다. 모든 스크립트가
`ON CONFLICT DO NOTHING`(또는 신규 slug만 삽입하는 UPSERT) 기반이라
재실행 자체는 안전(기존 행 파괴 없음) — 다만 이미 존재하는 행의
필드 값 변경(예: 제목 수정, 발행 상태 변경)까지는 반영하지 않는다는
한계는 그대로다(멱등 재실행이 하는 일은 "신규 추가"뿐, "기존 갱신"이
아님 — 별도로 문서화).
