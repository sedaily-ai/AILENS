# v0.2 — PostgreSQL ERD 문서화 (2026-09-01)

**왜**: `lens_schema_2026-08-26.sql`(원본 DDL)이 있었지만 테이블별 컬럼
명세는 촘촘한 데 비해 관계(FK·카디널리티·삭제정책)가 글로만 정리돼 있어
파악이 어려웠다.

**한 것**: Mermaid ERD 소스 14개(도메인별 12장 + 전체 위상도 + 렌더설정) +
SVG 인라인 HTML 열람본(`docs/architecture/lens-postgres-erd.html`) 작성.
작성자(minyoung0303)가 두 가지 논의 필요 이슈를 커밋 메시지에 직접 남김:
웹툰 시리즈 엔터티 부재, `ai_usage_logs` 배타 CHECK와 탈퇴 정책의 잠재 충돌.

**성과**: "정의서는 있지만 관계가 안 보인다"는 문제를 시각 자료로 해결.
다만 원본 SQL과의 전수 대조는 이 시점엔 없었다(→ v1.0에서 발견된 40여 곳
오류의 원인).

관련 커밋: `7d836dd`(ERD 소스), `a0c6559`(HTML)
