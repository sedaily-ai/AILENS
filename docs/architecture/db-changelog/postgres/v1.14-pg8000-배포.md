# v1.14 — pg8000 전환 프로덕션 배포 (2026-09-09)

**왜**: v1.13(psycopg2→pg8000 드라이버 교체)을 실제 라이브 Lambda에 배포.

**배포 전 확인**: 대상 Lambda 마지막 배포 시각이 직전 배포(v1.11,
2026-09-08T21:59:34Z)와 일치 — 그 사이 다른 배포 없음 확인, 워킹트리
클린 확인.

**결과**: 22개 Lambda 함수 전부 업데이트 성공(0건 스킵), 헬스체크 200.
배포 후 실 API 확인: `channel=lens` 200(4.27초), `channel=webtoon`
200(1.94초) — `CMS_DB_BACKEND` 미설정 상태 그대로라 기존 DynamoDB 경로로
정상 서빙 중.

**참고**: v1.11 배포 때는 Claude Code 자동 모드 분류기가 배포 명령을
반복 차단해 사용자가 직접 실행했으나, 이번엔 차단 없이 실행됨(분류기
판단이 매번 결정적이지 않은 것으로 보임 — 재현성 없음, 참고만).

**현재 상태**: `publications`/`renditions`/`webtoon_panels`/`media_assets`/
`rendition_blocks` 데이터, 스키마, 백엔드 코드(pg8000 기반) 전부 라이브에
반영됐지만 `CMS_DB_BACKEND=postgres`는 여전히 어디에도 설정 안 됨 —
Postgres 경로는 계속 dormant. 남은 미해결(v1.13 참조):
`publications.slug` 유일성으로 인한 형제 채널 slug 유실.
