# v1.7 — article_categories 매핑 확정·이관 (2026-09-08)

**왜**: v1.6에서 보류했던 `article_categories` — `articles.category`(전통
신문 섹션: 경제/사회/정치/국제/문화/스포츠/IT_과학 등)와 `categories`
테이블(AI LENS 자체 분류: 증시/부동산/산업/금융·정책/국제/재테크/문화)이
서로 다른 체계라 임의로 매핑하지 않고 사용자 확인을 거쳤다.

**결정**(사용자 확인, 2026-09-08):
- `경제` → `금융·정책`: `증시`(주식시장 특화)보다 범위가 넓은 `금융·정책`이
  신문 `경제` 섹션(거시경제·정책·고용 등 포괄)과 더 맞는다고 판단.
  `Signal,Deal,ECM`/`Signal,Deal,M&A` 같은 증시·딜 특화 코드가 이미
  별도로 존재하는 것도 `경제`가 증시 전용이 아니라는 근거.
- `국제` → `국제`, `문화` → `문화`: 그대로 대응.
- 나머지(정치/사회/스포츠/IT_과학 등 50종)는 **미배정**(article_categories
  행 없음) — AI LENS의 7개 카테고리 자체가 경제·금융 콘텐츠에 편중돼
  있어, 안 맞는 원본 기사에 억지로 카테고리를 붙이지 않는 게 맞다고 판단.

**결과**:

| 카테고리 | 건수 |
|---|---|
| 금융·정책 | 6,531 |
| 국제 | 1,820 |
| 문화 | 1,096 |
| **합계** | **9,447** |

18,114건 중 9,447건(52%)에 카테고리 배정, 8,667건(48%)은 미배정으로 남음.
