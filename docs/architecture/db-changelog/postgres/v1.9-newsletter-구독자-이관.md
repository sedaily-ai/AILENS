# v1.9 — newsletters 시드 + 구독자 이관 (2026-09-09)

**왜**: 마지막 미해결 항목. `newsletters` 테이블이 원본 DDL에서 시드되지
않아 비어있었고, 실제 서비스는 지면 구분 없는 "오늘의 한 통" 단일
뉴스레터만 발송 중이라 구독자 3명을 어느 `newsletter_id`에 배정할지
근거가 없었다.

**결정**(사용자 확인, 2026-09-09): `sections`(지면 1면/증권 1면/산업
1면/시그널 1면, 이미 시드됨) 기준으로 `newsletters` 4행을 먼저 만들고,
구독자 3명은 **1번(지면 1면)에 임시 배정**한다. 실제로는 지면별 발송이
아니라 단일 발송이라는 사실을 여기 명시한다 — 나중에 지면별 발송이
실제 구현되면 이 임시 배정을 재검토해야 한다.

**결과**:

| 테이블 | 결과 |
|---|---|
| `newsletters` | 4행(지면 1면/증권 1면/산업 1면/시그널 1면) |
| `subscriptions` | 3건, 전부 `newsletter_id=1`(지면 1면)에 임시 배정 |

**⚠️ 임시 배정 표시**: 위 3건은 실제로 지면 1면 뉴스레터를 구독한 게
아니라, 지면 구분 없는 단일 뉴스레터 구독자다. `newsletter_id=1`은
편의상 배정한 값이지 실제 의미가 아니다.

남아있던 항목(article_categories, 뱃지, 커뮤니티 게시판, newsletter
구독자) 전부 처리 완료.
