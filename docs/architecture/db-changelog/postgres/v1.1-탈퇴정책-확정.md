# v1.1 — 회원 탈퇴 삭제 정책 확정 (2026-09-08)

**왜**: v1.0에서 논리·물리 설계를 확정했지만, 원본 SQL에도 정의돼 있지 않던
유일한 미해결 항목(회원 탈퇴 시 삭제 정책)이 남아있었다. 법무 검토가
필요하다고 판단해 보류했었으나, 개인정보보호법 조문 자체가 공개 법령이라
직접 리서치로 확정 가능하다는 판단하에 조사 후 결정.

**리서치한 것**:
- 개인정보보호법 제21조: 개인정보처리자는 보유기간 경과·처리목적 달성 시
  **지체 없이** 파기해야 하고, 파기는 복구·재생 불가능한 방식이어야 한다.
  다른 법령이 보존을 요구하는 경우만 예외이며, 그 경우 분리 보관 의무가 있다.
- 업계 실무 관행: "지체 없이"는 통상 근무일 기준 5일 이내로 처리.
- AI LENS는 전자상거래(결제 기록 보존 의무 없음)·통신(통신비밀보호법 대상
  아님) 서비스가 아니라 별도 보존 의무 법령이 해당 사항 없음을 확인.

**결정**: **탈퇴 = 하드 삭제 원칙, 접수 후 영업일 5일 이내 처리.**
`users.status='withdrawn'`은 삭제 배치 실행 전까지의 임시 상태로만 쓰고,
배치의 `DELETE`가 원본 스키마의 `ON DELETE CASCADE` 관계를 그대로 타고
내려가 관련 개인정보 전체를 삭제한다. `ai_usage_logs`는 애초에 FK가
없어(v1.0에서 확인) CASCADE 대상이 아니고 PII 컬럼도 없어, 법이 요구하는
"분리 보관"을 구조적으로 이미 만족한다.

**성과**: 스키마 변경 없이(원본 CASCADE 설계 그대로) 정책만 확정 —
`docs/architecture/lens-erd-src/14-operations.md` §4. 이걸로 논리 설계의
마지막 미해결 항목이 닫혔고, 5단계(구현) 진입을 막던 조건이 해소됐다.

관련: `docs/architecture/lens-erd-src/14-operations.md` §4, `06-users.mmd`
