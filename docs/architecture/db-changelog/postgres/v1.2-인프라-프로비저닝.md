**결정한 것**:
- 엔진 버전 16.14 — `14-operations.md`의 pg_bigm/pg_partman 지원 확인이 PostgreSQL 16
  기준이었음.
- Aurora **Serverless v2**(프로비저닝형 대신) — dev/검증 단계 비용 최소화 목적.
  Min 0.5 ACU로 잡아 완전 정지(콜드스타트)는 방지. 나중에 프로비저닝형으로
  바꾸거나 용량 범위를 조정하는 것은 인스턴스 재생성 없이 가능(같은 엔진).
- 보안그룹 인바운드를 전체 개방(0.0.0.0/0) 대신 단일 작업 IP로 제한.

- 확장 5종(pg_trgm/btree_gin/vector/pg_bigm/pg_partman) 설치
- 원본 스키마(`lens_schema_2026-08-26.sql`) + `14-operations.md` 결정 적용
- 서비스 백엔드(Lambda)와의 네트워크 연결 — 지금은 격리된 상태
