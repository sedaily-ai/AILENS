# v0.1 — PostgreSQL 스키마 원본 설계 (2026-08-26)

**왜**: DynamoDB 오버로드 단일 테이블 구조를 관계형으로 정규화 이관하기
위한 6단계 설계 산출물.

**한 것**: `lens_schema_2026-08-26.sql` — 50테이블·뷰1·확장3(pg_trgm,
btree_gin, vector). 이 레포 밖(외부 정의서 작성 과정)에서 만들어졌고,
2026-09-08에 레포로 편입됨(`docs/architecture/lens-erd-src/lens_schema_2026-08-26.sql`,
커밋 `1057956`).

**설계 당시 이미 반영된 실무 판단**:
- 파티션 키를 PK에 포함(`ai_usage_logs`, `view_events`) — Postgres
  네이티브 파티셔닝 제약을 정확히 앞서서 반영
- 한국어 검색·파티션 운영 자동화를 "확인 필요" 조건부로 명시적으로
  남겨둠(추측으로 채우지 않음) → v1.0에서 확정
- `view_counts.real_count`를 "제약으로 표현 불가, DB 권한으로 처리"라고
  명시 → v1.0에서 구체 GRANT문으로 완성

이 원본이 이후 모든 버전의 기준선이다 — v0.2 이후는 전부 이 파일을
검증·시각화·완성해가는 과정이었다.
