# 2026-09-18 웹툰 컷 이미지 "단계별 생성"(Stage Lab) 기능 추가

작성: 문영광 + Claude Code
관련: `admin/backend/routes/webtoon_lab.py`, `admin/backend/handler.py`,
`admin/frontend/src/components/WebtoonStageLab/WebtoonStageLab.tsx`,
`admin/frontend/src/components/PromptChatLab/PromptChatLab.tsx`

## 배경

컷 이미지 생성 파이프라인이 번역→인물 생성→배경 생성→합성→스타일 적용 여러
단계를 거치는데, 기존엔 최종 결과만 보였다. 사용자가 "그 단계들도 프롬프트별로
보이게 하면 안되나요?? 단계별로 컨트롤 하고 싶은 니즈가 있어서"라고 요청, 읽기
전용 노출과 각 단계 직접 제어 두 옵션 중 "2단계로"(직접 제어) 선택.

**주의**: 이 문서의 "단계별"은 컷 이미지 생성 파이프라인의 내부 단계(번역/
인물/배경/합성/스타일)를 가리킨다. 챗랩의 스크립트 생성 쪽에 있던
"1단계(스크립트)/2단계(장면 연출)" 구분과는 완전히 별개 축이다 — 그쪽은
같은 날 이후 작업에서 아예 통합·제거됐다
([[2026-09-18-웹툰-원빵흐름-스크립트스테이지-통합.md]] 참고). 이 Stage Lab
기능 자체는 이번 통합과 무관하게 그대로 유지된다.

## 한 것

- 백엔드(`webtoon_lab.py`)에 단계별 엔드포인트 신설: `handle_stage_translate`
  (번역), `handle_stage_character`(인물 생성, GPU/비동기), `handle_stage_background`
  (배경 생성), `handle_stage_composite`(합성), `handle_stage_style`(스타일 적용),
  `handle_stage_history`(단계별 산출물 조회). 공통 기록 헬퍼 `_record_stage()`
  신설, `_job_payload()`에 `s3_key` 필드 추가.
- `handler.py` HANDLERS에 6개 라우트 등록(`POST /admin/webtoon-lab/stage/
  {translate,character,background,composite,style}`, `GET .../stage/history`),
  API Gateway(`chzwwtjtgk`)에도 `aws apigatewayv2 create-route`로 실제 라우트
  생성(기존 `integrations/lgj4lzl` 재사용).
- 프론트에 `WebtoonStageLab.tsx` 신설 — 전체 폭 슬라이드오버 패널,
  `WebtoonImageLab.tsx` 스켈레톤을 그대로 따름. `WebtoonImageSettingsPanel`에
  새 `onOpenStageLab` prop을 추가해 `PromptChatLab.tsx`에서 열 수 있게 연결.

## 결정

- 별도 세션/상태 관리 테이블을 새로 만들지 않고, 기존 job 저장 패턴
  (config 테이블에 pk 네임스페이스 하나 늘리는 방식)을 그대로 재사용.
