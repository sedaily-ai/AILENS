5. 시나리오별 권장 스펙 산정제안

현재 피크 대비 ×3 기준 프론트 3 태스크(1 vCPU/2 GiB) · API t3.medium · Aurora 최대 12 ACU. ×30 이상은 인스턴스 증설보다 정적 생성·캐시 적중률 개선 우선.

  • 기준: 피크 오리진 1.51 req/s에서 0.5 vCPU 태스크가 CPU 100% → 포화점 vCPU당 약 3.0 req/s → 50% 사용률 vCPU당 1.5 req/s(경험 값, 부하 시험 아님)
  • 태스크 최소 2개(2 AZ). 사용자 환산은 현재 사용자당 요청 수 유지 가정
  • 비용: us-east-1 공시 단가 · 월 730시간 · 데이터 전송·요청 요금 제외

7.3 조회 한계

  • 비용 실측 불가(Cost Explorer SCP 차단). 비용 = 보고서 값 또는 공시 단가 추정
  • vCPU당 1.5 req/s = 14일 관측치 역산 경험 값. 확정에 부하 시험 필요
  • 미측정: CloudFront 캐시 적중률 · EC2(API) 요청 수 · Bedrock 분당 쿼터 사용률 · 파이프라인 1회 실행 시간 · question·v2-quiz 호출처. Polly·Rekognition = 계정 전체 지표만 존재
  • EC2 메모리 = 에이전트 수집 5일치
  • sedaily-mbti-* = 공용 접두사로 일부 DynamoDB·S3·Lambda는 AI LENS 전용 아닐 가능성. ElastiCache Redis · 옛 PostgreSQL(ensedaily-db)은 AI LENS 사용 근거 없음
