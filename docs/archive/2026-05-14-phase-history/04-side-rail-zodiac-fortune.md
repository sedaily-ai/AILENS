# Phase 04 — SideRail 띠별 "오늘의 재운" 카드 (시도 → REVERTED)

작성: 2026-05-14 · 상태: **REVERTED (제거 완료)** — 위험 부담으로 베타에서 제외

## 시도 배경
서울경제 지면에 실리던 띠별 재운 콘텐츠를 AI LENS SideRail 에 노출, 클릭하면 사주 페이지로 연결하는 컨셉. 내일 AWS 미팅에서 토의·시연 목적으로 mock 12 띠 × 오늘/금주 정적 데이터 + UI 박았음.

## REVERT 이유 (왜 뺐나)

사주·재운은 **틀리면 신문 신뢰도가 직격타** 입는 도메인이라 출시 전 결정해야 할 본질이 많음. 베타에서 mock 으로 박는 것도 위험 부담이 큼:

| # | 위험 | 비고 |
|---|------|------|
| 1 | **사주 정합성** | 12 띠 재운은 그날 일진(日辰)이 각 일주와 어떻게 상호작용하는지로 결정. AI 자유 글짓기로 만들면 사주 원리 안 맞을 위험. |
| 2 | **법적 책임** | "오늘의 재운" 이 사용자 의사결정(투자·계약)에 영향 줄 가능성. 신문사 명의로 박히면 책임 큼. 지면도 외부 업체(다지옴·홀성명학회)로 책임 분산. |
| 3 | **부정 메시지 검수** | "사고 조심" · "큰 손실" · "이별" 같은 강한 부정을 AI 자동 출력 시 사용자 충격. 검수 게이트 없이 베타 노출 위험. |
| 4 | **출생년도 단위 분기 필요** | 지면 표준은 12 띠 × 8~10 출생년대 = ~96 콘텐츠/일. 12 띠 단순화는 시연용일 뿐 운영 수준 아님. |
| 5 | **사주력 엔진 필요** | 음력 기반 일진 계산. 단순 양력 lookup 안 됨. saju.sedaily.ai 가 이미 보유. |
| 6 | **시스템 소속 모호** | AI LENS 가 자체 보유 vs `saju.sedaily.ai` 가 책임. 사주 도메인이 saju 로 이미 분리된 상태라 AI LENS 자체 보유는 책임 분리 깨짐. |

## 출시 전 반드시 결정 (재진입 조건)

이 카드를 다시 박으려면 아래가 다 정해진 후에:

1. **콘텐츠 소스** — 외부 사주 업체 라이센스 (예: 다지옴 홀성명학회) vs 자체 운영
2. **검수 워크플로우** — 사주 전문가 1차 검수 → 발행 게이트
3. **시스템 소속** — `saju.sedaily.ai` 가 책임 + API 제공, AI LENS 는 fetch 하는 구조 권장
4. **출생년대 분기** — 12 띠 × N 년대 단위
5. **면책 문구·라이센스 표기** — 법무 검토
