# archive — 폐기된 옛 문서

**현행과 안 맞는다는 걸 알면서 참고용으로만 보존하는 곳.** `worklog/`(그때
무슨 일이 있었는지 기록)와 다르다 — 여기는 "한때 정본이었지만 지금은
틀린 문서"가 대상이다.

## 규칙

- `architecture/`나 `product/`에 있던 문서가 더 이상 현실과 안 맞게 되면
  여기로 옮긴다 — **지우지 않는다** (완전 삭제가 맞다고 판단되면 그건
  archive가 아니라 진짜 삭제 대상이니 사용자 확인 먼저).
- 옮길 때 파일 맨 위(또는 관련 섹션)에 "왜 낡았는지 / 언제 왜 바뀌었는지"
  한 문단을 남긴다 — 그냥 이동만 하면 읽는 사람이 뭐가 문제인지 알 수 없다.
- 옮긴 이유는 `worklog/`에도 한 줄 남긴다(어느 세션에서 왜 옮겼는지 추적
  가능하게).
- 여기 있는 문서를 다시 살려서 정본으로 되돌리는 일은 거의 없다고
  가정한다 — 그럴 필요가 생기면 그때 가서 판단.
