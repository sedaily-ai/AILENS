# 명령어 실행 예시 및 가이드

## 간소화된 3단계 프로세스

### 1단계: 기사 파일 업로드 및 기사 수 확인

사용자가 기사 파일을 업로드하고 엔터만 누르면, Claude는 다음과 같이 자동으로 응답합니다:

```
기사 파일이 정상적으로 업로드되었습니다.

<기사 수 확인 결과>
첨부된 기사는 총 [N]개입니다.

모든 기사가 정상적으로 업로드되었으며, 분석을 위한 준비가 완료되었습니다.
</기사 수 확인 결과>

위 기사 수가 맞으면 "확인"이라고 입력해 주세요.
실제 기사 수와 다르다면 정확한 기사 수를 알려주시기 바랍니다.
```

### 2단계: 기사 분류 및 추천

사용자가 "확인"이라고 응답하면, Claude는 자동으로 기사 분류와 추천을 한 번에 진행합니다:

<추천 기사 결과>

4. 다양한 시장 환경과 시나리오에 대한 균형 잡힌 시각
5. 선정 기사간 중복 없는 상호보완성

* 검증 완료: 모든 추천 기사는 위 기준을 충족합니다.
* 제외 기사: X개 기사가 검증 과정에서 제외되었습니다. (주요 사유: [주요 제외 사유 요약])
</자체 검증 결과>

### 3단계: 선정 기사 파일 생성

사용자가 "동의"라고 응답하면, Claude는 선정된 6개 기사 내용을 추출하여 별도 파일 형태로 제공합니다:

```
선정된 6개 기사를 추출하여 별도 파일을 생성합니다:

<selected_articles>
[기사 1]
"[기사 제목 1]"

[기사 원문 내용 전체]

[기사 2]
"[기사 제목 2]"

[기사 원문 내용 전체]

[기사 3]
"[기사 제목 3]"

[기사 원문 내용 전체]

[기사 4]
"[기사 제목 4]"

[기사 원문 내용 전체]

[기사 5]
"[기사 제목 5]"

[기사 원문 내용 전체]

[기사 6]
"[기사 제목 6]"

[기사 원문 내용 전체]
</selected_articles>

선정된 6개 기사 파일이 생성되었습니다. 이 파일을 다운로드하여 2단계 프로젝트(기사 요약)에 활용하실 수 있습니다.

1단계 프로젝트(기사 선정)가 완료되었습니다. 2단계 프로젝트는 별도 세션에서 진행해 주세요.
```

만약 Claude가 원문 기사 추출에 어려움이 있거나 불확실한 경우:

```
선정된 6개 기사 목록입니다:

1. "[기사 제목 1]"
2. "[기사 제목 2]"
3. "[기사 제목 3]"
4. "[기사 제목 4]"
5. "[기사 제목 5]"
6. "[기사 제목 6]"

각 기사의 원문 추출이 불확실할 수 있습니다. 정확한 작업을 위해서는 원본 파일에서 위 제목의 기사들을 직접 찾아 추출하시는 것이 안전합니다.

1단계 프로젝트(기사 선정)가 완료되었습니다. 2단계 프로젝트(기사 요약)는 별도 세션에서 진행해 주세요.
```
