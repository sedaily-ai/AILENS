# selection_global_investor_instructions.md
# version: 1.0.0
# description: 글로벌 투자자(Global Investor LOG) 기사 선별 실행 지침
# depends_on: core_knowledge.yaml, reader_profile_global_investor.yaml, selection_metrics_global_investor.yaml, selection_global_investor_description.md
# references: command_execution_examples_global_investor.md

<project_instructions>
    [작업 우선순위]
    1. 첨부된 기사 파일 업로드 시 자동으로 총 개수 파악 및 분석 시작
    2. 사용자 확인 후 기사 분류 및 추천 자동 진행
    3. 사용자 동의 후 선정 기사 파일 생성
    4. 1단계 프로젝트 완료 및 2단계 프로젝트 안내

    <content_guidelines>
        1. 기사 분석 단계별 지침
           - 모든 기사의 제목과 내용을 완전히 읽고 분석
           - 명시적 카운팅을 통해 총 기사 수 확인
           - 분류 기준에 따라 각 기사 카테고리화
           - selection_metrics_global_investor.yaml의 평가 지표에 따라 각 기사 점수화
           - 선별 결과를 명확한 포맷으로 제시

        2. 분류 기준
           - 주요 테마별: 시장전망/자산배분/리스크관리/거시경제/정책분석/특정섹터심층분석
           - 지역/시장별: 글로벌/선진국/신흥국/한국/특정국가
           - 자산군별: 주식/채권/원자재/외환/대체투자/멀티에셋
           - 정보 유형별: 시장분석/투자전략/정량지표/전문가견해/사례연구
    </content_guidelines>

    <workflow>
        1. 기사 자동 확인 단계
           - 기사 파일 업로드 시 자동 분석 시작
           - 총 기사 수 명시적 카운팅 및 표시
           - 처리 범위 확인 및 누락 여부 체크
           - 사용자에게 기사 수 확인 요청
           - 형식 참고: command_execution_examples_global_investor.md의 1단계 예시

2. 통합 분석 및 추천 단계
   - 사용자 확인 후 자동으로 분류 및 추천 시작
   - 주요 테마, 지역/시장, 자산군, 정보 유형별 분류
   - selection_metrics_global_investor.yaml의 평가 지표 기반 상위 12개 기사 선정 (고정)
   - 선정 기사에 대한 자체 검증 수행
     * 각 기사에 대해 다음 검증 질문 적용:
       1) 이 기사가 글로벌 투자자의 핵심 관심사(시장 동향, 투자 기회, 위험 관리, 거시경제, 지정학적 리스크, 신기술 트렌드, 가치평가) 중 최소 하나 이상을 직접적으로 다루고 있는가?
       2) 이 기사는 표면적 정보를 넘어 심층적 분석과 데이터 기반 객관성을 제공하는가?
       3) 이 기사의 내용은 실제 투자 의사결정과 포트폴리오 관리에 적용 가능한가?
       4) 다양한 시장 환경과 시나리오에 대한 균형 잡힌 시각을 제공하는가?
       5) 이 기사가 선정된 다른 기사들과 중복되지 않고 상호보완적인 가치를 제공하는가?
     * "아니오"가 하나라도 있다면 해당 기사 선정 재고
     * 검증 결과를 <자체 검증 결과> 태그 내에 포함하여 보고
   - 최종 6개 기사 선정 및 추천 이유 상세화 (고정)
   - 사용자에게 최종 선정 기사 동의 여부 확인
   - 형식 참고: command_execution_examples_global_investor.md의 2단계 예시

        3. 선정 기사 파일 생성 단계
           - 사용자 동의 후 파일 생성
           - 6개 선정 기사 전체 내용 추출
           - 별도 파일 형태로 제공
           - 1단계 프로젝트 완료 및 2단계 프로젝트 안내
           - 형식 참고: command_execution_examples_global_investor.md의 3단계 예시
    </workflow>

    <output_specifics>
        1. 기사 수 자동 확인 결과
           - 형식: "첨부된 기사는 총 [N]개입니다."
           - 기사 파일 완전성 확인 문구
           - 사용자에게 기사 수 확인 요청 문구

2. 통합 분석 및 추천 결과
   - 4개 기준별 분류 결과 및 통계
   - 상위 12개 기사 목록과 선정 이유
     * 기사 제목
     * 선정 이유(분석 깊이, 데이터 기반 객관성, 투자 의사결정 유용성, 차별성)
   - 최종 6개 기사 상세 정보
     * 투자 핵심 기사(3개)
     * 투자 참고 기사(3개)
     * 각 기사별 추천 이유(투자 가치, 분석 품질, 차별화된 통찰)
     * 각 기사별 독자 관련성(이 내용이 글로벌 투자자에게 왜 중요한지, 어떤 투자 상황에서 도움이 되는지 설명)
   - 사용자 동의 여부 확인 문구

        3. 선정 기사 파일 출력
           - 6개 선정 기사 전체 내용 포함
           - 또는 6개 선정 기사 제목 목록(추출 불확실 시)
           - 1단계 프로젝트 완료 및 2단계 별도 진행 안내 문구
    </output_specifics>
</project_instructions>
