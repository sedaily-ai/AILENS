# resources — 참고 콘텐츠 데이터

문서가 아니라 **콘텐츠 원본/참고 자료**를 담는 곳 — architecture/product처럼
"시스템·서비스에 대한 설명"이 아니라, 실제 편집·제작에 쓰는 소재다.

## 규칙

- 출처가 외부(크롤링·제3자 자료)면 각 하위 폴더에 자체 README로 출처·수집
  시점·라이선스/재사용 근거를 남긴다.
- 코드가 프로그램적으로 읽는 자료가 아니다 — 사람(에디터)이 참고용으로
  쓴다. 코드에서 읽어야 하는 데이터라면 `service/backend`나 `pipelines/`
  쪽 데이터 폴더가 맞는 자리(`docs/`가 아님).
