# 타임머신 1면 이미지 인수 규격

2026-11-03 · v1 · 대상: 1면 이미지를 올리는 사람

> 갖고 계신 1면 JPEG를 고치지 말고 지금 폴더 구조 그대로 S3 한 곳에 올려 주세요.
> 올리기 전에 점검 스크립트에서 **오류 0건**, 올린 뒤 대조에서 **차이 0건**이 나오면 끝이에요.

## 1. 저장소

| 항목 | 위치 |
|---|---|
| 버킷 | `sedaily-lens-timemachine-newspaper` (AWS us-east-1, 비공개) |
| 원본 이미지 | `s3://sedaily-lens-timemachine-newspaper/timemachine-newspaper/img/` |
| 점검 결과 | `s3://sedaily-lens-timemachine-newspaper/intake/check/` |
| 2026 텍스트 CSV | `s3://sedaily-lens-timemachine-newspaper/intake/text/` |
| 사이트 주소(개발이 연결) | `https://ailens.sedaily.ai/timemachine-newspaper/img/1995/05/19950517.jpg` |

- 버전 관리를 켜 두어, 잘못 덮어쓴 파일도 90일 안에는 되돌릴 수 있어요.
- `intake/`는 사이트에 공개되지 않아요.

## 2. 파일 형식

- 지금 가진 JPEG 원본을 그대로 올려요. 자르기, 크기 바꾸기, 다시 저장, 압축, 회전을 하지 않아요. 신문은 정해진 비율이 있어서 원본 그대로 보여 줘요.
- 하루에 1장(그날 1면)이에요. 같은 날 판이 여러 장이면 대표 1장만 올리고, 나머지는 목록으로 알려 주세요.
- 텍스트는 수집 스크립트가 만든 CSV 그대로예요(`date,page,rank,is_top,article_id,title,url,thumbnail`).

## 3. 파일 구조

```
<지면1면 폴더>/1995/05/19950517.jpg   →   timemachine-newspaper/img/1995/05/19950517.jpg
```

- 지금 로컬 구조(연도/월/YYYYMMDD.jpg)와 같아서 이름을 바꿀 필요가 없어요.
- 확장자는 소문자 `.jpg`예요. `.JPG`·`.jpeg` 파일은 점검에서 오류로 나오니 그 파일만 고쳐 주세요.
- 폴더 안의 다른 파일(메모, 숨김 파일)은 올라가지 않아요.

## 4. 업로드 방식

**준비물**: 이 저장소의 `timemachine-data/upload/check_images.py`, Python 3, AWS CLI v2, 버킷에 올릴 권한.

**권한**: 지금 쓰는 AWS 권한으로 이 버킷에 올릴 수 있으면 그대로 써요. 없으면 개발에 말씀해 주세요. 업로드 전용 정책 `lens-timemachine-newspaper-upload`(두 폴더에 올리기만 가능, 지우기 없음)를 붙여 드려요.

Windows에서는 아래 `python3`를 `py`로 바꿔 실행해요. `<지면1면 폴더>`는 실제 경로로 바꾸고 따옴표로 감싸요.

**① 점검**

```
python3 timemachine-data/upload/check_images.py "<지면1면 폴더>"
```

- 결과는 이미지 폴더 옆 `<폴더이름>_newspaper_check/` 에 생겨요(이하 `<결과폴더>`).
- 마지막 줄이 "오류 0건이면 올려도 됩니다"여야 다음으로 넘어가요. 오류가 있으면 목록(`newspaper_problems.csv`)의 파일을 고치고 다시 점검해요.
- 파일을 모두 읽어서 수십 분 걸릴 수 있어요.

**② 올리기**

```
aws s3 sync "<지면1면 폴더>" s3://sedaily-lens-timemachine-newspaper/timemachine-newspaper/img/ --region us-east-1 --exclude "*" --include "*.jpg" --exclude "*/._*" --content-type image/jpeg --cache-control "public, max-age=2592000"
```

- 옵션은 올릴 파일 고르기와 형식·캐시 설정이라 그대로 두세요.
- 중간에 끊기면 같은 명령을 다시 실행해요. 이미 올라간 파일은 건너뛰어요.
- `--delete`는 붙이지 않아요.

**③ 점검 결과·텍스트 올리기**

```
aws s3 cp "<결과폴더>/newspaper_manifest.csv" s3://sedaily-lens-timemachine-newspaper/intake/check/newspaper_manifest.csv --region us-east-1
aws s3 cp "<결과폴더>/newspaper_problems.csv" s3://sedaily-lens-timemachine-newspaper/intake/check/newspaper_problems.csv --region us-east-1
aws s3 cp "<CSV 경로>/naver_front_2026.csv" s3://sedaily-lens-timemachine-newspaper/intake/text/naver_front_2026.csv --region us-east-1
```

**④ 대조**

```
aws s3api list-objects-v2 --bucket sedaily-lens-timemachine-newspaper --prefix timemachine-newspaper/img/ --region us-east-1 --output json > newspaper_listing.json
python3 timemachine-data/upload/check_images.py --compare "<결과폴더>/newspaper_manifest.csv" newspaper_listing.json
```

- "차이 0건 — 올리기 완료"가 나오면 끝이에요. 차이가 있으면 ②를 다시 실행하고 대조해요.

**⑤ 개발에 알리기**: ① 결과의 첫 두 줄(장 수·총 바이트), ④ 결과, 확인 목록 중 설명이 필요한 것.

## 5. 검증 기준

| 수준 | 기준 |
|---|---|
| 오류 (0건이어야 올림) | 이름·폴더가 `YYYY/MM/YYYYMMDD.jpg` 형식이 아님 |
| | 폴더의 연·월과 파일 이름의 날짜가 다름 |
| | 없는 날짜, 창간일(1960-08-01) 전, 오늘 이후 |
| | 빈 파일, JPEG로 읽히지 않음, 파일 끝이 잘림 |
| | 다른 날짜 파일과 내용이 똑같음 |
| 확인 (올려도 됨, 목록만 봐 주세요) | 지면 공백 기간(1980-11-26~1988-07-31) 날짜 |
| | 1996-09-29 이후 일요일(이때부터 일요일은 휴간) |
| | 가로 1,000px 미만, 가로가 세로보다 크거나 같음 |
| | JPEG가 아닌 파일(올라가지 않음) |
| 대조 (올린 뒤) | 올라가지 않은 파일, 남는 파일, 크기가 다른 파일, 내용이 다른 파일 모두 0건 |
| 개발 확인 | 버킷의 장 수·총 바이트가 `newspaper_manifest.csv`와 같음. 사이트 주소 연결 뒤 표본 이미지가 열림 |
