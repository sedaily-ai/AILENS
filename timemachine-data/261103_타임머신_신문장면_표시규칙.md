요구사항: `261103_타임머신_지면1면_요구사항.html`. 이미지 저장소·올리기 규격: `261103_타임머신_1면이미지_인수규격.md`와 README "데이터 구조".

## 범위

- 바꾸는 것: 이 장면에 1면 이미지를 넣고, 기사 목록의 출처·순서·문구와 지면이 없는 날의 안내·대체를 정한다.
- 바꾸지 않는 것: 백엔드(`time-machine` 함수), "그날의 기사" 탭, `/timeline` 페이지, 모바일 앱, 그날 신문 공유 카드와 영수증.

## 2. 표시

**지면 사진**
- 날짜로 정해진 주소(`/timemachine-newspaper/img/YYYY/MM/YYYYMMDD.jpg`)를 화면이 바로 불러온다. 연도 파일에 이미지 정보를 두지 않아서 이미지를 올리면 바로 보인다.
- 원본 비율 그대로 보여 주고 자르지 않는다. 뜨기 전 자리는 가로세로 비율로 잡는다(표본 3장은 세로가 가로의 1.37~1.39배, 전체는 측정 전).
- "1면 크게 보기" 버튼(44px)으로 확대·이동할 수 있는 보기를 연다. 닫기는 Esc와 바깥 누르기.
- 대체 글(alt)은 "1995년 5월 17일 서울경제 1면".

**기사 목록**
- 최대 4건, 부족하면 있는 만큼만 보여 준다.
- 네이버: 네이버가 준 순서의 앞 4건. 1번만 크게 보이고, 중요도나 "톱"이라고 말하지 않는다. 네이버 순서는 1번만 지면의 톱과 맞았고(2015-01-02, 2026-11-02 두 날짜 확인) 2번부터는 크기·위치 순서가 아니다. 썸네일 유무(`is_top`)도 쓰지 않는다(2015 표본에는 없고 2026 표본은 1번에만 있다).
- 빅카인즈: 지금 방식 그대로. 면 번호가 있는 시기는 본문이 긴 순에 `[사진]`·`[포토]` 제목은 맨 뒤, 그날 기사 시기는 그날 언론이 가장 많이 다룬 이슈 순이다. 출처 줄에 순서 기준을 밝힌다.
- 4건에서 빠진 네이버 기사는 사진에서 볼 수 있다.

**"1면" 문구**
- 1면이 확실한 날에만 쓴다: 지면 사진, 네이버 1면 목록, 빅카인즈 면 번호 시기(1994-01~1996-07, 2017-11-13~).
- 빅카인즈 그날 기사는 "그날 서울경제 기사"라고 부르고 "1면 기사"라고 부르지 않는다. 사진이 있는 날은 장면 이름에만 1면이 들어간다.
- 안내 문구에서는 못 구한 대상을 가리킬 때("이 날의 1면 사진을 찾지 못했어요") 쓸 수 있다.

**장면 이름**
- 사진이나 1면 기사가 있으면 "내가 태어난 날 서울경제 1면", 생일이 아닌 날 신문이면 "내 생일 무렵 서울경제 1면".
- 사진도 1면 기사도 없는 날은 "내가 태어난 날 서울경제".
- 화면 낭독용 제목은 "그날의 서울경제 1면"(사진·1면 기사가 있을 때) / "그날의 서울경제".

## 3. 지면이 없는 날

**이미지가 있으면 그날 지면이 있었던 것으로 본다.** 기사가 없다는 이유로 "지면이 없는 날"로 판단하지 않는다(네이버 수집 누락과 휴간을 구분할 수 없다).

| 날 | 보여 주는 것 |
|---|---|
| 일요일(1996-09-29부터 일요일자 없음) | 다음 날 월요일자. 월요일자가 없으면 하루 전 토요일자 |
| 명절·보관본 결측 | 가장 가까운 지난 신문(생일부터 하루씩 거슬러 최대 10일) |
| 10일을 거슬러도 없음 | 안내만 |
| 1990-01-01 이전의 명절·결측 | 안내만(지금도 안내만 한다) |
| 창간 전, 발행 중단(1980-11-26~1988-07-31) | 안내만 |
| 오늘·아직 올라오지 않은 날 | 안내만 |

- 월요일자를 쓰는 근거: 월요일자는 일요일 정오 이후의 기사까지 담는다(2017-11-13 이후 빅카인즈 송고 시각 기준, 인쇄 전날 12시~인쇄일 12시). 같은 기간(2017-11-13~2026-10-19)에 1면이 없는 비율은 월요일 9.9%(467일 중 46일), 토요일 5.6%(466일 중 26일)로 월요일이 높아 토요일자를 안전장치로 둔다. 1996-10~2017-11-12는 목록이 없어 재지 못했다.
- 대체한 날의 신문은 공유 카드와 영수증에 넣지 않는다(지금과 같다).

## 4. 안내 문구

제목 / 설명. 날짜는 한 줄에 붙여 쓴다.

| 상황 | 제목 | 설명 |
|---|---|---|
| 창간 전 | 서울경제가 창간하기 전이에요 | 서울경제는 1960년 8월 1일에 창간했어요. |
| 발행 중단 | 이 시기에는 서울경제가 발행되지 않았어요 | 1980년 11월 26일부터 1988년 7월 31일까지는 지면이 없어요. |
| 일요일 | 생일에는 신문이 나오지 않았어요 | 일요일이라 서울경제가 나오지 않았어요. 대신 다음 날인 ○월 ○일 월요일자 서울경제 1면을 보여 줘요. |
| 일요일, 월요일자도 없음 | 생일에는 신문이 나오지 않았어요 | 일요일이라 서울경제가 나오지 않았어요. 월요일에도 신문이 없어서 하루 전인 ○월 ○일 토요일자 서울경제 1면을 보여 줘요. |
| 명절·결측 | 그날 1면을 찾지 못했어요 | 명절 등으로 쉬었거나 보관본에서 빠진 날이에요. 대신 가장 가까운 지난 신문인 ○월 ○일 ○요일자 서울경제 1면을 보여 줘요. |
| 오늘 | 오늘 1면은 아직 올라오지 않았어요 | 오늘자 서울경제 1면이 올라오면 볼 수 있어요. |
| 사진만 없음 | 이 날의 1면 사진을 찾지 못했어요 | 대신 그날 서울경제 기사를 보여 드려요. |
| 사진만 있음 | 이 시기는 1면 기사 목록이 없어요 | 1면 사진을 크게 보면 기사를 읽을 수 있어요. |
| 둘 다 없음 | 이 날의 1면은 보관돼 있지 않아요 | 서울경제는 발행됐지만 1면 사진과 기사를 구하지 못했어요. 구간을 아는 경우(1978-01-01~1980-11-25)는 "1978년 1월 1일부터 1980년 11월 25일까지는 보관된 지면이 없어요." |
| 불러오기 실패 | 그날 신문을 불러오지 못했어요 | 연결이 원활하지 않을 수 있어요. 잠시 뒤 다시 불러와 주세요. (다시 불러오기 버튼) |

- 대체한 신문에 사진이나 1면 기사가 없고 그날 기사뿐이면 "서울경제 1면" 대신 "서울경제"라고 쓴다.
- 사진 주소를 불러오지 못한 것이 네트워크 문제인지 사진이 없는 것인지 구분할 수 없는 경우는 "찾지 못했어요" 문구를 쓴다.

**출처 줄**
- 사진이 있을 때: "1면 사진은 서울경제 지면 이미지예요." 뒤에 목록 출처를 붙인다.
  - 네이버: "1면 기사 목록은 네이버 신문보기에서 가져왔어요."
  - 빅카인즈 1면: "기사는 빅카인즈 보관본에서 고른 1면 기사예요. 본문이 긴 순서로, 사진 설명은 맨 뒤에 보여 줘요."
  - 빅카인즈 그날 기사: "기사는 빅카인즈 보관본에서 고른 그날 서울경제 기사예요. 1면 기사 목록이 아니에요."
- 사진이 없을 때는 지금 문구를 따르되 "실제 지면을 옮긴 것이 아니에요"는 사진이 있을 때만 뺀다.
- 맨 아래 "날짜는 그날 신문을 찾을 때만 서버로 보내요"는 그대로 둔다.

## 5. 저장소

기사 데이터는 S3 연도 파일(`timemachine-newspaper/index/v1/YYYY.json`)에 둔다. DynamoDB는 빅카인즈 결과 캐시 용도로 지금처럼 백엔드가 쓴다.

- 이미 지나간 날의 기사라 거의 바뀌지 않고 모든 사용자에게 같다.
- 사이트 주소로 파일을 바로 받아 서버 호출이 없고, 백엔드를 고치지 않는다.
- 이미지와 같은 버킷·같은 태그·버전 관리 안에서 관리된다.

## 6. 배포

- 화면은 이미지 보기를 끈 상태로 먼저 배포하고, 이미지 업로드를 확인한 뒤 켠다. 켜기 전에는 지금과 같게 동작한다.
- 이미지를 날짜 주소로 부르므로 1960~1989년 생일 날짜도 사이트 서버로 간다(지금은 1990년 이전 날짜를 서버에 보내지 않는다). 사이트의 접속 기록(CloudFront 로그)이 켜져 있으면 날짜가 거기에 남는다. 켜짐 여부는 사이트 주소 연결 때 조회하며, 확인 전이다.

## 7. 요구사항 과제별 처리

| 과제 | 처리 |
|---|---|
| 1 지면 없는 날 | 3절 대체 규칙 + 안내. 이미지 우선 |
| 2 데이터 결측 | 4절 안내 9가지로 있는 정보만 표시 |
| 3 오늘·미래 | 미래 날짜는 입력에서 이미 막혀 있다. 오늘 지면은 "아직 올라오지 않았어요" |
| 4 표시 편차 | 기사 최대 4건, 톱 표시 안 씀, 사진은 원본 비율로 자리를 잡음 |
| 5 기존 기능 유지 | 백엔드와 빅카인즈 시기·대체 동작을 그대로 둔다 |
| 6 응답·호출 비용 | 2011-07-09 이후는 연도 파일과 이미지 한 장으로 외부 호출이 없다. 그 이전은 처음 보는 날짜에 빅카인즈를 호출하고 결과는 DynamoDB에 저장된다. 미리 모으기는 보류 |
| 7 이미지 규격 | 원본 유지. 휴대폰 속도를 재서 느리면 비율을 지킨 축소본을 `web/`에 따로 만든다 |
| 8 매일 갱신 | 별도 수집 자동화 |
| 9 수집 실패 | 별도 수집 자동화(재시도, 알림, 누락 목록, 날짜 지정 재처리) |
| 10 저장소·구조 | README "데이터 구조". 태그는 `Service=lens` |
