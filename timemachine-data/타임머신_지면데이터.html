파일 형식이미지는 웹 제공 가능한 크기·형식(목록용·상세용). 일자 하나로 이미지 정보와 1면 기사를 한 번에 읽을 수 있어야 함이미지 형식·해상도(변환 후 크기 미측정), 응답 스키마, 본문·기자명 포함 여부
폴더·파일 구조일자만으로 위치 계산 가능, 형식 변경 대응(버전), 공개·비공개 구분. 로컬은 연도/월/YYYYMMDD.jpg경로 규칙, 버전 방식, 접근 제어
호출 방식일자 선택 시 네이버·빅카인즈 등 외부 호출 없이 응답. 지면 없는 날·이미지 없는 일자의 처리 규칙요청 수·응답 시간 목표(현재 없음), 발행일 판별 방식
데이터 저장소이미지 21.3GB + 일자 데이터 보관·제공. 비용태깅 Service=lens저장소 종류, Aurora(정본)·DynamoDB(기존 캐시)와의 관계, CloudFront 구성
효율적 호출같은 일자 반복 호출 방지. 과거 일자는 장기 캐시, 오늘·최근은 변동 가능. 갱신 시 당일·색인만 반영캐시 유효기간, 무효화 방식, 이미지 단계 로딩
매일 수집최신호 1면 이미지와 네이버 1면 텍스트를 같은 일자로 묶어 자동 적재. 실패 재시도·누락 알림·페이지 변경 알림. 무료 범위가 최신호 1면뿐이라 하루를 놓치면 보충이 어려움실행 시각(게시 시각 측정 후), 실행 환경, 재시도·알림 방식
